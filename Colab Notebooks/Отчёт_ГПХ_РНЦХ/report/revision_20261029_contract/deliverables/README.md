# Новая версия для авторского рецензирования — 29.10.2026

Основной файл: `Отчёт_ГПХ_РНЦХ_20261029_УО_договор_для_рецензирования.docx`.

УО является основной целью; ФВ оставлена дополнительным направлением. Главы выстроены по исследовательской последовательности и требованиям договора: основания → методика → КТ и сегментация → модели → эксперименты → результаты → достигнутые характеристики и ограничения.

В приложении А находится матрица всех 41 переданного требования. Её отдельная копия — `../contract_matrix.md`. Статусы разделяют наличие описания, частичную проверку, неподтверждённые характеристики и отдельные результаты передачи. Начать рецензирование удобно с этой матрицы (стр. 298–305 в собранной версии) и таблицы 11.6 — паспорта достигнутых характеристик (начало на стр. 260). После изменения текста страницы могут сдвинуться; надёжными ориентирами остаются названия разделов.

Всего 30 иллюстраций: все 24 прежние позиции сохранены и добавлены 6 рисунков из доступных HTML-отчётов и расчётов. Для новых графиков приведены происхождение и ограничения интерпретации. Участники обозначены буквами; количественные значения не менялись при подготовке изображений.

Прежний Word сохранён без изменения. В новом включена регистрация дальнейших исправлений; уже внесённые редакционные изменения представлены как исходная версия для рецензирования, без накопленных технических исправлений. После начала авторской правки не заменять этот файл повторной сборкой из Markdown.

Отрицательные результаты, условные оценки, неидентифицируемость и ограничения переноса сохранены. Сквозной подтверждённый расчёт УО и его точность не объявляются достигнутыми. Полные исследовательские архивы и презентация остаются отдельными результатами передачи; эта редакция их комплектность не подтверждает.

Файлы `review_delivery.json`, `docx_audit.json`, `layout_audit.json` и `preservation_audit.json` фиксируют проверку сборки. `reference_styles.docx` — служебный шаблон, не файл для рецензирования. Внутренний PDF использован только для контроля вёрстки.
