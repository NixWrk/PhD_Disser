# Исторические и объединённые прототипы

Этот каталог хранит исторические файлы и санифицированные указатели на исходные
версии, из которых выделяются новые серии `NN.MM`. Файл в `archive/legacy/`
служит источником происхождения, а не активным этапом расчёта и не
подтверждённым научным результатом.

Полные несанифицированные снимки могут содержать локальные пути, widget-state и
субъектно-связанные outputs. Они хранятся локально в `../private/`, который
исключён из Git. Исходный корпус восстанавливается из коммита
`1ac7813654b59861e359cffe3ad40941baeab2d9` и
`../../MIGRATION_MANIFEST_2026-08-26.json`.

## Правила использования

- Не читать архивный файл как вход активного расчёта.
- Не переносить сохранённый output без проверки входов, единиц, калибровки,
  состояния дыхания и версии кода.
- При извлечении блока фиксировать исходный путь, идентификаторы ячеек либо
  разделы и контрольную сумму из манифеста.
- Субъектно-связанные outputs и локальные пути не добавлять в Git повторно.
- Указатель со статусом `sanitized_provenance_pointer` не содержит исходного
  кода и не заменяет восстановление версии из Git.
- Удалять локальный приватный архив можно только после сравнения старого и
  нового расчётов и отдельного решения автора.

## Типы файлов

- Реально перемещённый исторический файл сохраняет исходные ячейки и может
  содержать старые пути или outputs; его нельзя использовать downstream.
- Санифицированный указатель содержит только старый путь, исходный коммит,
  ссылку на манифест и текущего владельца.

Для исходного состояния миграции используется коммит
`1ac7813654b59861e359cffe3ad40941baeab2d9`.
