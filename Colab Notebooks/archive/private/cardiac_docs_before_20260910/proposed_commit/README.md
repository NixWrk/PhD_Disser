# Проект кандидатской диссертации

Текущая структурная миграция начата **26 августа 2026 года**. Репозиторий содержит
код, рабочие документы, исторические исследовательские попытки и производные
материалы кандидатской работы по оценке сердечно-лёгочных компонентов
тетраполярной реокардиографии (ТРКГ).

## Каноническая рабочая область

[Colab Notebooks](Colab%20Notebooks/README.md) — база текущего исследования и
разработки. Наличие ноутбука, сохранённого output или численного файла не означает,
что результат научно подтверждён. Для результата должны быть установлены входные
данные, параметры, версия кода, единицы, QC и связь с конкретным протоколом.

## Текущее ограничение доказательной цепочки

В репозитории пока не зафиксирована полностью проверенная сквозная связь:

`ручная Inobitec-сегментация → субъект-специфическая геометрия → монтаж
электродов → физиологическая запись → параметры модели → FEM/QC → итоговый
диссертационный вывод`.

Сохранённые outputs и исторические результаты следует трактовать как рабочие или
диагностические материалы, пока для конкретного запуска не зафиксированы входы,
версии, единицы, контрольные суммы и QC.

## Данные и приватность

Исходные КТ, МРТ, ЭКГ, РЕО, STL и другие записи могут находиться вне репозитория
и содержать медицинские данные. В Git уже присутствуют отдельные производные
параметры, временные метки и notebook outputs, поэтому репозиторий нельзя
автоматически считать обезличенным или готовым к публичному распространению.

Не переносить и не коммитить исходные медицинские данные без отдельного решения.
Не публиковать производные данные до проверки идентификаторов, происхождения и
допустимого режима доступа.
