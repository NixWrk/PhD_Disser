# Дыхательные уровни Nik

`nik_breath_hold_levels.csv` фиксирует медианные уровни `BASE_2` на плато
задержки глубокого вдоха и глубокого выдоха. Значения перенесены из
`../Colab Notebooks/timestamps/*nik.json`.

- `delta_in_minus_ex_ohm = Z_inhale_hold_ohm - Z_exhale_hold_ohm`;
- строка 90 мм помечена `is_independent=0`, потому что `90nik.csv` является
  побайтовой копией `100nik.csv`;
- для совместной обратной задачи используются девять независимых размеров;
- записи получены последовательно, поэтому кривые по разным размерам допустимо
  собирать только для воспроизводимых плато задержки дыхания;
- спокойное и усиленное дыхание должны анализироваться как временные сигналы
  внутри каждой записи, а не как одновременная многобазовая кривая.

## Интерпретация для обратной задачи

Разность задержек вдоха и выдоха уменьшает постоянный offset конкретной записи и влияние
неизменного контакта электродов, но одновременно содержит два эффекта: изменение эффективного
`rho2` и изменение геометрии лёгкого/профиля `h(s)`. Подстановка дыхательной разности в
Якобиан вдоховой FEM при фиксированной геометрии требует нереалистично большого
`delta rho2 = 14...21 Ом·м`; это диагностический признак обязательного геометрического вклада,
а не оценка физиологического изменения сопротивления.

Полная постановка, сценарная связь с отношением объёмов лёгкого и обязательный профильный
анализ описаны в
[`../../../docs/INVERSE_IDENTIFIABILITY_AND_BREATHING_STATES.md`](../../../docs/INVERSE_IDENTIFIABILITY_AND_BREATHING_STATES.md).
