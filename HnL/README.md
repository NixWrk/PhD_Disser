# HnL — просмотр и вычитание импедансных каналов

Графические инструменты (PySide6 + matplotlib) для интерактивной работы с записями многоканального импеданса: просмотр каналов вместе с ЭКГ и подбор коэффициента вычитания одного канала из другого.

## Файлы

| Файл | Назначение |
|---|---|
| `NIX_HnL_V.1.1.py` | Основной инструмент. Выбор двух импедансных каналов $i,j$ и коэффициента $k$ (ползунок 0…2, шаг 0.01); отрисовка ЭКГ, $y_i(t)$ и разности $y_i(t)-k\,M\,y_j(t)$, где $M=\lVert y_i\rVert/\lVert y_j\rVert$ по выбранной норме |
| `GUI.py` | Более ранняя оболочка общего назначения: рекурсивный выбор папки с `.txt`, список каналов чекбоксами, инверсия и масштабирование ЭКГ, диапазон времени, расчёт половины амплитуды по выбранному ПРКГ-каналу, тепловая карта медиан скрытых каналов, оценка $\rho_1$ по медианному $z$ и параметрам $a,b$ |
| `prototype.ipynb` | Черновой прототип, из которого выросли оба скрипта |

## Запуск

```powershell
pip install PySide6 matplotlib numpy pandas
python NIX_HnL_V.1.1.py
```

## Связь с остальной работой

Инструменты решают задачу разделения вкладов «на глаз»: подбор $k$ показывает, насколько один канал объясняется другим. Количественная постановка той же задачи — анализ идентифицируемости источников ТРКГ, [Colab Notebooks/14](../Colab%20Notebooks/14_Идентифицируемость_источников.ipynb) и [13_Методология_ФВ_УО.md](../Colab%20Notebooks/13_Методология_ФВ_УО.md), этап B.

Разработка ведётся в ветке `Калмыков-HnL`.
