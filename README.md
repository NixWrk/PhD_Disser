# Калмыков — проекты

## Структура

```
Калмыков/
├── HnL/                  # Проект: анализ кардио-респираторных сигналов
│   ├── NIX_HnL_V.1.1.py  # Основной скрипт
│   └── GUI.py            # GUI-оболочка
├── 3D_Slicer/            # Проект: сегментация КТ → COMSOL
└── Old_code/             # Архив старых версий
```

## Ветки

| Ветка               | Описание                          |
|---------------------|-----------------------------------|
| `Калмыков`          | База (общая точка отсчёта)        |
| `Калмыков-HnL`      | Проект анализа HnL-сигналов       |
| `Калмыков-3dSlicer` | Пайплайн сегментации КТ → COMSOL  |
