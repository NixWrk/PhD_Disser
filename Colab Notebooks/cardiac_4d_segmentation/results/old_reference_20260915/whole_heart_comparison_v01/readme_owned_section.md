

## Сравнение динамики камер исторической КТ — 21.10

[Ноутбук 21.10](21.10_Сопоставление_динамики_камер_OLD.ipynb) и
[HTML без кода](21.10_Сопоставление_динамики_камер_OLD.html) сопоставляют
20 фаз одной исторической серии: контуры исходной КТ с последующим переносом
и пороговым выделением крови против TotalSegmentator v2. Отдельно показаны
наружная область сердца и кандидат ткани стенки. Разметка остаётся
кандидатной: обнаружены неопределённые границы камер и выходных трактов.
Расхождения методов пока не являются измеренной ошибкой TotalSegmentator.

Исходные КТ, маски, поля деформации, редактируемые проекты Slicer четырёх
опорных фаз и манифесты сохраняются в локальном каталоге OLD. Переменная
окружения `OLD_REFERENCE_ROOT` задаёт этот каталог; перенос готовых масок
использует `OLD_TRANSPORT_ROOT`, указывающий на папку с `config.local.json`.
Научный отчёт содержит описание происхождения и ограничений обоих способов.

- `transport_old_cardiac_candidates.py`: перенос контуров по деформации КТ;
  запуск в Python с SimpleITK и локальной конфигурацией.
- `refine_old_cardiac_candidates.py`: выделение крови в перенесённых областях
  по трём порогам; уже сохранённые результаты не заменяются.
- `build_old_dynamic_comparison.py --root <OLD_ROOT> --output <NEW_OUTPUT>`:
  проверка контрольных сумм, физических сеток и масок; расчёт объёмов,
  межфазных изменений и диагностических рисунков. Требуются все 20 фаз.
- `build_old_dynamic_report.py --root <OLD_ROOT> --analysis <NEW_OUTPUT> --output .`:
  формирование отчёта по рассчитанным данным без повторной сегментации.
- `create_old_dynamic_review_scene.py`: создание проектов Slicer; локальный
  корень задаётся через `OLD_REVIEW_ROOT`. Статус масок при экспорте остаётся
  непринятым. Наличие проекта не означает завершённую анатомическую разметку.

После просмотра автоматических контуров следующие исправления должны иметь
отметку об отсутствии ослепления. Исходный зафиксированный вариант сохраняется.
