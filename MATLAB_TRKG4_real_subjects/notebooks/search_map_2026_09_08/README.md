Источник — завершённый расчёт `auditfix_20260908`: 100 оценок, 85 допустимых,
15 отклонённых. Это 45 комбинаций центра и угла в **22 различных центрах**.
В 18 центрах есть допустимые варианты; в четырёх все проверенные варианты
отклонены. Это локальный участок: диапазон u — 30 мм, v — 20 мм.

Первичный подсчёт по точному равенству чисел CSV давал 23 центра. Два значения
u отличались примерно на 4.4e-16 мм и представляли один центр. Для группировки
использовано округление u, v до 1e-8 мм; эта техническая точность не является
оценкой точности положения электродов. Исходная история не изменена.

Цветом показан минимум **составного критерия J среди реально проверенных**
ρ₁, ρ₂, φ для данного центра. Критерий включает отклонение FEM от эксперимента
и априорные штрафы; его нельзя подписывать как RMSE, ошибку в Омах или
вероятность. Количество проверок в центрах различается. Серый крест означает,
что именно проверенные варианты отклонены; он не доказывает невозможность
другой ориентации в этом месте. Интерполяции и закрашивания непроверенных
участков нет. Поиска совпадения двуслойной модели с FEM при фиксированных
сопротивлениях эта карта не представляет.

Лучший вариант — оценка №94: J=24.067229, RMSE к эксперименту 7.287878 Ом;
u=7.879754 мм, v=10.654766 мм, φ=2.5°; ρ₁=5.552166 Ом·м,
ρ₂=30.706947 Ом·м. h до вершины лёгкого — 30.484929 мм. Остановка по бюджету,

## Воспроизведение и происхождение

Из корня MATLAB-проекта в MATLAB:

```matlab
addpath('notebooks/search_map_2026_09_08');
export_search_geometry('auditfix_20260908');
```

Затем Python с установленными numpy, pandas, scipy, plotly, pyvista, matplotlib:

```text
python notebooks/search_map_2026_09_08/build_search_map.py --tag auditfix_20260908
```

Экспортёр проверяет опубликованный контракт и использует точные копии функций
позы из зафиксированного `src/run_trkg4_inverse_inhale.m`. Нового FEM-расчёта
или оптимизации нет. Совпадение геометрии проверяется по h всех 85 допустимых
оценок, XYZ и оси итогового кандидата. Текущая поверхность кожи — все 155120
граней фактической FEM-сетки. Лёгкие и кости упрощены только для отображения;
кость является дополнительным контекстным слоем из локального STL.

Для видимости центры маркеров приподняты на 0.8 мм по наружной нормали,
а контур лучшего — на 1.3 мм. Таблицы и подсказки сохраняют исходные XYZ.
Отображаемые электроды 140 мм — заданные проектированные центры лучшей позы,
не контуры площадок и не их центроиды. Виды «Точки крупно» и «Область сборки»
намеренно ограничены; «Всё тело» включает всю расчётную поверхность.

`search_map_checks_*.json` содержит проверки SHA-256, количества точек,
геометрии и происхождения слоёв. `browser_checks.json` фиксирует реальную
проверку WebGL, кнопок обзора, включения костей и электродов, подсказки с
параметрами и отсутствие ошибок страницы. Это техническая проверка
визуализации, не физическая валидация FEM.

HTML автономен и содержит локальную геометрию. Файлы не опубликованы,
исходные данные и завершённый расчёт не изменены.
