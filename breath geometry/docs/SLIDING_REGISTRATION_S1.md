# Спецификация registration-кандидата S1

Дата фиксации: 2026-07-31.

## Какую задачу решает S1

S1 получает **обе** фазы одной пары: fixed-КТ выдоха и moving-КТ вдоха. Он должен
восстановить проверяемые соответствия анатомии между ними. Это reference-registration для
парных открытых данных, а не способ угадать выдох добровольца по одной КТ.

Если S1 пройдёт валидацию, его поля можно будет использовать для двух следующих задач:

1. измерить реальные парные изменения формы лёгких и стенки на открытых данных;
2. получить надёжные обучающие цели для отдельной модели
   `КТ вдоха → ансамбль возможных выдохов`.

До прохождения S1 нельзя строить парные карты толщины. Даже прошедший Gate 1L разрешает
только анализ лёгких; полная величина `кожа→лёгкое` требует также Gate 1B.

## Входы и выходы

Входы S1:

- CT в общей физической системе координат;
- маски лёгких и тела обеих фаз;
- маски костных структур, если они доступны;
- protocol/FOV/spacing metadata.

Expert landmarks не являются входом и не используются при выборе параметров.

Основной выход — не одно глобально гладкое поле, а как минимум два piecewise-smooth поля:

- `u_lung`: fixed-expiration → moving-inspiration внутри лёгких;
- `u_body`: fixed-expiration → moving-inspiration в грудной стенке и остальном теле.

На плевральной границе требуется согласованная нормальная компонента
`n·u_lung ≈ n·u_body`, но допускается скачок тангенциальной компоненты. Производная
искусственно склеенного поля через этот скачок не имеет физического смысла, поэтому
Jacobian оценивается отдельно внутри областей, с исключением интерфейсной полосы.

Каждый артефакт обязан хранить направление, RAS/LPS basis, миллиметры, spacing, source и
target space, параметры, checksum входов, версию кода и QC disposition.

## Заранее выбранная архитектура S1

S1.0 состоит из следующих стадий:

1. Одинаковая нормализация HU и общий физический grid; rigid-предсовмещение проверяется по
   позвоночнику/костям.
2. Отдельные lung- и body-кандидаты оцениваются по изображениям и соответствующим маскам.
   Locked ConvexAdam остаётся неизменяемым глобальным baseline, а не автоматически
   принимается как часть S1.
3. В интерфейсной полосе решается coupling-задача: штрафуется только расхождение нормальных
   компонент. Тангенциальное равенство не навязывается.
4. Регуляризация и topology QC выполняются отдельно для лёгких и стенки. Особо
   протоколируются нижняя треть лёгких и область диафрагмы.
5. Composite field разрешён только как явно маркированное производное представление для
   resampling/визуализации. Из него нельзя вычислять Jacobian через плевральный скачок.

Конкретный оптимизатор и веса S1.0 разрешено выбирать на synthetic suite и development
LungCT без expert landmarks. До первого просмотра 13-case expert regression результата
они фиксируются в versioned config.

Текущая реализация S1.0 зафиксирована в `configs/sliding_s1_v0.json`: masked ConvexAdam
для лёгкого, Diffeomorphic Demons для стенки и coupling к сглаженной normal маски лёгкого
без штрафа тангенциальной компоненты. Это кандидат на synthetic gate, а не прошедшее поле.

## Synthetic gate до реальных пар

`notebooks/05_sliding_phantom.ipynb` проверяет, что выбранное multi-region представление и
метрики способны выразить правильный контакт/скольжение и различить два разных failure
mode. Это representation gate: он уже пройден точным известным полем, но ещё ничего не
говорит о способности S1 восстановить поле из изображений.

Следующий algorithmic synthetic gate запускает S1 вслепую по synthetic изображениям как
минимум на трёх заранее зафиксированных вариантах spacing, нормального движения и
тангенциального скольжения. Для каждого варианта одновременно требуются:

- p95 endpoint error `u_lung` и `u_body` не больше 1.5 размера максимального вокселя;
- p95 расхождения нормальных компонент на интерфейсе не больше 1.0 мм;
- ошибка median тангенциального slip не больше 1.0 мм;
- Jacobian p01 не меньше 0.10 и нулевая доля `Jacobian <= 0` в каждой области;
- правильные direction/basis/unit metadata;
- отрицательные контроли «стенка не движется» и «интерфейс приклеен» проваливают
  соответствующие независимые метрики.

Если S1 использует численную инверсию для перехода `inspiration → expiration`, round-trip
p95 должен быть не больше максимального размера вокселя внутри каждой области.

Пороги выбраны до реализации S1 и не меняются после просмотра expert landmarks. Изменение
порога означает новый versioned candidate и записывается в журнале решений.

## Gate 1L: лёгкие на реальных парах

Единица анализа — субъект. Для каждого субъекта одновременно требуются:

- mean independent expert TRE не больше 2.0 мм;
- p95 independent expert TRE не больше 5.0 мм;
- FOV-aware Dice лёгких не меньше 0.90;
- FOV-aware lung surface p95 не больше 5.0 мм;
- body/common-FOV Jacobian p01 не меньше 0.10 и отсутствие `Jacobian <= 0`;
- отдельный отчёт TRE нижней, средней и верхней третей.

Image-derived keypoints остаются development-диагностикой и не подменяют expert TRE.
Текущие 13 expert cases являются frozen regression set, поскольку их ошибки уже повлияли
на выбор архитектуры. Для итогового утверждения нужен новый нераскрытый внешний набор.

## Gate 1B: грудная стенка на реальных парах

Gate 1B должен независимо проверять:

- FOV-aware соответствие наружной поверхности тела;
- устойчивые костные ориентиры: позвоночник, грудина и рёбра;
- соответствие границ жира/мышц там, где оно воспроизводимо;
- повторяемость сегментации и долю валидных `кожа→лёгкое` профилей в общем FOV;
- regional Jacobian/folding внутри стенки.

Сейчас для этих величин нет независимого body-wall ground truth и ещё не зафиксированы
обоснованные численные пороги. Поэтому Gate 1B имеет состояние `NOT VALIDATED`, а не
неявный PASS по lung landmarks. Пороги будут определены до парного анализа по
segmentation-repeatability и отдельным body/bone annotations на данных с достаточным FOV.

## Критерий перехода

- Representation gate PASS: можно реализовывать и отлаживать S1 на synthetic данных.
- Algorithmic synthetic gate PASS: можно запускать frozen S1 на development и затем на
  13-case regression set.
- Gate 1L PASS: можно строить парные карты формы лёгких для прошедших субъектов.
- Gate 1L + Gate 1B PASS: можно строить соответствующие парные карты полной толщины
  `кожа→лёгкое` и её тканевых компонентов.
- Только после появления таких проверенных пар можно обучать single-CT ensemble model.
