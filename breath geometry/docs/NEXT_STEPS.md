# План ближайшей реализации

Дата: 2026-07-17.
Опорные разделы мастер-плана: Этапы 0–4, раздел 18 (архитектура), раздел 24 (milestone), раздел 29 (Пакеты 1–4).

## Рамки

1. Обучение моделей в этом проекте не проводится. Допускается только inference уже существующих моделей и их валидация на имеющихся данных.
2. Дообучение, fine-tuning и любая подгонка весов на P01–P03/U01–U03 запрещены. Если обучение окажется необходимым, оно оформляется отдельной задачей и выполняется на открытых данных, а не на этих шести людях.
3. Запрет касается обучения, а не нейросетей как таковых: готовая модель, применяемая только для inference, разрешена.
4. Калибровка скалярного prior по P01–P03 под LOSO остаётся в рамках: это калибровка режима, а не обучение весов. P0V сохраняется как целевой режим мастер-плана.

Следствие: Этап 13 (гибридные и обучаемые модели) выходит за рамки; третий уровень ENVIRONMENT.md (PyTorch/MONAI, nnU-Net, registration networks, learned inspiration-to-expiration models) остаётся отключённым, кроме inference готовых моделей.

## Цель

Цель не меняется: предсказание индивидуальной анатомии максимального выдоха по КТ глубокого вдоха, по мастер-плану, вплоть до сценариев для U01–U03. Ближайшие блоки — это Gate 0–2, то есть подготовка данных, без которой не начинается ничего остального.

Отдельно и параллельно ведётся задача про толщину стенки грудной клетки (см. ниже). Она не является заменой основной цели и не сдвигает её.

## Блок A. Разблокировать окружение (Gate 0, milestone M0)

Состояние: .venv создан, но содержит только pip и setuptools; requirements.lock.txt отсутствует; пакет breathgeom не установлен; tools/bin пуст. Команды быстрого старта из README и ENVIRONMENT.md сейчас не выполняются.

1. Собрать окружение:

~~~powershell
powershell -ExecutionPolicy Bypass -File tools/bootstrap.ps1 -WithGeometry
~~~

Признак успеха: созданы requirements.lock.txt, .venv/Scripts/breathgeom.exe, pytest, ruff, mypy. При сетевой ошибке увеличить -PipTimeoutSeconds и проверить прокси.

2. Не подменять venv системным Python: в нём нет nibabel и SimpleITK, а scikit-image 0.18.1 и trimesh 4.0.5 старше границ geometry-extra.

3. Установить dcm2niix; SHA-256 сверяется с tools/toolchain.lock.yaml:

~~~powershell
powershell -ExecutionPolicy Bypass -File tools/install_dcm2niix.ps1
~~~

4. Проверить toolchain:

~~~powershell
.\.venv\Scripts\breathgeom.exe tools status
.\.venv\Scripts\breathgeom.exe project validate --config configs/paths.local.yaml
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\ruff.exe check .
.\.venv\Scripts\mypy.exe src
~~~

Ожидается: dcm2niix найден в tools/bin, gmsh 4.15.2 совпадает с lock, тесты зелёные.

5. Зафиксировать requirements.lock.txt в Git; он не входит в .gitignore.

Критерий выхода: команды README выполняются с чистого клона без обходных путей.

## Отдельная задача. Толщина стенки грудной клетки по геометрии

Статус: отдельная задача, параллельная основной линии. Не меняет цель проекта и не имеет приоритета над Gate 0–2.

Вопрос: как и насколько меняется толщина мышечного слоя грудной стенки между глубоким вдохом и максимальным выдохом.

Метод: без моделей и без отдельного сегментационного трека, грубо, по геометрии. Задача целиком опирается на маски, которые Этап 3 производит и так: body, lung_left, lung_right, skeleton_all. Мышечная метка в configs/labels.yaml не заводится.

1. Слой определяется как область между наружной поверхностью body и поверхностью лёгкого, за вычетом скелета.
2. Толщина считается через distance transform внутри слоя либо как расстояние от наружной поверхности body до поверхности лёгкого вдоль внутренней нормали.
3. Считается на вдохе и на выдохе для P01–P03 после жёсткого совмещения по скелету (Этап 5), иначе разница фаз смешивается с разницей позы.
4. Агрегация по зонам, а не по точкам: рёберные уровни, передняя, боковая и задняя стенка, левая и правая стороны.
5. Результат: по каждому человеку и зоне толщина на вдохе, толщина на выдохе, абсолютное и относительное изменение, разброс внутри зоны.

Что этот метод честно измеряет: чисто геометрически получается толщина всей мягкотканной стенки — мышца вместе с подкожным жиром и кожей, — а не мышечный слой отдельно. Для грубой оценки этого достаточно, но в отчёте величина называется своим именем. Если понадобится отделить мышцу от жира, минимальным добавлением будет HU-порог мышечного окна внутри уже построенного слоя; это порог, а не модель, и он применим только к сериям без контраста.

Ограничения результата:

- $n=3$, это описательное измерение на трёх людях, а не популяционный факт;
- максимальный выдох форсирован, поэтому разница отражает одновременно сокращение мышц и геометрическое сжатие слоя; разделить вклады без функциональных измерений нельзя, и литературный обзор уже отмечает, что форсированный выдох не является масштабированной версией спокойного;
- 4DCT нет, поэтому точечное соответствие между фазами не заявляется, сравниваются зоны;
- задержка дыхания допускает двигательные артефакты, локально имитирующие изменение толщины;
- метод грубый по построению, и результат имеет смысл только если изменение заметно превышает разброс внутри зоны.

Зависимости: тонкая реконструкция 0,5 мм из Блока B, маски Этапа 3, совмещение Этапа 5. Отдельной инфраструктуры не требует и реализуется как надстройка над Этапом 4.

## Порядок и зависимости

A → B → C, далее основная линия мастер-плана. Блок A блокирует всё. Блок C начинается после Gate 1, поскольку конвертировать имеет смысл только отобранные серии. Задача про толщину стенки подключается после Этапа 3 и не конкурирует с Gate 0–2 за очередь.
