# tools — автоматика исследовательской отчётности

Инструменты, обслуживающие регламент из [ПРАВИЛА_ОПИСАНИЯ_РАСЧЁТОВ.md](../Colab%20Notebooks/ПРАВИЛА_ОПИСАНИЯ_РАСЧЁТОВ.md): проверка первичных записей, сборка производных историй, экспорт ноутбуков в HTML и публикация в архивное зеркало.

| Файл | Назначение |
|---|---|
| `research_report.py` | Основной инструмент: `validate`, `build`, `export-html`, `sync`, `update` |
| `install_research_reporting_task.ps1` | Установка задачи Windows, запускающей `update` каждые 15 минут |
| `tests/test_research_report_transactions.py` | Тесты транзакционного отката и восстановления при публикации |

## Команды

Запускать из каталога `Калмыков`:

```powershell
python tools/research_report.py validate
```

```powershell
python tools/research_report.py update
```

`update` последовательно проверяет записи, строит отчёты, экспортирует сохранённые ноутбуки в HTML и публикует Markdown/HTML в зеркало. Публикация по умолчанию разрешена только при чистой рабочей копии Git, привязана к постоянному `project_id` и ветке `publish_branch` — это не позволяет другой копии проекта, другой ветке или `detached HEAD` занять то же зеркало.

Тесты:

```powershell
python -m unittest discover -s tools/tests -p "test_*.py" -v
```

## Конфигурация

Все пути и режимы заданы в [`research-report.json`](../research-report.json): корень записей `research/`, каталог производных `research/generated/`, корни ноутбуков для экспорта, архивное зеркало на `Z:` и маркировка конфиденциальности. Диск `Z:` должен быть подключён в сеансе того же пользователя, от которого работает задача по расписанию.

Первичные записи и их типы описаны в [research/README.md](../research/README.md).
