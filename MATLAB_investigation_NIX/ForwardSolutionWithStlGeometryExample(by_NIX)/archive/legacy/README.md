# Legacy Scripts

This folder keeps early experiments and historical helpers that are not needed
for the current STL impedance workflow.

Current main entry point:

```matlab
run_stl_impedance_calculation
```

Current matched-anatomy resolution workflow:

```matlab
run_all_anatomy_resolution_sweep
generate_all_anatomy_resolution_report
```

Files archived here include the older single-surface Netgen prototype, smoke
tests, early YAROSLAV wrappers, Netgen options, and exploratory mesh-size/body
summary scripts.
