# COMSOL_investigation_NIX — исторические пробы COMSOL

> **Статус на 23.08.2026:** COMSOL-файлы были пробами и теперь сохраняются как
> история. Папка не является активной или валидированной FEM-веткой
> диссертации.

Материалы фиксируют эксперименты с импортированной геометрией, вариантами
электродов, COMSOL Java API, однородными моделями и диагностикой базового
импеданса. Численные значения и интерпретации относятся к конкретному
историческому этапу и не должны использоваться как текущий научный результат.

## Что сохранилось

- `java/` — runner- и probe-файлы для COMSOL 6.0;
- `matlab/` — черновик LiveLink, численно не верифицированный;
- `homogeneous_electrode_study/` — бинарные MPH-снимки, CSV и PNG нескольких
  электродных сценариев;
- `visualization/` — диагностические изображения геометрии, материалов и
  физики;
- `RUNBOOK_COMSOL_6_0.md` — машинозависимые команды исторической установки.

## Что не восстановлено в Git

README прежнего этапа ссылался на STEP-геометрию, основные модели, результаты,
логи и сводный CSV. Эти каталоги и файлы в отслеживаемом состоянии отсутствуют.
Runner-файлы также жёстко привязаны к `C:\tmp` и локальной установке COMSOL.

Нет единого manifest, связывающего ручную Inobitec-сегментацию, конкретную
анатомию, экспериментальный монтаж электродов, физиологическую запись,
параметры модели и QC. Поэтому папка не воспроизводит сквозной расчёт.

## Правила хранения

- не возобновлять расчёты на реальных данных без новой отдельной задачи;
- не считать сохранённые MPH, CSV, PNG или старые числа подтверждёнными
  результатами;
- не переносить код в TRKG4 автоматически;
- возможное повторное использование начинать с минимального фрагмента,
  синтетической геометрии, зафиксированной версии COMSOL, единиц и QC;
- перед внешней публикацией проверить субъектно-связанные производные значения
  и права на исходную геометрию.
