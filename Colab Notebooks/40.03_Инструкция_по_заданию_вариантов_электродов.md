# 40.03. Как задать несколько расстановок электродов ТТРКГ

Инструкция относится к интерфейсу [расстановки электродов](../MATLAB_TRKG4_real_subjects/output/nik_surface_landmark_picker.html) на поверхности модели Nix. Она дополняет [ноутбук о поверхностных координатах](40.03_Поверхностные_координаты_электродов_ТТРКГ.ipynb). Дата уточнения рабочего порядка — 10.09.2026.

**Один вариант — одна полная расстановка четырёх электродов — один JSON-файл.** Для сравнения пяти вариантов нужно сохранить пять файлов. В каждом будут свои четыре центра. В обычной постановке каждый вариант рассчитывается отдельно; сохранение пяти файлов не означает одновременного присутствия двадцати электродов на теле.

## Что обозначают четыре точки

| Кнопка в HTML | Имя в JSON | Назначение |
|---|---|---|
| I+ | I_plus | Токовый электрод положительной стороны |
| V+ | V_plus | Измерительный электрод положительной стороны |
| V− | V_minus | Измерительный электрод отрицательной стороны |
| I− | I_minus | Токовый электрод отрицательной стороны |

Знаки задают роли электродов. Передаточный импеданс определяется по разности потенциалов V+ и V− при токе между I+ и I−. Назначение ролей сохраняется в файле и должно сохраняться при подготовке расчёта.

В интерфейс встроена конкретная индивидуальная поверхность. Координаты другого испытуемого нельзя задавать на этой модели и затем переносить на его сетку без отдельного геометрического преобразования и проверки.

## Первый вариант: четыре точки

1. Откройте HTML в браузере и выберите режим **«Четыре точки»**.
2. Поверните модель мышью; колёсиком измените масштаб. Для выбора центра используйте одиночный щелчок по наружной поверхности. Перетаскивание мышью служит для вращения модели.
3. Нажмите **I+** и выберите его центр. Аналогично задайте **V+**, **V−** и **I−**. После щелчка интерфейс выбирает следующую незаполненную роль; при необходимости нужную кнопку можно выбрать вручную.
4. Проверьте четыре маркера и список **«Центры электродов»**. Координаты показаны в миллиметрах. Для исправления выберите кнопку соответствующего электрода и щёлкните в новом месте.
5. В поле **«Имя варианта (без .json)»** укажите `ttrkg_001`. Допускаются строчные латинские буквы, цифры, подчёркивание и дефис; первый символ — буква. Пробелы и расширение вводить не нужно.
6. Нажмите **«Скачать JSON»**. Убедитесь, что браузер сохранил `ttrkg_001.json`. Если браузер спрашивает папку, выберите папку вашей серии.

Слои сердца, лёгких и скелета помогают ориентироваться. Для уверенного выбора наружной точки используйте кнопку **«Наружная поверхность»**. Нажатие на внутренний орган не задаёт поверхностный электрод.

Кнопка скачивания становится доступной после задания четырёх центров. Это проверка заполнения формы; она ещё не подтверждает допустимость контактных площадок на расчётной сетке.

## Второй и последующие варианты

Если требуется изменить один электрод, **не очищайте всю расстановку**:

1. Выберите кнопку изменяемого электрода, например V+.
2. Щёлкните в его новом положении. Остальные три центра сохранятся.
3. Измените имя на `ttrkg_002`.
4. Скачайте файл и проверьте его наличие.

Повторите эти действия с именами `ttrkg_003`, `ttrkg_004` и далее. Если требуется полностью новая расстановка, нажмите **«Очистить четыре точки»**, затем задайте все четыре центра заново.

**Каждый JSON содержит полный вариант, а не только изменение относительно предыдущего.** Поэтому второй вариант можно рассчитывать независимо от первого.

Не используйте одно имя для разных вариантов: браузер может добавить суффикс вроде `(1)` или предложить перезапись. Перед передачей расчётной серии приведите имена к однозначному виду. Для исправленной версии удобно использовать имя `ttrkg_002_v2`; в список расчёта включите именно выбранную редакцию.

Перезагрузка или закрытие страницы удаляет текущую несохранённую расстановку. Скачанные файлы сохраняются на диске, но **импорт JSON обратно в этот HTML пока не реализован**. Поэтому последовательные небольшие изменения удобнее выполнить за один сеанс, скачивая каждый завершённый вариант.

## Варианты с равными расстояниями вдоль двух путей

Режим **«Симметричные пути»** удобен, если нужно сравнить несколько значений расстояний:

1. Выберите этот режим и сторону **I+/V+**.
2. Начните путь с выбранного анатомического ориентира и задайте не менее двух точек в направлении внешнего токового электрода.
3. Выберите сторону **I−/V−** и независимо задайте второй путь от соответствующего ориентира.
4. Введите расстояние **от опорной точки до внутреннего электрода** и расстояние **от внутреннего до внешнего электрода**, в миллиметрах.
5. Нажмите **«Расставить симметрично»**, проверьте четыре центра, укажите имя и скачайте JSON.
6. Для следующего варианта измените расстояния, **снова нажмите «Расставить симметрично»** и скачайте результат под новым именем.

Каждый путь должен быть достаточно длинным для суммы двух расстояний. Направляющие сохраняются вместе с параметрами. Симметрия здесь означает равенство заданных расстояний вдоль двух путей, а не зеркальное отражение координат или доказанную анатомическую симметрию. Окончательные пути и центры вычисляются на расчётной поверхности.

Числа 20, 40, 80 или 100 мм из прежних расчётов не являются обязательными настройками для новой расстановки. Пользователь задаёт нужные расстояния явно.

## Что передать для включения в расчётную серию

Соберите выбранные JSON в одну папку. Рекомендуемое место внутри расчётного проекта:

```text
MATLAB_TRKG4_real_subjects/
  output/exploratory/user_surface_montages/
    ttrkg_001.json
    ttrkg_002.json
    ttrkg_003.json
```

Это рекомендуемая папка входов, **она не является автоматически обрабатываемой очередью**. Можно использовать другую локальную папку, указав её путь.

Сообщите путь к папке, точный список включаемых вариантов и смысл различий. Например:

| Файл | Что меняется | Участвует в серии |
|---|---|---|
| ttrkg_001.json | Исходная расстановка | Да |
| ttrkg_002.json | Изменено положение V+ | Да |
| ttrkg_003.json | Изменено положение обоих измерительных электродов | Да |

Это пример описания, а не уже созданные пользовательские расстановки.

Отдельно задайте **форму и размер каждого контакта**: для диска — диаметр; для манжеты — ширину и правило охвата/ориентации. Если параметры одинаковы у всех вариантов, достаточно указать их один раз. Если контактное сопротивление известно, укажите значение, единицы и происхождение; если оно неизвестно, его расчётное значение или сценарии должны быть отдельно зафиксированы как допущение.

HTML сохраняет **центры**, поэтому размер показанного маркера не означает физический диаметр электрода. Имена файлов также не задают контактную геометрию. Произвольный щелчок на поверхности не определяет ось манжеты или поперечную плоскость внутри конечности. Смешанный вариант с наружными токовыми плоскостями и внутренними измерительными манжетами требует своей явной геометрической спецификации.

Для воспроизводимого сравнения положений обычно сохраняют общими форму, размер и контактные параметры, изменяя только координаты. Если меняются и они, это должно быть отражено в описании варианта.

## Как сохранённые варианты попадут в вычисления

Дальнейшая подготовка выполняется расчётным кодом. Пользователю не нужно вручную править массивы XYZ или матрицы EIDORS.

| Этап | Что должно быть получено |
|---|---|
| 1. Регистрация входов | Явный список выбранных JSON, уникальные имена вариантов, контрольные суммы файлов и связь с исходной поверхностью |
| 2. Проверка координат | Чтение через `trkg4_load_surface_landmarks`; повторная проекция свободных центров или вычисление центров по поверхностным путям |
| 3. Построение контактов | Модель EIDORS с заданной формой и размером каждой площадки; запрошенные и фактические координаты, смещения при проекции, площади и отсутствие пересечений |
| 4. Подготовка расчётного входа | Экспорт через `trkg4_export_sensitivity_model`; отдельная запись каждого варианта в `montages` контракта исследования |
| 5. Контроль включения | Список монтажей в расчётном входе точно соответствует выбранному списку; ни один вариант не пропущен и не заменён автоматически |
| 6. Расчёт и сравнение | Общие литературные диапазоны ρ, единая частота и правила проверки точности; результаты с идентификатором каждого варианта |

Контактная матрица должна соответствовать конкретной объёмной сетке. Если для нового контакта нужна новая сетка, нельзя просто перенести матрицу в прежний расчёт: подготовка и геометрические проверки выполняются заново.

На текущем этапе чувствительность относится к **одновременному равномерному изменению ρ целого компартмента** при фиксированной геометрии. Изменение координат электродов задаёт другой монтаж. Локальные тканевые пробы, движение эквивалентной сердцу сферы и изменения её радиуса в эту постановку не включаются.

**Текущий статус реализации.** Сохранение отдельных вариантов, загрузчик координат и расчётное ядро для нескольких подготовленных монтажей существуют. Сквозной автоматический пакетный переход «папка пользовательских JSON → построенные контакты → готовый список монтажей» пока не реализован. Поэтому наличие файла означает «координаты сохранены», а участие в расчёте подтверждается только после подготовки модели, проверки списка входов и появления завершённых результатов этого варианта.

Сейчас пользователь может подготовить все варианты по этой инструкции. Их геометрия станет конкретным входом для следующего этапа подключения к EIDORS. Текущий расчёт сгущения сетки по ρ для прежних сборок от этого не изменяется.
