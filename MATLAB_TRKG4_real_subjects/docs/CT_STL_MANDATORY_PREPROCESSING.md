# Обязательная предобработка CT/STL для модели TRKG4

Эта процедура обязательна для каждого испытуемого и каждой новой
CT-сегментации до запуска EIDORS.

## Физический смысл

STL не хранит «вещество внутри»: он хранит только треугольную границу.
Замкнутая ориентированная поверхность определяет твердотельный объём, который
затем заполняется тетраэдрами FEM.

`rho_lungs` в этой модели является эффективным сопротивлением всего лёгочного
объёма — ткань плюс содержащийся воздух. Поэтому внутренние бронхи не должны
образовывать отдельную материальную границу. После объединения с тем же
материалом они закономерно не видны на внешней поверхности. Наружная трахея и
части дыхательных путей за пределами паренхимы должны оставаться в геометрии.

Если бронхи должны отображаться или иметь другую проводимость, для них нужна
отдельная CT-сегментация `airways.stl`. Операция заполнения не может восстановить
анатомию, отсутствующую во входных данных.

## Допустимый исходник

Для Nik выбран:

```text
data/nik/stl/lungs_ct_full_clean.stl
```

Это локальная копия:

```text
Z:/02 Big_data/3D/NIX/CT_10_12_25_RNCH_NIX_STL/NIX_CT_lungs_clear_smooth.stl
```

Поверхность замкнута, manifold, содержит трахею и имеет `z_max = 19.49 мм`.
Ранний `data/nik/stl/lungs.stl` имеет `z_max = 6.84 мм`: трахея в нём уже
обрезана, поэтому он запрещён как источник новой версии.

Контрольная растеризация `lungs_ct_full_clean.stl` с шагом 1 мм дала
`4 242 435` внутренних вокселей до `binary_fill_holes` и `4 242 434` после
удаления мелких компонент — разница всего 1 воксель. Следовательно, этот
clean-исходник уже задаёт заполненный объём; дополнительное грубое
«раздувание» поверхности не требуется.

`NIX_Lung_Raw.stl` используется только как визуальный референс: в нём 1091
компонента и 1532 незамкнутых/non-manifold ребра.

## Обязательная последовательность

1. Скопировать исходный CT/STL без изменений и присвоить ему отдельное имя
   `*_ct_full_clean.stl` или `*_raw.stl`. Никогда не затирать исходник.
2. Проверить общую систему координат, миллиметры и взаимное положение
   `body/lungs/heart/bones`.
3. Проверить STL: число компонент, boundary/non-manifold edges, signed volume,
   bounds. Для рабочей маски boundary и non-manifold edges должны быть равны 0.
4. Построить бинарную объёмную маску с шагом не крупнее 1 мм. Заполнить только
   замкнутые внутренние полости (`binary_fill_holes`). Морфологическое закрытие
   тоннелей допускается только локально и после анатомической проверки.
5. Не требовать genus 0 автоматически. Канал трахеобронхиального ветвления
   может давать ненулевой genus и при этом быть правильной анатомией.
6. Для ускорения EIDORS выполнить topology-preserving decimation без смещения
   наружной поверхности.
7. Построить обязательные изображения спереди, сбоку и сверху вместе с сердцем.
8. Измерить булево пересечение с сердцем и изменение объёма/поверхности.
9. Сохранить результат новой версией. Переключать MATLAB-конфигурацию только
   после визуального утверждения.

## Запрещённые операции

- разрез лёгких срединной плоскостью;
- глобальный convex hull;
- coarse voxel-remesh как единственный способ «заполнения»;
- требование genus 0 ценой удаления трахеи/бронхов;
- восстановление отсутствующей трахеи угадыванием;
- перезапись исходного CT/STL.

## Критерии приёмки текущего кандидата Nik

Файл `body_solid_v3_1mm_r10_volume_fill.stl` (текущий):

- получен из того же неизменённого `body.stl` через изотропную маску 1 мм;
- на 1-мм маске closing 8 мм сохранял 12 тоннелей (`genus 12`) и давал только
  16.12 л после заполнения; минимальный проверенный радиус 10 мм дал `genus 0`;
- closing выполняется эквивалентным Euclidean distance transform (`--closing-method edt`),
  чтобы не перебирать ядро 21×21×21 на 53 млн вокселей;
- 1 замкнутая manifold-компонента, 0 boundary и 0 non-manifold edges;
- объём STL 20.171 л;
- 77 562 вершины, 155 120 треугольников;
- медианный эквивалентный шаг поверхности 1.52 мм;
- принята Delaunay FEM-сетка `nik_body_solid_v3_1mm_local2mm_alg1.msh`:
  153 415 узлов, 721 943 тетраэдра, объём тетраэдров 20.170763 л;
- Frontal-кандидат запрещён: при формально успешном завершении он заполнял только 17.31 л.

Предыдущий файл `body_solid_v2_volume_fill.stl`:

- получен из тела с удлинёнными руками через маску 2 мм;
- минимальный радиус closing 8 мм закрывает вход дыхательной полости;
- 1 замкнутая manifold-компонента, genus 0;
- объём 20.156 л;
- 30 002 вершины, 60 000 треугольников;
- среднее отклонение наружной поверхности 0.54 мм, 95% менее 0.96 мм.

Файл `lungs_solid_v3_volume_fill.stl`:

- 1 замкнутая manifold-компонента;
- 0 boundary edges, 0 non-manifold edges;
- 60 000 вершин, 120 000 треугольников;
- объём 4.242 л;
- genus 1, соответствующий сохранённой трахеобронхиальной топологии;
- наружная трахея сохранена до `z_max = 19.49 мм`;
- объёмная проверка 1 мм подтверждает отсутствие незаполненных замкнутых
  внутренних полостей;
- упрощение не сместило вершины относительно clean-исходника;
- пересечение с `heart.stl` около `55.8 мм³ = 0.056 мл`, то есть только
  субвоксельный контакт; кроме того, сердце назначается после лёгких и имеет
  приоритет при классификации тканей.

## Инструменты

- `tools/solid_fill_stl.py` — STL → бинарная маска → fill/closing → STL;
- `tools/decimate_stl.py` — topology-preserving decimation;
- `tools/blender_analyze_stl.py` — топологическая проверка;
- `tools/blender_compare_stl.py` — отклонение поверхностей;
- `tools/blender_intersect_stl.py` — пересечение органов;
- `tools/blender_render_stl.py` — контрольные проекции.

## Интерпретация результата обратной задачи

Принятая STL/FEM-модель, ограничения её геометрической точности, фактический путь поиска,
обусловленность Якобиана и схема совместного анализа вдоха/выдоха зафиксированы отдельно в
[`INVERSE_IDENTIFIABILITY_AND_BREATHING_STATES.md`](INVERSE_IDENTIFIABILITY_AND_BREATHING_STATES.md).
Этот документ обязателен при интерпретации численных значений `rho1`, `rho2`, положения
электродов и `h`: одна численная точка оптимизатора не доказывает физическую единственность.
