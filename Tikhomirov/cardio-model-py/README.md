# cardio-model-py

Python-порт репозитория [`WolframMath-master`](../WolframMath-master)
(физические модели, поиск параметров, расчёт объёма, систола) —
радиоимпедансная кардиография (РЕО-32) совмещённая с МРТ.

> Модуль `Project/RFFI.m` (STL-починка) функционально независим от
> остального Wolfram-кода и портируется отдельно — см.
> [`../cardio-stl-repair/`](../cardio-stl-repair/).

## Статус

**В разработке (фаза 0 — инфраструктура).** Реализация ведётся по
плану, см. документацию.

- [`docs/PORT_PLAN.md`](docs/PORT_PLAN.md) — полный план переноса:

  Wolfram → Python, риски, верификация.

## Установка (когда будет готово)

```bash
pip install -e .[dev]
```

## Связь с исходным репозиторием

Исходный Wolfram-код (`WolframMath-master/`) **остаётся нетронутым** и
служит эталоном. Все правки идут только в этот пакет.
