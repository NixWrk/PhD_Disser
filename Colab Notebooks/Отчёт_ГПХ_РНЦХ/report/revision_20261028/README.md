# Согласованная редакция научного отчёта

Здесь находится читательская редакция по заданию 28.10.2026, дополненная опубликованными результатами серии из 810 расчётных состояний. [План](PLAN.md), [критический разбор](CRITICAL_REVIEW.md) и [правила авторов](AUTHORING_RULES.md) задают содержание и критерии проверки. Исходные исследовательские главы сохранены в соседней папке `../chapters/`; их научные результаты не заменяются литературной редактурой. Для актуального Word используется именно эта двенадцатиглавная редакция; соседний объединённый исследовательский текст не является её исходником.

## Состав

- `chapters/` — двенадцать содержательных глав, каждая подготовлена отдельным агентом и проверяется общей редакцией.
- `reviews/` — адресные сведения о проверке источников, исправлениях и ограничениях.
- `front_matter.md`, `conclusion.md`, `appendices.md` — общие части отчёта; их наличие и готовность фиксируются по факту.
- `figures/` — изображения, включённые в сборку, с происхождением в `build_manifest.json`.
- `tools/` — сборка Word и технические проверки; эти скрипты не выполняют исследовательские расчёты.
- `source_snapshot.json` — исторический снимок исходных глав до дополнения; `reviews/update_20261028_source_snapshot.json` — версия новых результатов и проверка их контрольных сумм. Предыдущий манифест сборки сохранён отдельно в `reviews/build_manifest_before_update_20261028.json`.

## Сборка Word

Нужны Python с `python-docx`, `lxml`, `pypdfium2`, Pandoc и установленный Microsoft Word для обновления полей и фактической отрисовки. В текущей работе используется комплектный Python среды Codex; версии и результат сборки сохраняются в сопровождающем реестре. Из корня репозитория:

```powershell
$revision = 'Colab Notebooks/Отчёт_ГПХ_РНЦХ/report/revision_20261028'
$document = "$revision/deliverables/Отчёт_ГПХ_РНЦХ_20261028_для_рецензирования.docx"
python "$revision/tools/build_word.py" --output $document --figure-cache-manifest "$revision/reviews/build_manifest_before_update_20261028.json" --annotate-unavailable-references
python "$revision/tools/audit_revision.py" --availability-manifest "$revision/build_manifest.json"
& "$revision/tools/render_word.ps1" -InputDocx $document -OutputPdf 'output/gph_report_20261028/review_update/render/report.pdf' -UpdateAndSave -EnableTrackChanges
python "$revision/tools/render_pages.py" 'output/gph_report_20261028/review_update/render/report.pdf'
```

Параметр `--pandoc` позволяет явно указать исполняемый файл. `--partial` предназначен только для промежуточной проверки оформления: частичная сборка не является итоговым отчётом. Формулы преобразуются в редактируемый OMML. Таблицы разворачиваются; внешние научные ссылки сохраняются. Доступные локальные ссылки адресуются относительно каталога DOCX; при переносе одного Word-файла без репозитория они не сохранят доступ к приложениям. Недоступные исторические материалы получают явную пометку и отдельный список в манифесте; построение без разрешающего параметра по-прежнему останавливается при таком пропуске. Кэш прежних рисунков используется только при совпадении SHA-256. После обновления оглавления документ требуется просмотреть постранично. Запись исправлений включается после формирования чистого текста и оглавления, для последующих правок автора.

Штатный renderer навыка документов проверен, но в этой Windows отсутствует LibreOffice. Поэтому используется явная замена: Microsoft Word → PDF → PNG. PDF и PNG служат контролю вёрстки; запрошенный читательский формат — Word.

## Данные и передача

Полный архив экспериментальных исходников, протоколов и сегментаций описан в исторических реестрах. В текущем окружении он недоступен и заново не собирался; его наличие и контроль целостности не заявляются как выполненные проверки этой редакции. Первичные медицинские файлы не включаются в Git. Текущее дополнение использует доступные тексты, агрегаты и проверенные кэши рисунков; новых FEM-прогонов и публикации данных не выполнялось.

Готовность научной методики и готовность документа — разные состояния. Поставляемый текст должен точно описывать достигнутые результаты и незавершённые проверки, включая переход к УО и ФВ.
