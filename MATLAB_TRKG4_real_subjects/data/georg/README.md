# Профиль Georg

Профиль `georg` предназначен для проверки переносимости расчётного контура
ТТРКГ на анатомию второго испытуемого. Этот расчёт проверяет подготовку
геометрии, размещение электродов, решение прямой задачи и теорему взаимности.
Он не используется для оценки индивидуальных электрических свойств тканей
Georg и не является экспериментальной валидацией модели.

## Исходные поверхности

Локальным источником служит каталог
`D:\Аспа\Bitrix\ЭИТЛ\02 Big_data\3D\GEORG\2026-02-11\CT\STL`.
Путь зависит от рабочей станции и передаётся командам подготовки как входной
параметр; он не зашит в MATLAB- или Python-код. Каталог Bitrix является
предпочтительной локальной копией внешнего хранилища.

В локально исключённый из Git каталог `stl/` копируются следующие файлы:

| Локальное имя | Исходная поверхность | Назначение |
| --- | --- | --- |
| `body_source_ct.stl` | `soft_tissue_e2b542ab.stl` | внешняя поверхность тела до искусственного продолжения рук |
| `lungs.stl` | `lungs_f2c22e26.stl` | единая маска лёгких |
| `heart.stl` | `heart_4aa99565.stl` | единая маска сердца без разделения миокарда и крови |
| `bones.stl` | `bones_with_scapulae_92b6af43.stl` | маска костей, включая лопатки |

Отдельная маска крови отсутствует. Область сердца в первом проверочном
расчёте получает проводимость сердечной мышцы целиком; это допущение модели.

## Производные поверхности

Исходная внешняя поверхность Georg была замкнутой, но содержала
топологические тоннели и внутренние полости. Поэтому перед искусственным
продолжением рук `tools/solid_fill_stl.py` выполняет объёмное заполнение
с шагом 1 мм и морфологическим замыканием радиусом 10 мм, оставляет одну
связную компоненту и создаёт `body_solid_ct_1mm_r10_volume_fill.stl`.
Полученная поверхность замкнута, связна и имеет характеристику Эйлера 2.

После этого `tools/add_arm_extensions.py` определяет два крайних сечения по
оси X, оценивает их центры и эквивалентные радиусы по площади, добавляет
наружные цилиндрические продолжения и выполняет булево объединение с помощью
`manifold3d`. Полученная поверхность сохраняется как
`body_with_arm_extensions.stl`. Скрипт поддерживает как два открытых контура,
так и две закрытые плоские торцевые области.

Для Georg получены раздельные радиусы продолжений 29,430 и 34,209 мм.
Длина каждого продолжения равна 180 мм, перекрытие с исходной областью &mdash;
12 мм. Радиусы вычислены по торцевым сечениям заполненной поверхности;
длина и перекрытие являются параметрами проверочной постановки и не
трактуются как индивидуальные анатомические измерения.

Скрипт `tools/prepare_arm_parameter_surface.py` строит поверхность
`body_arm_parameter_surface_1mm.stl` с шагом около 1 мм в допустимых областях
размещения электродов. Эта поверхность служит непосредственным входом для
новой сетки Georg и не заменяется сеткой Nix. Она прошла геометрический QC:
поверхность замкнута, связна, не содержит самопересечений, а относительное
изменение объёма при локальном измельчении составило
$1{,}72 \cdot 10^{-5}$.

## Параметры первого проверочного расчёта

Проводимости мягких тканей и лёгких временно перенесены из расчётного профиля
Nix. Такой перенос позволяет отделить проверку геометрии и программного контура
от задачи индивидуальной идентификации проводимостей. Сердце и кости получают
частотно-зависимые значения из базы ITIS при 50 кГц. Все численные значения и
число элементов каждого тканевого класса записываются в JSON-контракт
конкретного расчёта.

Небольшая доля вершин и центров граней лёгких и костей выходит за исходную
поверхность тела; кроме того, между некоторыми внутренними масками имеются
небольшие пересечения. Поэтому первый расчёт считается проверкой технической
переносимости. Порядок назначения пересекающихся тканевых масок и влияние этих
дефектов на импеданс требуют отдельной оценки.

Все STL, сетки, координаты электродов, MAT/CSV/JSON-результаты и HTML-отчёты
этого профиля остаются локальными и исключаются из Git. В notebook-файлы
результаты проверки Georg не копируются.

## Результат проверки переносимости

Построенная сетка содержит 958 345 узлов и 5 602 072 тетраэдра. Её объём
равен 36,4968 л. Автоматический контроль не выявил инвертированных или
вырожденных тетраэдров. Эти показатели подтверждают техническую пригодность
сетки для данного прогона, но не являются проверкой точности сегментации.

Расчёт выполнен при частоте 50 кГц для одной расстановки: внутренние электроды
удалены от границы &laquo;туловище &mdash; рука&raquo; на 20 мм, внешние
&mdash; ещё на 80 мм. Для всех четырёх моделей контакта использованы одна
сетка и одно назначение тканей.

| Область | Проводимость, См/м | Назначено тетраэдров | Основание |
| --- | ---: | ---: | --- |
| мягкие ткани | 0,211498 | 5 579 407 | значение профиля Nix, перенесённое для технической проверки |
| лёгкие | 0,057449 | 16 716 | значение профиля Nix, перенесённое для технической проверки |
| сердце целиком | 0,195435 | 1 725 | проводимость сердечной мышцы из ITIS |
| кортикальная кость | 0,020642 | 4 224 | значение из ITIS |
| кровь | 0,700801 | 0 | маска отсутствует, отдельная область не назначена |

Пересекающиеся маски назначаются последовательно: лёгкие, сердце, кости,
кровь. Более поздняя доступная маска заменяет класс, назначенный ранее.
Отсутствующая маска крови ничего не заменяет. Следовательно, строка крови
в контракте фиксирует только доступное справочное значение проводимости,
а не реально смоделированный компартмент.

| Модель контакта | Передаточный импеданс, Ом | Отличие по модулю от диска |
| --- | ---: | ---: |
| поверхностный диск диаметром 5 мм | 166,638 | 0 % |
| кольцо шириной 5 мм по окружности руки | 163,658 | 1,79 % |
| широкая манжета эквивалентной площади | 155,426 | 6,73 % |
| идеализированная внутренняя плоскость сечения | 164,356 | 1,37 % |

Для правой и левой рук ширина эквивалентной манжеты составила соответственно
17,104 и 14,715 мм, поскольку их модельные радиусы различаются. Во всех
сценариях прямой и взаимный импедансы совпали с относительной ошибкой не более
$5{,}3 \cdot 10^{-16}$. Различия между типами контакта не являются
радикальными для этой геометрии, однако это вывод одного модельного прогона,
а не доказательство их общей эквивалентности.

После сохранения параметрической расстановки в локальный файл
`data/georg/electrodes/electrodes_4_arms_xyz_mm.csv` штатная точка входа
`run_trkg4_forward_subject('georg')` также завершила прямой расчёт. Для её
контактной площадки около 70,8 мм&sup2; получено значение 167,963 Ом. Это отдельная
техническая проверка: число не следует отождествлять с результатом 5-мм диска,
площадь которого в сравнительном тесте составляла около 19,6 мм&sup2;.

Автономный интерактивный отчёт находится в
[`output/georg_arm_electrode_portability_report.html`](../../output/georg_arm_electrode_portability_report.html).
