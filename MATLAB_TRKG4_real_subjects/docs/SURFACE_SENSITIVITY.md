# Поверхностные JSON → полный перебор чувствительности по ρ

Этап `40.09` использует центры из JSON `trkg4_ttrkg_surface_v3` с режимом
`explicit_points`. Каждый файл — самостоятельная сборка с четырьмя ролями:
I+, V+, V−, I−. Число файлов не фиксировано. Роли не восстанавливаются по
порядку полей, рисункам или именам файлов.

## Текущая серия TEPC

Локальная папка: `output/exploratory/tepc_preparation_20260911`.
Получены TEPC-2…TEPC-7. TEPC-1 и AEPC-5 в архиве отсутствуют.
По выбору автора все контакты — поверхностные диски диаметром 5 мм,
площадь π·2,5² мм² без поправки 0,9. Удельный контактный импеданс
1,5915494309189532e-4 Ом·м² перенесён как фиксированное допущение предыдущего
исследования. Частота 50 кГц и литературный профиль ρ сохранены для сравнения
с предыдущими сборками; статья использует 100 кГц. Это не воспроизведение
эксперимента статьи.

## Подготовка другой серии

1. Экспортировать отдельный именованный JSON каждой сборки. Архив должен
   содержать только эти файлы, без вложенных папок. Сохранить исходную
   поверхность выбора; имя и хеш связываются с расчётной моделью.
2. Запустить `tools/prepare_surface_sensitivity.py import --help` и передать
   архив, действующий study-файл с нужными объёмными блоками, профиль ρ,
   подготовленную сетку и её приёмку, identity модели, поверхность, новую
   выходную папку, диаметр и удельный контактный импеданс. Шаблон study задаёт
   только объёмную модель и разделение компартментов; прежние контакты
   не переносятся. Импорт проверяет хеши и сохраняет исходные JSON без изменений.
3. В MATLAB добавить `src` и `vendor_stl_eidors`, запустить EIDORS, восстановить
   рабочую папку проекта после его startup и вызвать:

   ```matlab
   report = trkg4_prepare_surface_sensitivity(manifest_file);
   assert(strcmp(report.status,'passed'));
   ```

   Это сборка матриц и геометрический QC, без факторизации. При отказе
   сохранить каталог контактов и выяснить причину. Нельзя просто увеличить
   допуски ради запуска. Новая геометрия сетки требует новых объёмных блоков,
   идентичности модели и приёмки; она не совместима со старыми матрицами.
4. После успешной подготовки: `tools/prepare_surface_sensitivity.py seal
   --base ПАПКА`. Создаются неизменяемый план, контрольная серия и блоки
   полного перебора. Повторная запись поверх готовых studies запрещена.

Текущий контракт компартментов рассчитан на модель Nix: мягкие ткани объединяют
блоки 0–1, сердце — 2, лёгкие — 3, кости — 4. Для другой схемы тканевых блоков
нужно расширить проверенный контракт; одного нового архива координат недостаточно.
Старый MAT этапа 40.05 хранит геометрию в мм и объёмные матрицы в СИ; новый
экспорт хранит геометрию в метрах. Подготовка должна явно различать форматы.

## Запуск готовой серии

Из корня MATLAB-проекта используется один исполнитель:

```text
python tools/run_surface_sensitivity.py --base ПАПКА --deps ПАПКА_ЗАВИСИМОСТЕЙ --check
python tools/run_surface_sensitivity.py --base ПАПКА --deps ПАПКА_ЗАВИСИМОСТЕЙ --matlab MATLAB_EXE --pilot
python tools/run_surface_sensitivity.py --base ПАПКА --deps ПАПКА_ЗАВИСИМОСТЕЙ --matlab MATLAB_EXE --full
python tools/run_surface_sensitivity.py --base ПАПКА --deps ПАПКА_ЗАВИСИМОСТЕЙ --analyze
```

`check` проверяет входы, не запускает FEM. `pilot` проверяет аналитические
производные центральными разностями двух шагов по целым компартментам;
локальных анатомических проб нет. `full` требует успешного контроля.
Каждый блок исполняется через `run_pipeline('Profile','electrode_sensitivity',...)`.
По умолчанию работа последовательная, четыре потока. Пока серия 40.08 имеет
статус running, новый тяжёлый расчёт блокируется, без автоматического ожидания.

Основная сетка: 5³ узлов + 4³ независимых центров ячеек на сборку; вложенная
сетка 3³ используется для сравнения предпочтений. Для шести сборок это
1134 состояния плюс 78 контрольных. Пересчёт всей сетки после прерывания
не требуется: завершённые блоки проверяются по study, версии кода, входным
и выходным хешам. Незавершённые попытки сохраняются с новым номером.

`analysis/summary.json` содержит решения о достаточности покрытия;
CSV — производные по ρ, показатели избирательности, парные проверки,
устойчивость предпочтений и конечные отклики между границами диапазонов.
Результат отрицательной проверки сохраняется как отрицательный; уровень 9³
не запускается автоматически. Подробная методика — в ноутбуке 40.09.

Читательский отчёт обновляется командой
`python tools/build_surface_sensitivity_report.py --base ПАПКА`.
HTML экспортируется без входного кода. Локальные медицинские координаты,
анатомические изображения, MAT, MSH и исходный архив не публикуются.

## Уточнение сетки для контактов 5 мм

Первый QC текущей серии отверг TEPC-3 и TEPC-6: фактические центры
контактов отклонились до 22,03 мм. Исходная попытка сохраняется в
`contacts_before_refinement`, её manifest — в `manifest_before_refinement.json`.

`tools/refine_surface_contact_mesh.py` делит выбранные рёбра во всех
прилежащих тетраэдрах и граничных треугольниках. Координаты старых вершин
сохраняются, новые узлы лежат в серединах рёбер, тканевые метки наследуются.
Контроль включает весь набор граней тетраэдров, совпадение наружной границы,
положительность объёмов и сохранение объёмов групп. Окрестность контакта
8 мм, целевое граничное ребро 1 мм. Это геометрический контроль, не
сходимость решения.

После успешного геометрического контроля MATLAB-функция
`trkg4_export_refined_surface_model(manifest_file, refined_mesh_file, output_directory)`
собирает новые SI-блоки с проверкой EIDORS. Команда
`tools/prepare_surface_sensitivity.py adopt-refinement --base ПАПКА` сохраняет
отвергнутую попытку и связывает manifest с новой моделью. Затем обязательны
повторный `trkg4_prepare_surface_sensitivity`, `seal` и контрольная серия.
Нельзя подставлять новые контакты к объёмным матрицам старой сетки.
