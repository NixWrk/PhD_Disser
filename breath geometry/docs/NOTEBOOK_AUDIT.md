# Аудит `01_inhale_exhale_inspection.ipynb`

Дата: 2026-07-30. Notebook выполнен для одного случая `copd1` и остаётся разведочным
инструментом. Его outputs не являются batch-результатами.

## Итоговая оценка

Notebook полезен как визуальный QC и как хроника обнаруженных ошибок. Он не должен быть
основным местом реализации количественного анализа. После исправления библиотечного кода
часть сохранённых outputs устарела и должна быть очищена или пересчитана только после
прохождения новых gate.

| Раздел | Статус | Что оставить / изменить |
|---|---|---|
| Загрузка DIR-Lab и orientation report | оставить | Перенести выбор case/path в конфиг, добавить batch manifest |
| Проверка осей по телу и позвоночнику | оставить как обязательный QC | Автоматизировать asymmetric orientation checks |
| Профили площади тела/лёгких | оставить | Использовать как phase/coverage QC, не как регистрацию |
| Компоненты маски лёгких | оставить | Вынести построение маски в библиотеку и сохранять QC |
| Жёсткое совмещение | заблокировано | `copd1` Dice 0.507 < 0.70; downstream локальные сравнения невалидны |
| Наложение контуров | оставить | Показывать до/после и фиксированные анатомические уровни |
| 3D поверхности | оставить для QC | Не интерпретировать визуальную похожесть как точность |
| Радиальная карта | исследовательская | Лучи из центра и касательные траектории не являются соответствиями |
| 300 landmarks | критически важный gate | Исправлен порядок Euler; нужен deformable TRE и per-region отчёт |
| HU-компартменты в фиксированном z-поясе | не использовать количественно | Пояс не материальный; органы входят/выходят при дыхании |
| Проверка «сохранения объёма» | удалить как доказательство | В фиксированном поясе объём ткани не обязан сохраняться |
| `measure_layers` по секторам | отозвано | Ранее около половины ходов не доходили до ребра; теперь код их отбрасывает |
| Карта толщины на поверхности | отозвано | Это интерполяция независимых sector medians, не DVF и не соответствия |
| Финальные физиологические выводы | заменить | Notebook должен завершаться таблицей QC/gate, а не утверждением об эффекте |

## Конкретные проблемы реализации

1. `DIRLAB_ROOT` и `CASE` заданы внутри notebook.
2. Результат существует только для одного распакованного случая.
3. Функции `profiles`, `contours`, `radial_map` и построение компартментов определены в
   ячейках и не покрыты тестами.
4. Один диапазон `shared[0]..shared[-1]` связывается с лёгким, а не с ребром или электродами.
5. Угловая система кода и подписи на полярных графиках не совпадают.
6. 2D-нормали игнорируют наклон поверхности по z.
7. Сравнение sector medians использует разные точки поверхности в двух фазах.
8. До deformable registration все локальные карты смешивают движение и несоответствие.

## Новая роль notebook

Notebook должен стать тонким отчётом над batch-артефактом одного запуска:

1. прочитать manifest и результаты выбранного case;
2. показать orientation/coverage QC;
3. показать rigid и deformable registration QC;
4. показать landmarks и gate verdict;
5. только при пройденном gate показать профили/поля;
6. явно отделить observation от inference;
7. сохранить лёгкие статические PNG/SVG, а интерактивный HTML — вне Git.

До реализации batch-конвейера текущий notebook сохраняется как исторический прототип и не
перезапускается для получения новых научных чисел.
