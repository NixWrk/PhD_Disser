## Дыхание

В каждом из 9 исследований ровно **два задержанных дыхания**, разнесённых на 160–390 секунд, и **в обоих есть тонкая реконструкция 0,5 мм**. Это подтверждает наличие вдоха и выдоха у каждого человека.

Признак фазы в manifest — `acquisition_index` (0 или 1) и `acquisition_offset_s`. Абсолютное время съёмки не экспортируется: дата, привязанная к человеку, считается идентифицирующей.

Проценты в описаниях серий (`SEGMENT 0%…95%`) — фазы сердечного цикла R-R, а не дыхания. Серии `CARDIAC_PHASE` представляют один объём в 13–20 сердечных фазах, поэтому у них много кадров при малом числе уникальных позиций.

Какое из двух сканирований является вдохом, по заголовкам не определяется. Объективный признак — воздушный объём лёгких: больший объём соответствует вдоху. Это назначение выполняется после конвертации.

## Геометрия

Геометрия лежит не в верхнеуровневых тегах, а в функциональных группах:

~~~text
SharedFunctionalGroupsSequence → PixelMeasuresSequence      (spacing, thickness)
PerFrameFunctionalGroupsSequence → PlanePositionSequence    (позиция кадра)
PerFrameFunctionalGroupsSequence → PlaneOrientationSequence (ориентация)
~~~

Верхнеуровневые `ImagePositionPatient` и `ImageOrientationPatient` пустые. Scanner берёт позиции по кадрам, проецирует их на нормаль среза и сортирует физически, не по имени файла и не по `InstanceNumber`.

Реконструкция перекрывающаяся: **срезы 0,5 мм идут с шагом 0,25 мм**, толстые 5,0 мм — с шагом 2,5 мм. Брать межсрезовый шаг из `SliceThickness` здесь неверно, он вдвое больше фактического.

## Ограничение: цилиндрический кроп

Диаметр реконструкции 198,8–290,6 мм, центр — изоцентр пациента (`DataCollectionCenterPatient = [0, 0, z]`), а не сердце. Проверка на пикселях: во всех просмотренных срезах ткань упирается в границу круглого поля, в среднем срезе ткань занимает около 45 % приграничного кольца.

Разбор по угловым секторам на серии с FOV 219,7 мм (стороны определены по `axcodes` тома, ориентация LAS, а не RAS):

| Сектор | Доля обрезанных бин-срезов |
|---|---|
| Правый | 50 % |
| Задний | 46 % |
| Передний | 42 % |
| Левый | 30 % |

Следствие: обрезаны **все четыре сектора**, целого сектора не остаётся, полной окружности грудной стенки в этих данных нет. Наружная граница тела достоверна только там, где она не совпадает с окружностью FOV, поэтому валидность определяется отдельно для каждого среза и углового бина, а к результату прикладывается доля пригодной окружности. Полная окружность доступна только на открытых данных.

## Технические замечания

- пиксельные данные сжаты JPEG Lossless, pydicom без плагина их не декодирует; декодирование идёт через dcm2niix;
- `SeriesDescription` и `ProtocolName` не считаются гарантированно обезличенными и до ручной проверки не публикуются;
- SHA-256 по файлам и сериям включается флагом `--checksums` и обязателен для замороженного manifest.

## Что осталось до Gate 1

1. Создать приватную таблицу соответствия каталог → псевдоним; часть людей снята дважды в разные дни, поэтому число уникальных людей меньше девяти и определяется только этой таблицей.
2. Назначить вдох и выдох двум сканированиям по объёму лёгких.
3. Пересмотреть дизайн `configs/dataset.yaml`: деление «3 парных + 3 только-вдох» диску не соответствует, выдох есть у всех.
4. Зафиксировать правило выбора primary series и заполнить `selection_status`, `selection_reason`, `qc_status`.
5. Прогнать scan с `--checksums` и заморозить manifest.
6. Сделать image QC report без персональных overlay.
