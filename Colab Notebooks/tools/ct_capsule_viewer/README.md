# Просмотрщик КТ-поверхностей и координат капсул

`build.py` создаёт локальную стартовую страницу и три автономные HTML-страницы
для Ника, Георга и Ярослава. Исходные STL передаются как аргументы; в коде нет
машинных путей. Генератор сохраняет все грани STL без упрощения. Выходной
каталог с поверхностями медицинских данных должен оставаться локальным.

```powershell
python build.py --nix "<путь-к-NIX_CT_body_clear_smooth.stl>" `
  --georg "<путь-к-GEORG_SOFT_SOLID.stl>" `
  --yaroslav "<путь-к-YAROSLAV_SOFT_SOLID.stl>" `
  --out "<локальный-каталог-вывода>"
```

Для Ника использовать `NIX_CT_body_clear_smooth.stl` по решению автора.
Поверхность отличается от прежней `NIX_SOFT_SOLID.stl`; разметка по старому
STL не загружается автоматически из-за проверки SHA-256 и требует повторного
выбора координат на принятой поверхности.

Откройте `index.html` из каталога вывода. На странице испытуемого введите имя
метки, при необходимости примечание, затем щёлкните по поверхности. Доступны
удаление и экспорт JSON/CSV; JSON можно вновь загрузить для продолжения.
Экспорт содержит имя и SHA-256 исходного STL. Это ручные точки **поверхности**
в исходных координатах STL. Единицы предположительно миллиметры; совпадение
с координатами DICOM и центром капсулы в объёме здесь не валидируется.

Ошибка прежнего равномерного освещения и её исправление зафиксированы в
[`DISPLAY_QC.md`](DISPLAY_QC.md). При импорте разметки, выполненной до
исправления, интерфейс показывает предупреждение о повторной проверке точек.
