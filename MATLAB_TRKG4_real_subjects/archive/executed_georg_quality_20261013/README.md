# Версии кода до усиления проверок общей модели

Здесь сохраняются побайтные копии исходников, заменённых после подготовки
повторного расчёта Георгия. Они нужны для проверки происхождения ранее
полученных результатов. Действующий код находится в `src/` и `tools/`.

Этот каталог не добавляется в MATLAB path и не является отдельным
расчётным pipeline. Контрольные суммы конкретного выполненного расчёта
записаны в его локальном плане и паспортах результатов.
