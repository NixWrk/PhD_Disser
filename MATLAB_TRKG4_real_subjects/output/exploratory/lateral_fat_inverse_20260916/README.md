# Восстановление сопротивлений в модели с жиром

Продолжение раздела 5.5 ноутбука 33.09. Используются прежняя пятикомпонентная геометрия полной статической КТ, C01 и четыре конечных контакта диаметром 5 мм. Новое положение не ищется. Входы — девять базовых экспериментальных импедансов Ника на вдохе и выдохе; их сопоставимость при последовательной регистрации сохраняется как допущение.

ρ₁ описывает оставшийся мягкотканный фон после выделения жира, костей, сердца и лёгких; ρ₂ — лёгкое; ρ₃ — объединённый подкожный и внутренний жир. Смысл нового ρ₁ отличается от сопротивления всего внелёгочного объёма прежней двухтканной модели.

## Постановки и ограничения

- Основной расчёт: общие ρ₁ и ρ₂ подбираются по всем девяти размерам отдельно для каждого дыхательного состояния при 50 и 100 кГц. Жир, кости и сердце имеют литературные свойства.
- Проверка ρ₃ при 50 кГц: его фиксируют на 75%, 100% и 125% литературного значения и повторно подбирают два параметра. Затем подбирают все три параметра в области 0,1–100 Ом·м. ±25% — заданный вычислительный сценарий, а не физиологический референсный интервал.
- Литературные интервалы используются **только после поиска**. Для оценки результата сохранены ориентиры ρ₁ = 1,377410468–10 Ом·м и ρ₂ от deflated выбранной частоты до 24,074073807 Ом·м; это не ограничения оптимизатора и не строгие индивидуальные нормы.
- По последнему решению автора численная область каждого свободного ρ: 0,1–100 Ом·м, без автоматического расширения. Если минимум остаётся на краю, конечное значение не объявляется независимо определённым.
- При 50 кГц отдельно рассчитывается профиль по ρ₂ = 0,1; 1; 5; 10; 20; 40; 60; 100 Ом·м с повторным подбором ρ₁ в области 0,1–100 Ом·м из одного старта 4 Ом·м и литературным ρ₃; глобальность этого вспомогательного минимума не доказана.
- Все основные двух- и трёхпараметрические подгонки используют одинаковые веса, два старта и аналитический якобиан по логарифмам сопротивлений. FEM/CEM решается на каждой итерации; прежняя двухтканная интерполяция не используется.
- Геометрия КТ на вдохе и контактное сопротивление неизменны. Успех оптимизатора и совпадение двух стартов не доказывают глобальной единственности или физической достоверности оценок. Граничное значение не принимается как внутренняя оценка сопротивления.
- 50 и 100 кГц обозначают расчётные сценарии с одними наблюдениями; частота прибора этим не устанавливается. Используется действительная скалярная проводимость, без анизотропии и диэлектрической составляющей.

Частотные свойства взяты из той же замороженной [IT’IS V5.0](https://itis.swiss/virtual-population/tissue-properties/downloads/database-v5-0), DOI 10.13099/VIP21000-05-0. [Дисперсионные зависимости Gabriel](https://itis.swiss/virtual-population/tissue-properties/database/dielectric-properties) определяют метод получения проводимости. Сводка [низкочастотной проводимости](https://itis.swiss/virtual-population/tissue-properties/database/low-frequency-conductivity) включает межисследовательский разброс, но не превращает выбранные ±25% в индивидуальный диапазон жира.

## Результат основных экспериментальных подгонок

При литературном жире и 50 кГц получены граничные кандидаты: вдох — ρ₁ = 4,014019, ρ₂ = 100 Ом·м, RMSE = 10,919648 Ом; выдох — ρ₁ = 3,786917, ρ₂ = 100 Ом·м, RMSE = 9,919635 Ом. Все восемь подгонок с фиксированным жиром достигают верхнего предела ρ₂. Сценарии ±25% изменяют ρ₁ примерно в пределах 5%, но совпадение граничных ρ₂ не означает отсутствия влияния жира.

При свободном ρ₃ и 50 кГц лучший из двух стартов даёт: вдох — (ρ₁, ρ₂, ρ₃) = (21,954225; 0,1; 2,056695) Ом·м и RMSE = 4,920635 Ом; выдох — (17,056814; 0,1; 2,135937) Ом·м и RMSE = 4,750291 Ом. Меньшая невязка сопровождается выходом далеко за литературные ориентиры и достижением нижнего вычислительного предела лёгкого. Эти кандидаты не принимаются как независимо установленные свойства тканей. Численная проверка интегрирования пройдена во всех десяти экспериментальных подгонках.

## Файлы и проверки

Окончательный расчёт с пределом 100 Ом·м хранится в `capped100`. Попытка автоматического расширения (`broad`) также остановлена по уточнению автора и не является итоговым расчётом. Начальный запуск с жёсткими литературными границами остановлен по уточнению автора: его файлы в корне и `limited_worker.m` сохранены только для прослеживаемости; значения на границе 24,0741 Ом·м не принимаются как восстановленные сопротивления.

- `capped100/fits.csv` — параметры, невязки, границы, зависимость от стартов и проверка интегрирования.
- `capped100/predictions.csv` — все девять прогнозов каждой подгонки, цели и остатки; `capped100/jacobian_*.csv` — три аналитических столбца чувствительности.
- `capped100/identifiability.csv` — число обусловленности и локальное усиление ошибки ρ₂ при фиксированном и свободном ρ₃ в одной точке. Эти числа не являются доверительными интервалами.
- `capped100/inverse_comparison.html` — интерактивное сопоставление подгонок с измерениями.
- `segmentation_3d.html` — полная сегментация в доступном поле КТ, наружная FEM-оболочка и точные контактные площадки всех размеров. Упрощение поверхностей применяется только к отображению. Фон показан наружной оболочкой; органы на рисунке не обрезаются границей FEM, а в электрическом расчёте используются только внутри неё.
- `capped100/profile.csv` и `capped100/rho2_profile.html` — профиль невязки по ρ₂ с заново подобранным ρ₁.
- `capped100/execution_*.json`, `*_qc.json`, индивидуальные JSON подгонок — контрольные суммы, стартовые решения, численные проверки и ограничения.

Каждая подгонка проверяется повторным прямым прогнозом на 1024 точках интегрирования относительно основного результата на 4096 точках. Условие: |ΔZ| ≤ 0,02 Ом + 0,001|Z|. Этот допуск относится к интегрированию на данной сетке, а не к ошибке прибора или параметров. Отдельно проверяются три производные центральной разностью и восстановление известной тройки 4, 12 и литературного ρ₃ в синтетической задаче без шума. Общая пространственная сходимость и независимая физическая валидация остаются незавершёнными.

## Повторение

Рабочая папка — `MATLAB_TRKG4_real_subjects`. Требуются локальные матрицы предыдущего опыта с жиром, маски и контактные данные. Исходные КТ, NIfTI, MAT и промежуточные `*.local.json` остаются локальными. В Git сохраняются код, отчёт с выходами, малые численные таблицы и контрольные суммы.

```matlab
run_pipeline('Profile','lateral_fat_inverse','State','inhale');
run_pipeline('Profile','lateral_fat_inverse','State','exhale');
addpath('src'); export_lateral_fat_contacts;
```

Два состояния можно рассчитывать отдельными процессами: они записывают разные файлы. Повторный запуск продолжает завершённые случаи только при совпадении контрольных сумм. Для новой постановки задавать новый `OutputDir`; Python-анализ и представление этой сохранённой редакции используют указанный в исходном коде каталог текущего опыта и требуют явного согласования пути при переносе.

```text
python tools/lateral_fat_3d.py
python tools/lateral_fat_inverse_analysis.py
python notebooks/build_lateral_array_design.py
python tools/verify_lateral_fat_inverse.py anatomy
python tools/verify_lateral_fat_inverse.py report
```

Обычное выполнение ноутбука читает проверенные сохранённые результаты и не запускает MATLAB. Исходные свойства жира могут быть заданы по литературе как условие расчёта; их индивидуальная точность и допустимость фиксации оцениваются отдельно от качества подгонки Z.
