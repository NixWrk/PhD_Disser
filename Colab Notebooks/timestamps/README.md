# Исторические локальные разметки

JSON-файлы этого каталога относятся к старому формату без обязательных
SHA-256, версии схемы и статуса ручного QC. Они сохранены только локально и
исключены из Git как потенциально субъектно-связанные производные данные.

Серии 11 и 33 читают только принятые sidecar из внешнего `derived_root`:
`derived/exp02/annotations/` или `derived/exp03/annotations/`. Старые файлы
имеют статус `legacy_unvalidated` и не являются каноническим входом.
