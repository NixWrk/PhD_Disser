# Профиль Yaroslav

Профиль `yaroslav` предназначен для проверки переносимости подготовки
геометрии, параметрического размещения электродов и прямого расчёта ТТРКГ на
анатомии ещё одного испытуемого. Результаты этого профиля являются результатами
математического моделирования. Они не являются экспериментальной проверкой
прибора и не позволяют оценивать функции сердца.

## Исходные поверхности

Локальным источником служит каталог
`D:\Аспа\Bitrix\ЭИТЛ\02 Big_data\3D\YAROSLAV\2026-01-28_RNCH\CT\STL`.
Для расчёта выбран единый набор поверхностей, полученный ручной сегментацией:

| Локальное имя | Исходная поверхность | Назначение |
| --- | --- | --- |
| `body_source_ct.stl` | `soft_tissue_7444d0a9.stl` | внешняя поверхность тела |
| `lungs.stl` | `lungs_2e868fc4.stl` | лёгкие |
| `bones.stl` | `bones_with_scapulae_4b98217f.stl` | кости, включая лопатки |
| `blood_source_ct.stl` | `blood_pool_7cb0a80e.stl` | исходная маска полости крови |

Маски из автоматической сегментации TotalSegmentator в этот набор не
подмешивались. В выбранном ручном наборе нет отдельно принятой маски миокарда
или сердца целиком. Поэтому сердце не образует самостоятельный компартмент:
полость крови получает проводимость крови, а окружающая её область сохраняет
фоновую проводимость мягких тканей. Это существенное ограничение модели.

Исходная маска крови содержала 42 связные компоненты и дефекты поверхности.
Скрипт `tools/extract_largest_stl.py` оставил крупнейшую замкнутую компоненту
объёмом 673,056 мл. Полученный файл `blood.stl` используется как техническая
маска полости крови; полнота её анатомического состава отдельно не
валидирована.

Все STL, сетки, координаты и результаты остаются локальными и исключаются из
Git. В notebook-файлы результаты этой проверки не копируются.

## Искусственные продолжения рук

Исходная КТ ограничивает руки краями поля сканирования. Для параметрического
размещения электродов `tools/add_arm_extensions.py` добавляет два
цилиндрических продолжения. В принятой проверочной постановке радиус каждого
цилиндра равен 75 мм, то есть диаметр равен 150 мм; длина составляет 180 мм,
а перекрытие с исходной поверхностью — 12 мм.

Диаметр 150 мм является параметром модельной геометрии, а не измеренным
диаметром рук испытуемого. Он выбран как нижняя граница, заданная для данной
проверки. Положение внутренних электродов задаётся расстоянием 20 мм от
границы «туловище — искусственная рука», а внешних — ещё на 80 мм в
дистальном направлении.

## Построение и контроль сетки

Поверхность `body_arm_parameter_surface_2mm.stl` имеет шаг около 2 мм на
искусственных руках. Объёмная сетка использует целевой шаг 1 мм в четырёх
тонких областях электродных плоскостей, 5 мм в остальном объёме искусственных
рук и 12 мм в туловище с переходной зоной 5 мм. Поэтому обозначение «1 мм»
относится только к локальным областям, а не ко всему объёму модели.

Сетка, построенная фронтальным алгоритмом Gmsh, была отклонена: при отсутствии
инвертированных элементов она сохраняла только 25,4065 л вместо 26,2685 л
замкнутой поверхности, то есть теряла около 3,3 % объёма. Основная сетка
Gmsh сохраняла объём, но содержала восемь тетраэдров объёмом не более
$10^{-6}$ мм³. Скрипт `tools/remove_degenerate_tetrahedra.py` удалил только
эти элементы и сохранил результат в совместимом с EIDORS текстовом формате
MSH 2.2.

Принятая для технического прогона сетка
`output/yaroslav_body_arm_parameter_mesh_electrode1mm_surface2mm_clean.msh`
содержит 574 939 узлов и 3 049 079 тетраэдров. Её объём равен 26,26849 л.
Автоматический контроль не обнаружил отрицательных или вырожденных элементов.
Этот контроль подтверждает пригодность сетки для расчёта, но не точность
анатомической сегментации.

## Компартменты и электрические параметры

Расчёт выполнен на всём объёме тела. Мягкие ткани задают фон, после чего по
центрам тетраэдров последовательно назначаются лёгкие, кости и полость крови.
Отсутствующая маска сердца ничего не назначает. Более поздняя доступная маска
заменяет класс, присвоенный ранее, если поверхности пересекаются.

Параметры мягких тканей и лёгких перенесены из профиля Nix только для проверки
переносимости расчётного контура. Они не являются индивидуальными оценками
Yaroslav. Проводимости костей и крови взяты из базы ITIS для частоты 50 кГц.

| Область | Проводимость, См/м | Тетраэдров | Статус |
| --- | ---: | ---: | --- |
| мягкие ткани | 0,211498 | 3 018 202 | фон; значение перенесено из профиля Nix |
| лёгкие | 0,057449 | 15 763 | маска доступна; значение перенесено из профиля Nix |
| сердце/миокард | — | 0 | отдельная принятая маска отсутствует |
| кортикальная кость | 0,020642 | 13 391 | маска доступна; значение ITIS |
| кровь | 0,700801 | 1 723 | очищенная маска доступна; значение ITIS |

## Сравнение моделей электродов

Все четыре варианта рассчитаны на одной сетке и при одном назначении тканей.
Для каждого варианта одновременно решены прямая и взаимная задачи. Ошибка
взаимности не превысила $3{,}9 \cdot 10^{-16}$, а предупреждений решателя о
плохой обусловленности на принятой сетке не зарегистрировано.

| Модель контакта | Передаточный импеданс, Ом | Отличие по модулю от диска |
| --- | ---: | ---: |
| поверхностный диск диаметром 5 мм | 244,808 | 0 % |
| кольцо шириной 5 мм по окружности руки | 226,675 | 7,41 % |
| широкая манжета эквивалентной площади | 221,977 | 9,33 % |
| идеализированная внутренняя плоскость сечения | 222,325 | 9,18 % |

При радиусе 75 мм ширина эквивалентной манжеты равна 37,5 мм. Идеальная
плоскость является внутренней численной границей нулевой номинальной толщины,
а не физически устанавливаемым электродом. Её проекция воспроизводит площадь
поперечного сечения с отклонением до 1,5 %, хотя площадь ступенчатой сеточной
поверхности больше геометрической примерно в 1,60 раза.

Различия между тремя распределёнными контактами и диском не превышают 9,33 %
в этом прогоне. Это подтверждает только отсутствие радикального расхождения на
данной модельной геометрии. Результат нельзя переносить на другие размеры рук,
анатомию, положения электродов или проводимости без отдельного расчёта.

Координаты параметрического монтажа сохранены в локальный файл
`data/yaroslav/electrodes/electrodes_4_arms_xyz_mm.csv`. После этого штатная
точка входа `run_trkg4_forward_subject('yaroslav')` завершила расчёт на той же
сетке и получила 244,942 Ом для контактных площадок площадью около
71,691 мм². Это отдельная техническая проверка. Её значение нельзя напрямую
сравнивать с результатом 5-мм диска, площадь которого равна 19,635 мм².

Автономный интерактивный отчёт находится в
`output/yaroslav_arm_electrode_portability_report.html`. Переключатель отчёта
показывает по четыре электрода выбранного типа; 16 записей в исходной таблице
соответствуют четырём отдельным сценариям, а не восьми или шестнадцати
одновременно установленным электродам.
