# История подготовки STL лёгких

Обязательная актуальная процедура описана в
[`CT_STL_MANDATORY_PREPROCESSING.md`](CT_STL_MANDATORY_PREPROCESSING.md).

## Версии

- `lungs.stl` — ранняя локальная поверхность, уже обрезанная по трахее
  (`z_max = 6.8 мм`). Не использовать как исходник новой обработки.
- `lungs_solid_v1.stl` — срединный разрез на два genus-0 тела. Трахея и бронхи
  потеряны. Оставлено только для воспроизводимости старого результата.
- `lungs_solid_v2.stl` — coarse voxel-remesh 4 мм раннего `lungs.stl`.
  Исходная обрезка трахеи сохранилась. Не использовать как финальную модель.
- `lungs_ct_full_clean.stl` — локальная неизменённая копия полного замкнутого
  CT-исходника `NIX_CT_lungs_clear_smooth.stl` с трахеей.
- `lungs_solid_v3_volume_fill.stl` — текущий кандидат: топологически безопасно
  упрощённая поверхность `lungs_ct_full_clean.stl`, определяющая заполненный
  лёгочный объём для эффективной `rho_lungs`.

Конфигурация MATLAB пока намеренно оставлена на `v1`; переключение на `v3`
делается только после явного утверждения контрольных изображений.
