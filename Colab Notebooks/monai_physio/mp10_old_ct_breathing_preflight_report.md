# Пригодность исторических КТ для проверки дыхательного прогноза лёгких

**Дата проверки:** 1 октября 2026 года. **Статус:** контроль входных данных; численная точность прогноза по историческим КТ не оценивалась.

## Вопрос и критерий

Проверялось, можно ли сопоставить прогноз готовой модели MONAI Physio с двумя КТ, снятыми при разных задержках дыхания в историческом каталоге `OLD`. Для количественной проверки нужны целые лёгкие на исходной и целевой КТ, обоснованное назначение дыхательного состояния каждой съёмке и соответствие этих состояний числовым стадиям сети. Наличие двух задержек само по себе этих условий не выполняет.

## Данные и метод

Историческая инвентаризация [Breath Geometry](../../breath%20geometry/docs/DATA_INVENTORY_STATUS.md) использована только для выбора серий. Заголовки выбранных DICOM повторно прочитаны из локальной копии на диске `D:`. Сопоставление проведено по идентификаторам исследования и серии, которые в открытый отчёт не выведены. Девять исследований представлены обезличенными псевдонимами в [машинном отчёте](mp10_old_ct_preflight_2026-10-01.json). Исходные медицинские изображения не копировались и не изменялись.

Отдельно проверены ранее сохранённые автоматические маски лёгких для 20 кадров одной исторической серии. Эти кадры относятся к **сердечному циклу одной съёмки**; обозначения `0–95 %` в их описаниях относятся к фазе сердца. Для каждой маски подсчитаны воксели лёгких на шести гранях тома. Такой контроль выявляет обрезку видимого органа, но не устанавливает его полную истинную форму.

## Результаты

На диске `D:` найдены обе тонкие КТ-серии для каждого из **девяти исследований**. Номинальный поперечный диаметр реконструкции этих серий составляет **198,75–290,63 мм**, продольный охват — **161,5–272,0 мм**. Эти числа характеризуют доступное поле изображения и не являются объёмом лёгких. В одном исследовании обнаружены два кандидата на первую тонкую реконструкцию с одинаковыми номинальными размерами; это отражено в машинном отчёте и не превращено в дополнительное дыхательное состояние.

Во всех **20 из 20** проверенных сердечных кадров автоматическая маска лёгких касается границ тома. На одной боковой грани находится **14 424–14 614** вокселей лёгкого, на противоположной — **1 252–1 356**, на нижней границе — **21 223–21 878**. Следовательно, абсолютный объём лёгких по этим маскам и его изменение между кадрами не характеризуют целые лёгкие. Штатный [скрипт подгонки готовой модели](mp10_fit_lung_to_ct.py) отклоняет маску, если она касается границы КТ; этот критерий проверенные 20 кадров не проходят.

Для остальных исторических пар пока нет принятой классификации первой и второй задержки как вдоха и выдоха и нет проверенного соответствия одной из них опорной стадии модели `g070`. Поперечный и продольный охват у разных задержек одного исследования может различаться, поэтому сравнение видимого воздушного объёма без контроля общего поля не позволяет назначить физиологические стадии. Полные маски лёгких для этих пар в данном опыте не строились. По одним заголовкам нельзя утверждать, что все девять пар обязательно обрезают лёгкие; для каждой пары это требует отдельного контроля изображений.

## Научное решение

**Численная ошибка дыхательного прогноза на `OLD` сейчас неидентифицируема.** Для уже сегментированной серии установлена обрезка лёгких, а для девяти пар не установлены дыхательные стадии входа и цели. Поэтому сеть не запускалась на этих парах ради сравнения с произвольно назначенным «выдохом»: такое число выглядело бы проверкой прогноза, хотя зависело бы от неустановленной привязки фаз. Этот результат характеризует пригодность данных для данного теста и не является ни подтверждением, ни опровержением точности самой сети.

Повторная оценка станет содержательной, если для выбранной пары будут независимо установлены состояния двух задержек, проверены общая наблюдаемая область и полнота лёгких, а соответствие стадиям сети задано до просмотра целевой КТ. Если лёгкие остаются обрезанными, допустима отдельная проверка смещения *наблюдаемого фрагмента* при заранее определённой стадии; её нельзя представлять как проверку объёма целых лёгких или как валидированную геометрию выдоха.

**Воспроизводимость:** [скрипт контроля](mp10_old_ct_preflight.py) формирует обезличенный [численный отчёт](mp10_old_ct_preflight_2026-10-01.json). В нём перечислены все выбранные серии, геометрия, прочитанная с диска `D:`, и касание границ по каждому из 20 сердечных кадров. Прогнозных поверхностей и метрик ошибки сети этот контроль не создаёт.
