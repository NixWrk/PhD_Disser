# План работы

## 1. Статическая проверка геометрии

Вход: реальные `body/lungs/heart/bones` STL испытуемого, 4 центра электродов.

Считаем:

- один прямой расчет `Z_model` для схемы TRKG;
- вклад геометрии и положения электродов в абсолютный импеданс.

## 2. Проверка электродов

Вход: 4 размеченных центра электродов на CT/STL поверхности.

Считаем:

- ближайшую поверхность для каждого центра;
- смещение фактического электродного патча от заданного центра;
- не попал ли электрод на полость, технологическую дырку или не ту часть руки.

## 3. Проверка расчетных rho для тканей

Вход: облака решений `rho_soft` и `rho_lungs`, литературные `rho_heart/rho_bone/rho_blood`.

Считаем:

- `Z_model(rho_soft, rho_lungs)` на реальной фиксированной геометрии;
- насколько результат зависит от rho при той же самой электродной постановке.

## 4. Пакетный расчет по испытуемым

Когда для каждого испытуемого заполнены `data/<subject>/...`, запускаем `run_trkg4_batch`.

Итоговые файлы пишутся в `output/`, большие данные в git не попадают.
