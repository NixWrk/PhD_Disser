# Кажущееся ρ по измерениям реокардиомонитора МГТУ

Расчёт 07.11.2026 относится к эксперименту 2: Георгий и Ник, канал BASE₂,
задержка глубокого вдоха. Он продолжает однородную постановку предыдущего
расчёта Scorpion на данных другой регистрации и другого прибора.

## Отбор и обработка

[Подготовщик](../MATLAB_TRKG4_real_subjects/tools/bmstu_apparent_resistivity.py)
сверяет исходные CSV с принятыми аннотациями `11.01` и снимком уровней
`33.06_side_arrays_exploratory.json`. Медиана BASE₂ заново вычисляется в
принятом окне задержки вдоха с отступом 0,5 с от обеих границ; конечные
временные границы включены. Допустимое отличие от снимка — 10⁻⁸ Ом.
При несовпадении хешей или непринятой разметке подготовка останавливается.

Независимый набор содержит десять размеров Георгия и девять Ника.
Номинальный размер 100 мм у Ника исключён после проверки совпадения с
90 мм по SHA-256. Аномалия канала 1 Георгия на 90/100 мм не исключает
автоматически BASE₂; полный QC этих записей остаётся ограничением.
Коэффициенты шкалы и смещения не подбираются.

## Индивидуальная геометрия и контакты

Для каждого участника используется собственная текущая КТ/FEM-геометрия.
Все области имеют одно неизвестное ρ. Для Ника известные центр C01 и угол
14° реконструированы на актуальной поверхности. Полные прежние координаты
и базис C01 недоступны; новая постановка на их основе не объявляется
побайтным воспроизведением старого монтажа. Для Георгия используются точные
сохранённые правила прежнего модельного места на его собственной КТ,
включая длину дуги сечения кожи. Равенство экспериментальных наклеек МГТУ
и Scorpion не установлено.

Для новых размеров контакты строятся заново каноническими функциями
`trkg4_local_exact_patches` и `trkg4_cem_contact_matrix`. Номинальный
диаметр — 5 мм, контактный параметр — сохранённый сценарий МГТУ из C01,
0,00015915494309189532 Ом·м². Оба параметра не измерены независимо.
Каждый расчёт содержит четыре боковых контакта. Площадки и возбуждение
ТТРКГ не моделируются; временное разделение каналов Scorpion не переносится
на реокардиомонитор МГТУ. Преобразование BASE₂ в собственный боковой
передаточный импеданс является явным рабочим допущением.

Сгущение выполняется существующим алгоритмом red/green с фиксированным
контролем качества и ограничением числа узлов. Порог mean ratio 0,01 и
предел обусловленности рёбер 10 000 не ослабляются. Сценарий ограничен
двумя уровнями; целевая длина ребра 0,5 мм задаёт отбор, но её достижение
хранится отдельно и не подменяется успехом ограниченной подготовки.
Глобальная сеточная сходимость не установлена. Проверяются исходные узлы,
положительные объёмы, замкнутая согласованная граница и сохранение объёма.

Площадки принимаются только при непересечении, соответствии индуцированным
граням, отклонении площади ≤10 %, центроида ≤0,75 мм и максимальном
удалении узла от центра ≤3,5 мм. Отказанные подготовки сохраняются отдельно.

## Однородный пересчёт и проверки

[Профиль MATLAB](../MATLAB_TRKG4_real_subjects/src/run_bmstu_apparent_resistivity.m)
использует канонический EIDORS для новой сетки. Неизменённое ядро
`trkg4_lateral_cem_response` решает полную CEM-задачу. При неизменной сетке
допустима проверенная сумма собственных единичных материальных матриц;
при изменении сетки объёмный оператор собирается заново в СИ.

\[
K(\rho)=K_0/\rho,\qquad
H(\rho)=C+\operatorname{diag}(K_0/\rho,0),\qquad
Z_{\mathrm{CEM}}(\rho_{\mathrm{каж}})=Z_{\mathrm{вдох}}.
\]

В общей области тела u — потенциал, K₀ — объёмный оператор единичной
проводимости, C — матрица конечных контактов. Контактный параметр
фиксирован и не масштабируется с ρ. Поэтому отношение к единичному
отклику используется только как начальное приближение. Метод Ньютона
по lnρ уточняет положительное ρ до невязки ≤10⁻⁵ Ом + 10⁻⁷|Zвдох|.
Это численный допуск, не оценка погрешности прибора. Контролируются
невязка системы <10⁻⁷ и взаимность <10⁻⁷ Ом.

Проверка на двух резистивных цепях с разными известными сопротивлениями
среднего участка отдельно проверяет обращение геометрического коэффициента;
она не заменяет проверку анатомии или сеточную сходимость.

## Воспроизведение

Из корня проекта:

```text
python -B MATLAB_TRKG4_real_subjects/tools/bmstu_apparent_resistivity.py data --data-root RAW --derived-root DERIVED --model-root MODELS --out NEW_RUN/inputs
python -B MATLAB_TRKG4_real_subjects/tools/bmstu_apparent_resistivity.py geometry --observations NEW_RUN/inputs/observations.local.json --subject nik --out NEW_RUN/nik --target-edge-mm 0.5 --refinement-levels 2
python -B MATLAB_TRKG4_real_subjects/tools/bmstu_apparent_resistivity.py geometry --observations NEW_RUN/inputs/observations.local.json --subject georg --out NEW_RUN/georg --target-edge-mm 0.5 --refinement-levels 2
python -B MATLAB_TRKG4_real_subjects/tools/bmstu_apparent_resistivity.py run --geometry NEW_RUN/nik/geometry.local.json --out NEW_RUN/nik_fem --matlab MATLAB_EXECUTABLE
python -B MATLAB_TRKG4_real_subjects/tools/bmstu_apparent_resistivity.py run --geometry NEW_RUN/georg/geometry.local.json --out NEW_RUN/georg_fem --matlab MATLAB_EXECUTABLE
python -B "Colab Notebooks/plot_bmstu_apparent_resistivity.py" --observations NEW_RUN/inputs/observations.local.json --geometry NEW_RUN/nik/geometry.local.json NEW_RUN/georg/geometry.local.json --results NEW_RUN/nik_fem/results.local.json NEW_RUN/georg_fem/results.local.json --out NEW_FIGURES
```

`RAW`, `DERIVED` и `MODELS` задаются локально; абсолютные медицинские пути
не встраиваются в переносимый код. Результаты и снимки исходников находятся
в локальном `output/exploratory/bmstu_apparent_20261107/`. Два графика,
таблица и пояснения сохраняются в
`Colab Notebooks/exploratory/bmstu_apparent_20261107/`.
Они являются условными результатами разработки методики.
