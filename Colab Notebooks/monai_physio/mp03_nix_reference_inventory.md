# MP-03. Независимый анатомический референс Ника для 4D-КТ

**28.09.2026. Вывод: ручная анатомия Ника есть, но принятой ручной маски фаз 00, 01 и 07 современной 4D-КТ не установлено.** Эти объекты нельзя подменять друг другом при проверке фазовой регистрации.

| Источник | Установленный факт | Применимость к 00→01/07 |
|---|---|---|
| Динамическая КТ | 12 фаз серии DICOM 307 `ALL`, каждая 512×512×256; шаг NIfTI `0,765625×0,765625×0,625` мм. Есть автоматические `whole_heart`, `blood_pool`, `myocardium` TotalSegmentator v2. | КТ и автоматические маски подходят для технического расчёта и внутреннего контроля, но не являются независимым ручным референсом. |
| Четыре версии проектов Inobitec | Read-only [`inspect_spj_embedded_dicoms.py`](../cardiac_4d_segmentation/inspect_spj_embedded_dicoms.py) нашёл в одной версии все 3072/3072 DICOM-объекта динамической серии 307 (12×256); в другой — 3899/3899 объектов серии 307 без полного однозначного разбиения на фазы. Две версии содержат по 237 объектов статической серии 303. Машинные инвентаризации сохранены только локально в `runs/nix_spj_*_inventory.json`. | Подтверждена связь **изображений** одного проекта с динамической серией. Проприетарные контуры, их классы, фазы и статус принятия не извлечены. По наличию КТ внутри SPJ нельзя объявить наличие ручных масок. |
| Исторические STL Ника | Найдены `heart_blood_pool` и `OLD heart_surface` из отдельной статической работы. После объединения дублирующих вершин STL геометрически замкнуты; объёмы около 781 и 1004 мл. | Нет подтверждённой цепочки `SPJ → серия 307 → фаза → ручной label → STL/NIfTI`. Названия не доказывают одинаковую онтологию с фазовой `whole_heart`. Объём динамической автоматической `whole_heart` фазы 00 — около 624 мл; это расхождение смешивает правила контура и снимки, не является ошибкой регистрации. |
| Поиск экспортов | В доступном каталоге Nix вне автоматических продуктов не найдено ручных NIfTI, NRRD или MHA. В проверенном внешнем 3D-корне не найдено фазовых NIfTI с признаками manual/reference/expert/annotation. | Количественная проверка по принятому ручному референсу невозможна на доступных файлах. Отсутствие экспорта не доказывает отсутствие рисунков внутри SPJ. |
| Канонический протокол [`21.05`](../cardiac_4d_segmentation/21.05_Валидация_анатомической_сегментации_сердца_4D_КТ.md) | Ручная сегментация Inobitec является каноническим источником, но для современных фаз всех трёх добровольцев принятые ручные NIfTI не установлены. Для Nix версию SPJ, фазу и семантику STL запрещено назначать по имени. | Подтверждает статус `pending_independent_anatomical_validation`. |

**Решение:** улучшение Dice/ASSD относительно отдельной автоматической фазовой маски относится к внутреннему QC. Исторический ручной STL допускается как внешний ориентир грубой анатомии/координат с указанием несовпадения серии и фазы; он **не** задаёт ошибку движения 00→01/07. Для независимой проверки нужен принятый экспорт именно из динамической серии 307 с соответствием `phase_id`, классом контура, правилами его построения, исходным проектом и хэшами. Если из-за контраста эти границы неразличимы, это следует фиксировать как отрицательный результат, а не подгонять их по автоматической маске.

доступных экспортов с признаками ручного контура не нашёл фазовых NIfTI/NRRD/MHA.

и [скрипт его построения](mp03_nix_blind_review.py) подготовлены для

исследовательский, не анатомически валидированный статус.
