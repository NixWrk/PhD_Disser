# Сохранение материалов задачи OLD

Текущие отчёты — 21.09 и 21.10 в основной папке серии. Отчёт 21.08 относится
к первой архивной реконструкции; сравнение 21.10 использует вторую.
Их последовательности и численные результаты не объединяются.

В Git сохранены канонический код основной папки, точные исторические снимки
скриптов в `results`, версии отчётов, таблицы объёмов и записи проверок.
`TASK_GIT_INVENTORY.json` перечисляет дополнительный набор этого коммита
с размерами и контрольными суммами. Предыдущие коммиты сохраняют канонические
реализации и актуальную редакцию 21.10.

Скрипты в папках результатов отражают отдельные этапы работы, включая
промежуточные исправления и подготовку локальных конфигураций. Они не образуют
последовательность команд для повторного запуска. Некоторые снимки содержат
исторические пути рабочей станции; актуальные переносимые команды находятся
в основной папке и README серии. Конфигурации, исходные КТ, плотные массивы масок,
поля деформации, окружения и журналы исполнения сохраняются локально.
Полное воспроизведение сегментации требует соответствующего локального набора.

Сохранение в Git фиксирует состояние исследования. Численные расхождения
остаются сравнением с непринятой разметкой; независимая точность TotalSegmentator
не установлена. Исторические отчёты читаются с учётом текущего вывода 21.10.
