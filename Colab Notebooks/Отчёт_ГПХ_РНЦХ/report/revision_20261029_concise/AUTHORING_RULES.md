# Правила сокращённой редакции

Источник — соседняя папка `../revision_20261029_contract`, её исходники и проверенные изображения. Ранние редакции и расчётные файлы допустимы для уточнения локаторов, но не расширять корпус и не выполнять новые расчёты. Требование автора о сильном сокращении заменяет прежнее требование расширять главы. Остальные научные ограничения сохранены.

Писать связный русский научный текст, а не телеграфный конспект. Удалять повторы, вводные клише, пересказ структуры документа и хронологию запусков. Формулы оставлять только необходимые для понимания метода, определять символы, единицы и условия. Не сокращать путём удаления существенных условий или снижения читаемости.

УО основная цель, ФВ дополнительная. Одна КТ — вход целевой постановки, 4D-КТ — референс. ЭИТ оценивает условные тканевые параметры; ТТРКГ после поправок используется для исследования сердечной динамики и УО. Сохранять неизвестное движение, пульсовой вклад мягких тканей и единого лёгочного компартмента. Сфера остаётся кандидатом. Целое сердце не равно ЛЖ и УО; ЭКГ не измеряет пространственное движение. Межсессионные записи не называть одновременными. Обработанные циклы не увеличивают число участников. Не объявлять сквозной УО валидированным.

Участники обозначаются Н, Г, Я, А. Собственный прибор — реокардиомонитор. Сохранять только уже разрешённые рисунки, без внутренних имён. Их пути находить по `../revision_20261029_contract/build_manifest.json`; в новом тексте ссылаться на уже скопированные `../figures/<hash>.png` относительно главы. Не перерисовывать и не редактировать изображения.

Главы: заголовок `# N Название`, подразделы `## N.1 Название`; формулы `\tag{N.k}`, рисунки и таблицы `N.k`. Таблицы закрытыми `<details>` с `<summary>Таблица N.k — ...</summary>`. В Word разворачиваются. Межглавные ссылки — новая нумерация 1–7, без ссылок на старые номера. Внутренние ссылки на подробности помечать названиями дополнительных материалов, чтобы основной редактор назначил окончательные номера приложений.

В конце главы `## Источники к главе N` с только использованными полными записями. Сохранить точные первичные ссылки и локаторы; не подставлять новые публикации из памяти и не выдавать отсутствующие тексты диссертаций за прочитанные. Старые номера [1] из разных глав нельзя механически смешивать: предпочитать ссылки `[автор, год; локатор](URL)` с соответствующей записью в библиографии.

До написания создать собственный реестр доказательств и переноса `reviews/NN_ledger.json`. Схема: `sources` (source_id,file,sha256), `claims` (id,text,type,status,source_id,locator,source_fragment,value,unit,boundary,destination), `section_map` (old_section,disposition,destination,reason). Статусы supported/bounded/conflicted/unsupported; для неподтверждённого сохранять именно отрицание доказанности. `value` и `unit` могут быть null. Каждый результат с числом обязан иметь исходный фрагмент и локатор. Каждый уникальный отрицательный результат/ограничение старых разделов обязан иметь назначение main/supplement; только буквальный или смысловой повтор может иметь merged_duplicate с указанием места сохранения. Не называть главу повторно проверенным первичным экспериментом: это источник редакционной переработки с прежней силой доказательств.

Разрешённые файлы исполнителя: только назначенная глава, одноимённый дополнительный материал `supplement/NN_...md`, реестр и рецензия `reviews/NN_...`. Подробный дополнительный материал содержит реальные сохранённые сведения, а не список «см. старую версию». Исходную расширенную версию не менять. Git, сборку Word, другие главы и общий план не трогать. Прочитать свою готовую главу целиком, проверить все числа и ссылки, посчитать слова. В рецензии объяснить, что исключено как повтор и что перенесено, где остаются пробелы. Не утверждать, что доказательность улучшилась от сокращения текста.

Научный workflow: `with_figures`, `section_only`; основания — существующий отчёт и его источники. Применить `scientific-evidence-workflow` и русский научный стиль. Новые внешние источники для этого редакционного этапа не искать. Word собирает основной редактор. Для рендера при необходимости используется штатный Word; bundled LibreOffice на этом Windows не найден, пользовательский LibreOffice не запускать.
