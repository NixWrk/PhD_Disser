# Требования к STL

Для каждого испытуемого нужны закрытые поверхности:

- `body.stl` - внешняя граница расчетной области;
- `lungs.stl` - легкие, можно объединенная маска;
- `heart.stl` - реальная сегментация сердца;
- `bones.stl` - кости;
- `blood.stl` - опционально.

Все STL должны:

- быть в одной системе координат;
- быть в миллиметрах или явно известной единице длины;
- не иметь самопересечений и больших дыр;
- лежать внутри `body.stl`, кроме самой внешней поверхности;
- соответствовать тому же положению тела, где размечены электроды.

Если маска не закрыта, `points_in_closed_surface` будет ошибочно классифицировать элементы. Для ремонта можно использовать исходный workflow из распакованного STL-примера: `prepare_stl_meshlab.m` и Python-скрипты подготовки поверхностей.
