Дата проверки: 28.09.2026. Область: только фазы `phase_00`, `phase_01`, `phase_07` современной 4D-КТ Georg и ручные маски сердца, пригодные для независимой оценки регистрации `00→01` и `00→07`. Локальные медицинские данные прочитаны без изменения. Пути к ним ниже даны относительно внешнего корня `3D/`, указанного в `AGENTS.md`.

## Вывод и доказательный статус

**[НЕРЕШЁННЫЙ ВОПРОС]** Принятой независимой ручной маски сердца, однозначно связанной с каждой из этих трёх фаз, в проверенных источниках **не установлено**. Прочитаны стандартные DICOM-заголовки, встроенные в два проекта Inobitec: один содержит все 3840 объектов динамической серии 309, второй — 281 объект статической серии 302. Это устанавливает связь **изображений проекта** с серией, но не раскрывает проприетарные объекты разметки, их классы и фазовую привязку. Следовательно, Dice/ASSD относительно `products_v2` — внутренний контроль автоматических масок TotalSegmentator, а не независимая анатомическая точность регистрации. По этому основанию геометрию MP-03/04 пока нельзя признать анатомически валидированной для FEM.

## Что нужно для независимой проверки, если решение о разметке изменится

1. До просмотра результатов регистрации зафиксировать объект оценки: минимум `whole_heart` на **каждой** из фаз 00, 01, 07. Если проверяются покамерные границы, разметить LA/LV/RA/RV отдельно; `heart_myocardium` и наружный контур не подменяют кровь камер. Для плохо видимой границы фиксировать `неопределённо`, а не дорисовывать её под модель.
2. На исходных КТ с закрытыми автоматическими масками и перенесённой геометрией разметчик задаёт одну версию анатомических правил: наружный контур, клапанные плоскости, отсечение сосудов, ушки, трабекулы/папиллярные мышцы и участки частичного объёма. Записываются эксперт, дата, видимость классов, доступ к прежним контурам и причины исключений. Если ослепление невозможно, обозначить референс как зависимый.
3. Сохранить неизменный исходный SPJ и отдельные бинарные NIfTI на гриде **соответствующей** фазы; в локальном манифесте связать хэши `SPJ → серия 309 → phase_id → структура/label → NIfTI`. Проверить форму массива, affine и ориентацию, единицы по DICOM/манифесту, `qform/sform`, ненулевую бинарную маску и покрытие сердца. Не подгонять affine или центр маски по ожидаемому результату.
4. Второй независимый просмотр спорных контуров и повторная разметка поднабора нужны для оценки неопределённости самого референса. Только после принятия сравнивать неподвижный контроль, rigid и Greedy на одной полной сетке по Dice, ошибке объёма, surface Dice с заранее установленным допуском, ASSD/HD95 и по локальным анатомическим зонам. Провал видимости или воспроизводимости может сделать такую проверку невозможной; это самостоятельный отрицательный результат.

До такого решения допустимы только внутренний CT/auto-mask QC на реальных фазах и отдельная проверка влияния кандидатной геометрии на FEM. Эти проверки не получают статус независимой анатомической валидации.
