# Локальные правила MATLAB/Python-моделей

- Это единственная активная папка MATLAB-моделирования проекта. Не создавать
  параллельный расчётный pipeline в другом каталоге.
- Каноническая точка входа для результатов, читаемых notebook-файлами, —
  `run_pipeline.m`. Карта стадий и артефактов находится в
  `docs/PIPELINE_FOR_NOTEBOOKS.md`.
- Активный MATLAB-код находится в `src/`, перенесённые проверенные функции — в
  `vendor_stl_eidors/`, Python-подготовка и QC геометрии — в `tools/`.
- `archive/MATLAB_investigation_NIX/` сохраняет происхождение раннего
  прототипа. Не добавлять архив на MATLAB path и не копировать его старые
  helper-файлы поверх активных версий.
- Все модели в этой папке выполняются MATLAB/EIDORS/Gmsh и Python-скриптами.
  Не приписывать существующим результатам отдельный расчёт COMSOL.
- STL, MSH, MAT, сигналы и медицинские исходные данные не коммитить. В Git
  хранить только код, обезличенные малые таблицы, документацию и безопасные
  контракты результатов. Абсолютные пути к DICOM в код не записывать; для
  локальной HU-визуализации использовать `KALMYKOV_DICOM_DIR` и
  предпочтительный корень внешних данных из корневого `AGENTS.md`.
- Перед принятием новой сетки проверять геометрию поверхности, объём,
  вырожденные/инвертированные тетраэдры, фактические положения электродов и
  теорему взаимности. Успешное завершение Gmsh само по себе не является QC.
- Для параметрического монтажа на руках принят файл
  `output/accepted_arm_parameter_mesh.msh`. Его статус подтверждается только
  отчётом `output/accepted_arm_parameter_mesh_acceptance.json`, полученным
  через `tools/verify_arm_parameter_mesh_acceptance.py`. Копии после
  `Relocate3D` отвергнуты из-за изменения границы и инвертированных элементов.
- Изменение точки входа или имени выходного файла одновременно отражать в
  `docs/PIPELINE_FOR_NOTEBOOKS.md` и в notebook-потребителе.
- Интерактивный выбор поверхностных координат предназначен для
  четырёхэлектродного монтажа ТТРКГ на любых требуемых участках внешней
  поверхности тела. Не использовать его для боковых сборок мягких тканей,
  РЕО32 или стандартной ТРКГ.
- Свободная расстановка четырёх именованных точек является основным режимом.
  Симметричный монтаж ТТРКГ является дополнительным режимом и задаётся равными
  расстояниями вдоль двух независимо размеченных поверхностных путей для сторон
  I+/V+ и I-/V-. В режиме путей не отражать координаты XYZ. Первая точка каждого пути должна
  соответствовать выбранному пользователем анатомическому ориентиру. Для
  частного монтажа на руках таким ориентиром может служить граница
  «туловище–рука». HTML-координаты центров считать предварительными; точные
  центры повторно вычислять MATLAB на расчётной поверхности.
- По запросу автора от 10.09.2026 добавлен отдельный UI-режим парного выбора:
  подсветка выбранной и ответной точек, первый щелчок — I+/I−, второй — V+/V−.
  Рабочее геометрическое допущение этого режима — отражение относительно
  настраиваемой плоскости с проекцией на противоположную наружную поверхность.
  Начальная плоскость по середине габаритов X не является анатомически
  валидированной. В расчётный JSON передаются четыре явных центра
  `explicit_points`; режим равных расстояний по путям остаётся отдельным.
- В параметрическом тесте различать четыре варианта: четыре поверхностных
  диска 5 мм; четыре кольцевые манжеты 5 мм; четыре широкие манжеты 15 мм;
  смешанный монтаж `outer_planes_inner_rings`. По уточнению автора от
  08.09.2026 в последнем варианте только наружные токовые I+/I− являются
  поперечными плоскостями внутри цилиндров рук; внутренние измерительные
  V+/V− должны оставаться поверхностными манжетами 5 мм. Старый вариант
  четырёх плоскостей `cross_section_plane` исключён из действующей
  спецификации. Исторический `cross_section_equivalent` означает широкую
  манжету и не является плоскостью.
- В исследовании чувствительности `40.05` по решению автора вся маска сердца
  представляет эффективную смесь крови и миокарда. Это допущение не задаёт
  измеренную долю крови и не разделяет проводимости крови и миокарда.
  Паспорт, входные хэши и результаты этой серии находятся отдельно в
  `output/exploratory/arm_sigma_20260908`; её широкие тканевые диапазоны
  не интерпретировать как амплитуды сердечного цикла или обычного дыхания.
- Состав и параметры конкретного расчёта брать из
  `output/nik_trkg4_arm_electrode_model_tests_contract.json`. Для Nix
  используется маска сердца целиком; отдельная маска крови отсутствует.

- Полный отчёт по боковым сборкам является этапом `20.10` и находится в
  `../Colab Notebooks/20.10_КТ_FEM_локализация_боковых_матриц_МГТУ.ipynb`.
  Генератор и вычислительное ядро остаются здесь. Старый notebook-путь содержит
  только указатель; не восстанавливать там независимо развивающуюся копию.

## Решение автора о хранении отчёта 20.10

По явному указанию автора от 10.09.2026 полные файлы
`20.10_КТ_FEM_локализация_боковых_матриц_МГТУ.ipynb` и соответствующий `.html`
в основной папке `Colab Notebooks` включаются в Git с сохранёнными выходами
и изображениями индивидуальной анатомии. Не исключать их автоматически
из коммитов и не очищать их численные выходы при обновлении документации.
Это разрешение относится к этим двум полным версиям научного отчёта;
исходные КТ/STL, записи сигналов и прочие отдельные массивы оно не включает.

## Движущаяся модель сердца: решение автора 15.09.2026

- Для геометрических изменений сердца принят неподвижный фон без сердца.
  В исходной разметке область сердца заменяется мягкими тканями; остальные
  метки, включая лёгкие и кости, сохраняются. Кости остаются отдельным
  фоновым материалом по прямому ответу автора.
- Каждый новый вариант строится заново из неизменяемого фона. Внутри текущей
  области сердечной модели материал получает свойства сердца; после выхода
  модели из участка восстанавливается именно его фоновый материал.
- Сердце имеет приоритет внутри своей области. Покрытие фоновых лёгких,
  мягких тканей или кости не является основанием отклонения варианта.
  Объём такого покрытия допустимо сохранять как описательную характеристику.
- Это допущение о назначении материалов, без механического перемещения
  окружающих органов. Под исходным сердцем не восстанавливается неизвестная
  анатомия: назначение мягких тканей остаётся явным допущением.
- Проверки внешней границы тела, единиц, систем координат, пространственной
  сходимости и численных производных сохраняются. Успех восстановления меток
  не является физической или анатомической валидацией.
- Подготовка карт: `tools/prepare_static_heart_replacement_pilot.py`.
  Она сохраняет отдельные метки и протокол, но не считает импеданс.
  При изменении меток необходимо заново собрать материальные матрицы
  действующим EIDORS-экспортёром; прежние матрицы для новой геометрии
  сердца не использовать.

## Стандарт конечных контактов — 16.09.2026

Во всех основных расчётах соблюдать [стандарт конечной площади электродов](docs/ELECTRODE_MODEL_STANDARD.md).
Новый стандартный контакт — диск диаметром 5 мм; для заданного эксперимента
или отдельного сценария сохранять явно обоснованный размер. FEM использует
CEM, а остальные методы должны учитывать и проверять конечные контакты.
Контактные матрицы и производные нельзя переносить на другой диаметр либо
другой набор физически присутствующих электродов без пересчёта.


## Совместная локализация боковых сборок — решение автора 16.09.2026

Текущая проверка последовательно восстанавливает кости, затем сердце при фиксированных C01, КТ-маске лёгкого и конечных контактах. Проверяются изменение прямого Z и ошибка восстановления сопротивлений после замены органов фоном. Выделение жира и новый поиск положения относятся к следующим этапам.

Будущий поиск положения должен совместно подбирать общие координаты и ориентацию монтажа и общую пару ρ₁, ρ₂ по вектору базовых Z всех независимо записанных размеров одного дыхательного состояния. Нельзя подменять эту постановку перебором положения при одной заранее фиксированной паре сопротивлений. Допустим вложенный поиск: для каждого положения минимизировать невязку по сопротивлениям в обоснованной области и сравнивать полученные минимумы. Отдельная пара сопротивлений под каждый скалярный Z не определяется одним измерением.

При известной индивидуальной КТ h вычисляется для каждого кандидата положения. Для вдоха и выдоха явно задавать связь геометрии и возможное постоянство ρ₁; автоматически объединять состояния нельзя. Сохранённые свойства костей и сердца считать литературными сценариями, а не дополнительными свободными параметрами без отдельной проверки идентифицируемости. Новую локализацию не объявлять независимо подтверждённой только по минимуму импедансной невязки.


## Жир в боковой модели — решение автора 16.09.2026

В прямом опыте 33.09, раздел 5.5, отдельно задаются кости, лёгкие, сердце и жир TotalSegmentator v2; оставшаяся область — мягкие ткани. Не пересчитывать положение C01 в этом опыте. Разделять эффект перехода к новым маскам и эффект присвоения жиру отдельной проводимости. Неполную маску сердечной КТ не продолжать на всю грудную клетку как нулевой жир. Для текущего полного расчёта использована статическая серия 301. Сопротивления назначены литературным сценарием и не подбираются к измерениям.
