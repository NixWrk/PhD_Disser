# Исторические сгенерированные mesh-пробы

Эти четыре малых файла перенесены из активных `data/` и `tools/`, потому что
они не вызываются единым pipeline и содержат машинозависимые пути старой
рабочей среды. Они сохраняются только для происхождения ранних попыток
построения 25-мм сетки. Не запускать их как актуальную постановку и не
добавлять в MATLAB/Gmsh path.

Актуальная сетка задаётся через `src/trkg4_config.m`, проверяется pipeline и
хранится вне Git как расчётный артефакт с QC.
