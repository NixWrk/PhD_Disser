# Исторические локальные параметры

Файлы `static.json`, `ct.json` и `systolic.json` относятся к историческому
расчёту без полного контракта калибровки, SHA-256 исходных записей, статуса
ручного QC и межзаписной неопределённости. Они сохранены только локально,
исключены из Git и имеют статус `legacy_unvalidated`.

Серии 33–60 не используют эти значения как канонический вход. Новые результаты
записываются во внешний `derived_root` после прохождения входных ворот
соответствующего ноутбука.
