# Две проверки сокращённых моделей — 20.14

Автор утвердил синтетическую и экспериментальную проверки 10.09.2026.
КТ принимается как достоверная анатомия, сопротивления испытуемого неизвестны.
Рабочие границы опираются на IT’IS V5.0 по указанию автора: мягкие ткани/мышцы
для ρ₁ и наполненное воздухом лёгкое для ρ₂. Их конкретное построение и
ограничения переноса изложены в ноутбуке 20.14; это не популяционные нормы.

Команды выполняются из корня `MATLAB_TRKG4_real_subjects`:

```text
python -X utf8 tools/geometry_validation_tests.py prepare
matlab -batch "run_pipeline('Profile','geometry_validation');"
python -X utf8 tools/geometry_validation_tests.py analyse
matlab -batch "run_pipeline('Profile','geometry_validation_cem');"
matlab -batch "run_pipeline('Profile','geometry_validation_derivative_qc');"
python -X utf8 tools/verify_geometry_validation_tests.py
python -X utf8 notebooks/build_geometry_validation_report.py
python -X utf8 notebooks/execute_geometry_validation_report.py
python -X utf8 -m pytest tests/test_geometry_validation.py tests/test_geometry_reduction.py -q
```

Подготовка создаёт неизменяемый план, 49 сочетаний сопротивлений и таблицу
девяти экспериментальных уровней вдоха. Повторная подготовка в существующей
папке запрещена. MATLAB формирует независимые синтетические импедансы,
используя готовые объёмные блоки 20.13. Эта стадия возобновляется по
завершённым сочетаниям только при совпадении плана, матриц и кода.

Анализ выполняет 392 ограниченные синтетические инверсии, восемь подгонок
измерений, 72 условных исключения размера, 144 одноканальных возмущения
±1% и проверку более узкого лёгочного диапазона. Полная электродная модель
CEM дополнительно подбирает два параметра по измерениям из трёх стартов;
эта стадия при повторном вызове выполняется заново. Её исходники не менять
во время работы. Технические ошибки решателя останавливают расчёт. Производные CEM
отдельно проверяются конечными разностями для двух крайних размеров, двух
параметров и двух шагов внутри рабочей области.

Основные входы: неизменённая библиотека `geometry_reduction_20260910`,
литературная таблица IT’IS и субъектный манифест
`data/nik/experimental/nik_breath_hold_levels.csv`. Выходы находятся в
`output/exploratory/geometry_validation_20260910`. Для другой серии нужны
согласованные новые входы и отдельная папка результатов; перенос данных
другого испытуемого в текущий фиксированный план не поддерживается.

Проверка результатов связывает входы и выходы контрольными суммами,
пересчитывает заявленные ошибки и контролирует соблюдение границ.
Ноутбук исполняет только чтение, таблицы и рисунки; HTML содержит результаты
без исходного кода. Независимая физическая валидация сопротивлений не следует
из этих технических проверок.

Сохранённая поза электродов использовала весь экспериментальный ряд.
Поэтому исключения размеров условны на эту позу; они не являются независимой
сквозной проверкой. PEM и CEM различаются электродной постановкой. Для
сокращённых FEM-масок здесь используется PEM; дополнительная CEM-инверсия
выполнена только для исходной КТ-геометрии. Реальные ошибки ρ₁ и ρ₂
неизвестны; проценты параметрической ошибки относятся к синтетическим данным.
