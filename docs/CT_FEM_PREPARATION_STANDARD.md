# Подготовка индивидуальной КТ-модели к конечноэлементным расчётам

Редакция от 26.10.2026. Этот порядок задаёт единый способ подготовки
геометрии грудной клетки и её тканевого состава. Индивидуальные данные,
электроды и области сгущения задаются конфигурацией. Геометрический контроль
не устанавливает сходимость электрического решения или точность
восстановления физиологических параметров.

Точка входа — [скрипт подготовки](../tools/prepare_ct_fem.py),
вычислительные процедуры — [модуль подготовки](../tools/ct_fem_core.py),
полный запуск описан в [конфигурации TotalSegmentator v2](../configs/ct_fem_totalsegmentator.example.json),
геометрические параметры — в [конфигурации сетки](../configs/ct_fem_preparation.example.json).
Неизменённые математические функции выполненного исследования Георгия
используются повторно. Ранее рассчитанные модели сохраняют собственные паспорта.

## Исходные данные и координаты

До геометрических операций выбирают конкретный том КТ, устанавливают его
происхождение, дату съёмки, поле зрения, пространственный шаг и дыхательное состояние.
Временное и анатомическое соответствие КТ эксперименту устанавливают отдельно;
совпадение испытуемого не доказывает неизменность размеров тела и дыхательного
состояния. Неизвестную дату или степень вдоха сохраняют как неизвестные входы.
Реконструкции кардиоцикла в одной задержке дыхания не считаются разными
дыхательными состояниями. Вход текущей версии — трёхмерный том NIfTI с
интенсивностями в единицах Хаунсфилда. Выбор и конвертация DICOM-серии
выполняются до запуска. Сегментация входит в полный запуск.

## Обязательный начальный этап: TotalSegmentator v2

### Самостоятельный результат до постановки FEM

Команда ниже завершает работу после сегментации и экспорта анатомических
поверхностей:

```text
python -B tools/segment_ct_to_stl.py --config <ct_pipeline.local.json> --out <fresh_STL_output>
```

Результат — `body.stl`, `lung.stl`, `bone.stl`, `heart.stl`, `fat.stl`
и паспорт `segmented_STL.local.json`. Все файлы происходят из собственных
масок TotalSegmentator v2 на исходной сетке выбранного КТ. Сохраняются
все компоненты и внутренние интерфейсы полостей: множество костных
фрагментов само по себе не является ошибкой экспорта. Проверяются
замкнутость, согласованность ориентации, положительный суммарный объём,
LPS/мм и максимальное смещение вершин при записи STL. Сравниваются
все соответствующие треугольники; выборочное сравнение здесь не требуется.
Исходные маски не меняются, область не обрезается, руки и электроды
на этом этапе не добавляются. Статус — автоматическая сегментация,
ожидающая анатомического просмотра. Объёмная сетка и FEM не запускаются.

### Продолжение для конкретной FEM-постановки

По прямому уточнению автора наружная STL-поверхность для нового общего
порядка должна происходить из TotalSegmentator v2. Полная цепочка:
**выбранный КТ-том → TotalSegmentator v2 → маски → STL в LPS/мм →
цилиндрические руки → подготовка поверхности → тетраэдры и контроль качества**.
Начальный этап выполняет `tools/ct_fem_ct_pipeline.py`, нейросетевой запуск —
`tools/ct_fem_totalsegmentator.py`. Автоматического перехода к HU-порогу
или ручному STL при отказе нет.

Задача `body` формирует `body_trunc` и `body_extremities`; `total` — лёгочные
доли, кости и целое сердце; `tissue_types` — подкожный и внутренний жир.
Результаты сохраняются на исходной сетке КТ. В полном запуске фиксируются
версия 2.x, параметры задач, SHA-256 КТ, классовых и объединённых масок.
Свежий запуск также сохраняет контрольные суммы использованных весов,
их метаданных и Python-исходников сегментатора. Паспорт повторно
используемой сегментации сохраняет собственную полноту происхождения;
недостающие сведения о весах не восстанавливаются предположением.
Повторное использование тканевых масок разрешено только с завершённым
паспортом TotalSegmentator v2 для того же файла КТ и совпадением всех
контрольных сумм. Маска тела при таком запуске вычисляется заново.

Расчётное тело задаётся объединением двух классов тела и, при явно
включённом `body_domain.include_TS_tissues`, четырёх тканевых масок.
Так сохраняется покрытие тканей при расхождении отдельных нейросетевых
задач. Выбирается связная область, содержащая всю исходную маску тела;
если сама маска тела распределена между несколькими компонентами, запуск
останавливается. Отделённые компоненты из тканевых классов сохраняются
диагностической маской. Исключение любого вокселя лёгкого или сердца
запрещено; суммарный объём остальных отделённых компонент ограничен
0,1% исходного тела. Для FEM создаются отдельные тканевые маски внутри
расчётной области, с числом исключённых вокселей по материалам.
Это рабочее правило вычислительной области; анатомическая причина
расхождения остаётся открытой и требует просмотра КТ.
Все исходные маски остаются неизменными. Доля добавленных вокселей
ограничена заранее заданным сценарием 0,1% объёма маски тела;
это техническое условие подготовки, не оценка анатомической погрешности.
Морфологическое замыкание и HU-сегментация на этой ветке не выполняются.
Перевод в STL использует marching cubes с уровнем 0,49 бинарной маски,
исходную матрицу RAS и смену знаков X/Y для LPS. Ошибка записи STL
контролируется отдельно, до 0,001 мм по выборочному расстоянию.

Из всех замкнутых поверхностей marching cubes выделяется наружная оболочка.
Другие компоненты допустимо считать внутренними полостями только после
проверки нахождения всех их вершин внутри наружной оболочки. Их суммарный
объём должен быть не больше 0,1% наружного объёма; исходный STL со всеми
поверхностями сохраняется отдельно. В FEM используется сплошная наружная
область. Это допущение о малых полостях, не исправление исходной маски и не
подтверждение их анатомической природы. Дополнительная поверхность снаружи,
незамкнутая компонента или превышение объёма блокирует подготовку.

Геометрия проверяется на связность, замкнутость, положительный объём
и самопересечения. Наличие ручки поверхности само по себе не исправляется
принудительным заполнением. Отказы сохраняются с исходными масками;
успех нейросети не означает анатомического принятия.

При заданном `contact_placement` контакты заново строятся на новой коже
и цилиндрах. Боковая длина откладывается по точной полилинии сечения кожи
плоскостью Y = const, а не по хорде. Для рук задаются расстояние вдоль
оси и угол на окружности. Исходные координаты сохраняются отдельно;
такая реконструкция остаётся модельной установкой, не измерением.

```text
python -B tools/prepare_ct_fem.py pipeline --config <ct_pipeline.local.json> --out <fresh_output>
```

Среда Python и каталог существующих весов указаны явно. Конфигурация
TotalSegmentator копируется только в исключённый локальный каталог;
ключ лицензии не попадает в паспорт. Статистика использования отключена,
временные медицинские файлы находятся внутри каталога запуска.
Windows nnUNet использует межпроцессные каналы: ограничение такого канала
является ошибкой исполнения, не основанием менять алгоритм сегментации.

Обязательны отдельные маски лёгких, костей, целого сердца и жира.
Для каждой указывают ручное, автоматическое или иное описанное происхождение.
Автоматическая маска не становится ручной вследствие общего описания
исследования. Пустые маски, пересечения и неполное поле зрения сохраняются
во флагах качества и рассматриваются до интерпретации расчётов.
Кровь и миокард внутри целой маски сердца здесь не разделяются.

КТ и маски должны иметь одинаковые размеры и точные матрицы преобразования
координат; пространственные единицы NIfTI — миллиметры. Автоматического
совмещения или пересчёта сетки изображения нет. Необходимые преобразования
выполняют отдельно с сохранением их параметров и проверки результата.

Геометрию сохраняют в системе LPS, в миллиметрах: положительное направление
X — влево, Y — назад, Z — вверх относительно человека. В принятой системе
NIfTI RAS первые две оси направлены вправо и вперёд; переход в LPS меняет
знаки первых двух мировых координат. Воксельные
индексы получают через обратную матрицу преобразования, а не делением
мировых координат на шаг изображения. Геометрию переводят в метры перед
сборкой электрических операторов.

## Наружный контур и цилиндрические руки

### Совместимость с самостоятельными готовыми STL

Выполненные диагностические прогоны с собственными замкнутыми STL
Inobitec сохраняют происхождение. Они не заменяют обязательную сегментацию
TotalSegmentator v2 в полном запуске.
В общей конфигурации используется `body.strategy = supplied_STL_LPS` с
`source_kind = manual_Inobitec`. Обозначение `author_STL_LPS` сохраняется
для совместимости с выполненными конфигурациями.
Обязательны путь и SHA-256 исходного STL, явные LPS/мм, происхождение,
сценарные ограничения покрытия тканей и основание этих ограничений.
КТ и четыре маски остаются индивидуальными входами на исходной сетке.

Ручной STL проверяется на замкнутость, связность, положительный объём и
самопересечения. Для контроля согласования он растеризуется в центрах
собственных вокселей КТ, без изменения исходной поверхности и масок.
Числа тканевых вокселей вне ручной области сохраняются отдельно; допустимый
остаток является условием новой вычислительной области, не погрешностью
сегментации или электрического решения. В данной исследовательской ветке
лёгкое и сердце должны покрываться полностью; для кандидатных масок кости
и жира задан рабочий предел 5%. Результат при таком условии не является
принятой анатомической моделью. У Ника фактически вне области 1,275% кости
и 2,902% жира, у Ярослава — 1,904% и 0,880%; эти различия не скрываются.

Морфологическое замыкание HU-контура к ручному STL не применяется.
Его отдельный отказ сохраняется и не переименовывается в успешный результат.
Исходный STL копируется побайтово; объединение с руками выполняет тот же
параметризованный алгоритм полного сечения, что для HU-ветки.
Далее используются общие стадии сетки, тканевых долей и CEM, с неизменными
пределами качества тетраэдров, площади контактов и электрического контроля.
Подготовку реализует `tools/ct_fem_manual_surface.py` в составе общей точки
входа. Основная последовательность — `surface → remesh → mesh`, включая
описанную ниже автоматическую коррекцию формы при необходимости.

Тот же интерфейс принимает расчётную наружную STL при явном
`source_kind = derived_CT_geometry_reference`. Это не делает поверхность
ручной сегментацией и не подтверждает её анатомическую точность. В контрольном
случае Георгия входом служит закреплённая поверхность `geometry_v5`.
Повторное выделение по HU сохраняется отдельным расчётом: его вариант с
пределом изменения контура 1,25 мм отклонён при выборочном максимуме
2,3291 мм. Проверка сетки от заданной STL не превращает этот отказ в успех
и не устанавливает точность замыкания маски относительно исходной КТ.

### Контур по интенсивности КТ

Первый этап выделяет тело по заданному порогу интенсивности. Применяемый
сценарий сохраняет крупнейшую пространственную компоненту, затем по срезам
выполняет морфологическое открытие, выбор крупнейшей компоненты и заполнение
замкнутых полостей. Пустой срез остаётся пустым. Правило ориентировано на
выбранное поле зрения грудной клетки; оно может исключить отдельные конечности
другого тома и требует просмотра относительно КТ.

Второй этап выполняет одну итерацию трёхмерного замыкания по шести соседям.
Доля изменённых вокселей не должна превышать заданный предел, максимально
0,001. Проверяют отсутствие потери ранее покрытой ткани и отдельно учитывают
воксели каждой маски вне тела. Допустимые остатки задаются явно и сохраняются
в паспорте; это не исправление сегментации. Морфологические операции заданы
в вокселях, поэтому их физический масштаб зависит от шага КТ.

Поверхность извлекают на уровне 0,49 бинарной маски. Раздельно сохраняют
контур до регуляризации и исправленную кожу. Замкнутость, связность,
положительный объём и самопересечения проверяют на экспортированном STL.
Упрощение до объединения с цилиндрами не выполняется. Коррекция контура —
ограниченный геометрический сценарий; её анатомическая точность не следует
из проверки топологии.

Два расстояния проверяют независимо: изменение исходного контура при
морфологической коррекции и отклонение экспортированного STL от поверхности
исправленной маски. Для каждого задают собственный предел и его основание.
Допуск экспорта не переносится на коррекцию анатомии. Сохраняют оба
направления выборочного расстояния и отрицательный результат даже при отказе
стадии. Если старый конфигурационный параметр не различает эти проверки,
скрипт требует явного описания пары сравниваемых поверхностей.

[Диагностический скрипт](../tools/ct_fem_body_diagnostic.py) проверяет
сохранённые маски и поверхности, локализует изменения по КТ и строит
сечения у наибольших проверенных отклонений. Он не перестраивает сетку и
не принимает исправление как анатомически подтверждённое.

Цилиндрические руки добавляют при явном принятии этого допущения.
Радиус, плоскость усечения, направление, длина, область поиска стыка и
зазор задаются для конкретного человека. Текущая версия поддерживает ось
LPS X. Радиус связан с обхватом формулой $R=C/(2\pi)$, где $C$ — обхват
в миллиметрах.

Выбирают сечение, в котором полностью помещается круг цилиндра с заданным
зазором. При необходимости стык смещают внутрь туловища. Сохраняют площадь
многоугольника, аппроксимирующего круг, площадь его пересечения с телом и долю покрытия;
всё сечение должно быть покрыто. Эта проверка относится к принятой
многоугольной аппроксимации окружности. После объединения повторяют контроль
поверхности и проверяют отсутствие выхода цилиндров за разрешённые границы
по Y и Z.

## Электроды и поверхность для объёмной сетки

Физические контакты перечисляют независимо от электрических групп.
Для каждого сохраняют исходный центр, происхождение координат,
номинальную площадь и результат проекции. Для каждой схемы отдельно
задают группы соединённых площадок и упорядоченные пары токового возбуждения
и измерения напряжения. Обращение порядка только токовой либо только
измерительной пары меняет знак передаточного импеданса. Одновременное
обращение обеих пар сохраняет его знак. Эти изменения отражаются во входах.

В каждой схеме явно перечисляют физически присутствующие контакты.
Неиспользуемый вариант из общего каталога не добавляют к границе модели.
Присутствующий контакт без подключения к одной из групп получает отдельный
плавающий потенциал и нулевой внешний ток. Это допущение о состоянии
электрода; оно требует соответствия фактическому подключению прибора.
Совпадающие центры двух альтернативных сборок допускаются только тогда,
когда эти контакты не присутствуют одновременно.

Отключение канала прибора и размыкание проводов между площадками — разные
состояния. Если несколько площадок остаются соединены, их моделируют одной
группой с общим потенциалом и нулевым внешним током, когда эта группа не
возбуждается. Разделять её на самостоятельные плавающие электроды без
подтверждения подключения нельзя. При неизвестном состоянии сравнивают
явно обозначенные сценарии, сохраняя одни и те же ткани, сетку и положения.
Меньшая невязка одного сценария не устанавливает фактическую схему опыта.

Номер канала не заменяет описание отведения. Обхват рук, число площадок,
размеры сборок, ориентация и центр не выводятся из имени испытуемого.
Приблизительный центр автора, ручная расстановка и найденное обратной задачей
положение — разные виды входов. Проекция на новую поверхность не считается
новой ручной установкой; её расстояние не является измеренной ошибкой
положения. Номера граней поверхности для расстановки нельзя напрямую
переносить в номера граней объёмной сетки.

Размер металлической площадки, площадь геля на коже и эффективная
электрическая площадь контакта фиксируются раздельно. Приближённое
воспоминание о размере не считается независимым измерением. Гель может
изменять область ввода тока; его внешний диаметр сам по себе не задаёт
эквивалентный диск CEM. Проверочный вариант площади требует собственных
контактных матриц, контроля отпечатка и проверки сгущения сетки.

Перед генерацией объёмной сетки поверхность подготавливают при контроле
геометрического изменения. Размеры рёбер и зоны уточнения задаются
конфигурацией, по всем нужным контактам и направляющим. Проверяют двусторонние
выборочные расстояния, объём, положение контактов, замкнутость и
самопересечения экспортированного результата. Выборочный максимум расстояния
не является доказанной глобальной границей геометрической ошибки.

Параметр MeshLab `per_operation_distance_mm = 0.2` ограничивает локальные
операции фильтра. Он не задаёт максимальное изменение всей поверхности после
шести итераций. Для сравнения соседних экспортированных стадий отдельно
задают `maximum_stage_sampled_distance_mm`; в примере он равен 0,75 мм.
Итоговое сравнение с исходной наружной областью также ограничено 0,75 мм,
относительное изменение объёма — 0,003. Это разные проверки. Их результаты
сохраняют до отказа стадии. Допуски не повышают после неудачного расчёта.
Описание локального параметра приведено в
[документации PyMeshLab](https://pymeshlab.readthedocs.io/en/latest/filter_list.html#meshing-isotropic-explicit-remeshing).

Объединение туловища с руками может создать очень короткие рёбра и узкие
треугольники при сохранении замкнутости и отсутствии самопересечений.
Для новых ручных STL с присоединёнными руками последовательность включает
`surface → remesh → mesh`; отказ `remesh` блокирует продолжение.
Переход напрямую к необработанному объединению не является способом
устранения отказа. Форма элементов объёмной сетки проверяется независимо от
геометрического контроля поверхности.

При срабатывании детектора самопересечений MeshLab сохраняют число выделенных
граней и отдельно проверяют пары кандидатов. Для почти компланарных граней
контрольных сеток Георгия и Ярослава получены ложные срабатывания. Общий
модуль допускает их исключение только после геометрической проверки проекций:
треугольники раздельны либо их проекции соприкасаются исключительно по общей
топологической вершине или ребру. Узлы не перемещают, допуск на площадь
перекрытия не вводят. Неоднозначная пара и превышение числа проверяемых
кандидатов блокируют стадию. Эта проверка не является ремонтом поверхности.

Полная электродная модель (CEM) использует конечные площадки. Номинальная
площадь и радиус в файле координат ещё не задают площадку на границе FEM.
До электрического расчёта строят её граничные грани, проверяют площадь,
центроид, протяжённость и перекрытия, задают контактный импеданс и модель
неактивных электродов. Для этого используются канонические MATLAB/EIDORS-
процедуры. Общая подготовка геометрии сама по себе не подтверждает
пригодность CEM-контактов.

[Подготовка CEM-контактов](../MATLAB_TRKG4_real_subjects/src/run_ct_fem_contacts_prepare.m)
сохраняет исходные строковые обозначения контактов и порядок групп.
Для разных номинальных площадей она использует повторные вызовы той же
канонической процедуры выбора граней по всем присутствующим центрам,
затем выбирает соответствующие площадки и проверяет отсутствие общих узлов.
Такой способ может отклонить допустимую физическую установку; отказ требует
проверки дискретизации, без ослабления геометрических допусков.

Для номинального диска диаметром 5 мм относительная ошибка площади должна
быть меньше 12 %, смещение центроида — меньше 1 мм, максимальное расстояние
узлов площадки от центра — меньше 3,7 мм. Для другой площади ограничение
протяжённости задают явно с обоснованием. Контактный импеданс каждой площадки
положителен и задан в Ом·м². Соединённые площадки могут иметь разные
контактные импедансы; равенство их потенциалов вводят преобразованием
матрицы контактов. Проверяют её симметрию и отсутствие токов при одинаковом
потенциале всех узлов и электродов.

## Автоматическая коррекция формы сетки

Основной запуск — `prepare_ct_fem.py pipeline`: он последовательно выполняет
`surface → remesh → mesh` в новом каталоге. Один и тот же алгоритм получает
индивидуальные КТ, маски, наружную поверхность и контакты из конфигурации.
Имена испытуемых и координаты проблемных мест в код не включаются.
Для площадок диаметром 5 мм общий пример задаёт рёбра поверхности 5 мм
вне зон сгущения, 2 мм в буфере и 0,8 мм около контактов.

Первый TetGen-расчёт проверяют по всем тетраэдрам. При нарушении mean ratio
или обусловленности включается `mesh.quality_recovery`. По центрам и
вершинам плохих элементов находят ближайшие точки поверхности. Для каждого
элемента хотя бы одна вершина должна находиться в пределах 2 мм от границы.
Центр тетраэдра с тремя граничными вершинами на кривой поверхности может
лежать глубже 2 мм; один лишь критерий по центру ошибочно исключает такой
граничный дефект. Если все четыре вершины дальше 2 мм от границы,
поверхностная коррекция отказывается от работы: она не предназначена
для исправления внутренних дефектов объёмной сетки.

Для допустимых случаев выбирают треугольники, центры которых находятся
в пределах 12 мм от найденных точек. На этой области выполняют шесть
итераций перестроения с целевым ребром 2 мм, локальным сглаживанием и
перепроекцией на поверхность данного прохода. Локальное ограничение
операций остаётся 0,2 мм. Это отдельная, явно заданная процедура после
отказа проверки формы; базовое глобальное перестроение выполняется без
сглаживания вершин.

Каждый исправленный экспорт повторно проверяют по замкнутости, топологии,
самопересечениям, объёму, исходной наружной области и положениям контактов.
Допуск 0,75 мм и относительный допуск объёма 0,003 относятся к исходной
области до всех проходов. Допуск проекции контактов также не обновляют
с накоплением: каждый проход сравнивают с исходными метаданными контактов
стадии `mesh`, сохраняя их исходные физические координаты и площади.
Маски, исходный STL и тканевые параметры не изменяют.

Разрешены не более трёх корректирующих проходов. В одном проходе допускается
не более 1000 плохих элементов и 100 000 выбранных граней. Параметры
фиксируются до запуска. Превышение ресурса, геометрического допуска или
числа повторов завершает стадию отказом. Пороги качества не ослабляются.

Все попытки, включая отклонённые, сохраняются с собственными входами,
направляющими, настройками, журналом TetGen и показателями качества.
`mesh_attempts.local.json` описывает выбор по форме; окончательный допуск
задаёт `mesh_quality.local.json` после полного контроля объёмной сетки и
фактической границы. `pipeline.local.json` создаётся только после успешного
завершения всех трёх стадий. При отказе сохраняется `pipeline_failed.local.json`.

## Сетка и тканевые доли

Тетраэдральную сетку строят с заранее заданными ограничениями формы и
ресурсов. Проверяют положительные ориентированные объёмы, отсутствие
дублирующихся элементов и замкнутую границу. Фактическую границу после
генерации сравнивают с исходной поверхностью по объёму и двусторонним
выборочным расстояниям. Имя входного STL не доказывает её сохранение.

Показатель формы равен $q=12(3V)^{2/3}/\sum_{k=1}^{6}l_k^2$, где $V$ —
модуль объёма тетраэдра, $l_k$ — длины шести рёбер. Для правильного
тетраэдра $q=1$. Допуск требует $q\geq0,01$; обусловленность матрицы
трёх рёбер не должна превышать 10 000. Эти технические критерии не задают
погрешность импеданса. Неудачный результат сохраняется с причиной отказа;
допуски автоматически не ослабляются. При чтении сохраняют порядок
граничных граней, к номерам которых относятся карты наследования.

Текущая генерация использует TetGen с сохранением кусочно-линейной границы,
ограничением отношения радиуса описанной сферы к кратчайшему ребру 1,5 и минимальным
двугранным углом 8°. Эти параметры генератора дополняют проверку полученных
элементов. Размер, максимальный объём элемента и предел числа добавленных
узлов сохраняют в конфигурации. Установленную версию TetGen и остальных
библиотек фиксируют в паспорте; скрипт не устанавливает зависимости сам.

Настройки оптимизации TetGen задают явно в `mesh.tetgen_options`. Шаблон
воспроизводит настройки первоначального успешного расчёта Георгия:
`opt_scheme=7`, `smooth_maxiter=7`, `nomergefacet=false`, `epsilon=1e-8`,
`opt_iterations=3`, `opt_max_asp_ratio=1000`, `optmaxdihedral=177`.
Сглаживание объёмной сетки TetGen и отключённое сглаживание исходной поверхности
MeshLab — разные операции. Фактическую границу после TetGen проверяют снова,
в том числе относительно наружной области до перестроения поверхности;
допуски двух стадий не складывают. Изменённые настройки являются отдельным
расчётным вариантом и требуют нового каталога и собственных проверок.

Нативный TetGen запускается изолированно с явным `mesh.maximum_seconds`.
Сохраняются параметры, версия, SHA входного STL, журнал, код завершения и
сырые массивы результата. Истечение времени, ошибка генератора или отказ
проверки формы не создают завершённого паспорта сетки. Сырые массивы
сохраняют для диагностики; они не допускаются к электрическому расчёту.

Проверка от 26.10.2026 установила, что первоначальная сетка Георгия
воспроизводится с точным совпадением узлов и связности после возврата
исходных настроек оптимизации. Редакция с `opt_scheme=1`,
`smooth_maxiter=0`, `nomergefacet=true`, `epsilon=1e-10` воспроизводит
отклонённый вариант. Поэтому пример конфигурации связывают с конкретным
успешным расчётом и снимком его программы; совпадения имени текущего
скрипта недостаточно. Подробности и границы проверки приведены в
[разборе построения сеток](CT_FEM_MESH_FAILURE_AUDIT_20261026.md).

Материалы записывают в порядке: фон, лёгкое, кость, целое сердце, жир.
На пересечениях масок действует приоритет: лёгкое, кость, сердце, жир,
затем фон. Остальная область, включая принятые искусственные продолжения
вне КТ, относится к фону. Это допущение; объём проб вне поля зрения
учитывают отдельно. Проводимости, частоту и литературные опоры задают при
постановке электрической задачи, с сохранением источников и единиц.

Тканевые доли получают на вложенных наборах 1024 и 4096 равномерных проб
в тетраэдре, построенных из последовательности Соболя с фиксированным
начальным значением генератора. Доли неотрицательны и в сумме равны единице.
Однородность проверяют по воксельному ограничивающему блоку. Несгущённый
элемент можно повторно использовать только при неизменных узлах, связности,
КТ, масках и правиле интегрирования. Разделённые элементы пересчитывают.

В текущем электрическом тракте проводимость элемента задаётся как
$\sigma_e=\sum_k w_{e,k}/\rho_k$, где $w_{e,k}$ — объёмная доля материала
$k$ в элементе $e$, а $\rho_k$ — его удельное сопротивление в Ом·м.
Проводимость измеряется в См/м. Это модель усреднения скалярной вещественной
изотропной проводимости; она не описывает анизотропию и частотную дисперсию.
Если одна КТ вдоха используется для обеих дыхательных проб, геометрическое
движение и изменение тканевых долей при дыхании отсутствуют в такой
постановке. Подбор разных сопротивлений фаз не проверяет адекватность
этого допущения.

## Раздельные численные проверки

Сгущение задают всеми контактами выбранного положения и явными внутренними
направляющими. Луч от кожи до первого попадания в маску лёгкого не считается
глубиной электрической чувствительности или эффективной толщиной
редуцированной модели. Перемещение сборок требует повторной проверки
покрытия фактических площадок сгущением.

От одного родителя строят два варианта одной дочерней сетки: с точным
наследованием коэффициентов и с новым интегрированием тех же масок.
Проверяют исходные узлы, суммы объёмов, границу, площади и первые моменты
родительских граней, а также энергию наследуемого линейного поля.

При одинаковых сопротивлениях, координатах, возбуждении и чтении напряжения
сравнивают три прямых расчёта: родитель, наследуемый дочерний вариант и
вариант с новыми долями. Первое сравнение выделяет изменение пространства
FEM, второе — изменение долей. Их взаимная компенсация не заменяет
раздельного контроля. Отдельно сравнивают правила интегрирования.

Если вложенные правила дают близкий импеданс, дополнительно проверяют,
не зависит ли результат от начального значения генератора последовательности
Соболя. Для усиленной проверки служит
[скрипт независимого интегрирования](../MATLAB_TRKG4_real_subjects/tools/georg_integration_stability.py).
На неизменной сетке он заново интегрирует все неоднородные элементы,
включая не разделённые при последнем сгущении. Точно сертифицированные
однородные элементы сохраняют единичную долю одного материала. Используют
два вложенных числа проб, например 4096 и 16384, и два разных начальных
значения генератора. Правила, фактические доли, исходники и подготовленные
матрицы проверяют по контрольным суммам. Старую матрицу нельзя объявить
результатом нового числа проб изменением одного поля паспорта.

Дыхательную разность проверяют отдельно от абсолютных уровней:
$\Delta Z=Z_{\mathrm{выдох}}-Z_{\mathrm{вдох}}$ для одного и того же
отведения. В продолжении расчёта Георгия заранее задан дополнительный
численный критерий $0,002+0,01|\Delta Z_b|$ Ом, где индекс $b$ обозначает
второй вариант сравнения. Проверяются все пары, без пропущенных или
повторных фаз. Этот критерий не является погрешностью экспериментального
измерения или статистической проверкой почти нулевого контраста.

Успешные проверки при одном векторе сопротивлений и одном положении
относятся только к этой точке. Для начала условного обратного поиска
сохраняют отдельный локальный допуск; глобальные поля сходимости и
физиологического принятия этим не изменяют. Выбранное поиском решение
повторно проверяют по сетке, тканевым долям, контактным отпечаткам,
вложенным правилам и независимым начальным значениям генератора.
Изменение лимита узлов является изменением ресурсного плана и сохраняется
явно; оно не ослабляет критерии формы элементов или электрические допуски.

Контактную дискретизацию проверяют при неизменных объёмных элементах,
материалах и физических центрах. Наследуемый и заново выбранный отпечатки
сопоставляют отдельной парой расчётов. Один успешный локальный переход
между сетками не устанавливает глобальной сеточной сходимости.

В текущих контрольных расчётах Георгия для пространства FEM, тканевых долей
и контактов используется допуск $0,02+0,005|Z_b|$ Ом, где $Z_b$ — импеданс
второго варианта сравниваемой пары в омах. Для правил интегрирования
1024 и 4096 проб допуск равен $0,02+0,001|Z_{4096}|$ Ом.
Все сравнения проводят по каждому отведению и состоянию, а не только по
максимуму или среднему. Это заранее заданные диагностические критерии
численного изменения; они не определяют физическую погрешность модели,
качество эксперимента или точность найденных сопротивлений.

## Исполнение и происхождение результатов

Каждая стадия получает локальную конфигурацию и создаёт новый каталог.
Пути входов разрешаются относительно конфигурации; медицинские абсолютные
пути не включаются в переносимый пример. До загрузки массивов и после
вычислений проверяют контрольные суммы КТ, масок, конфигурации, исходников
и зависимостей предыдущей стадии. Завершённый паспорт записывают после
проверок; незавершённая дочерняя ветвь не допускается как следующий родитель.

```text
python -B tools/prepare_ct_fem.py pipeline --config <local.json> --out <fresh_pipeline>
```

Если необязательные зависимости Python находятся в отдельном установленном
каталоге, его задают через `--dependency-dir <existing-runtime-dir>`.
Установка пакетов автоматически не выполняется. Для поэтапного исполнения
сохраняются отдельные команды:

```text
python -B tools/prepare_ct_fem.py validate --config <local.json> --out <validation>
python -B tools/prepare_ct_fem.py surface --config <local.json> --out <surface>
python -B tools/prepare_ct_fem.py remesh --config <local.json> --input <surface> --out <remesh>
python -B tools/prepare_ct_fem.py mesh --config <local.json> --input <remesh> --out <mesh>
python -B tools/prepare_ct_fem.py materials --config <local.json> --input <mesh> --out <materials>
python -B tools/prepare_ct_fem.py refine --config <local.json> --input <materials> --out <refinement>
python -B tools/prepare_ct_fem.py cem_contacts_input --config <local.json> --input <mesh_or_refined_branch> --out <cem_input>
```

Подготовленный файл контактов передают в MATLAB:

```matlab
run_pipeline('Profile','ct_fem_contacts_prepare', ...
    'InputFile','<cem_input>/cem_contacts_input.local.json', ...
    'OutputDir','<fresh_cem_output>');
```

Вызов выполняют из основной MATLAB-папки; точка входа подключает каталоги
канонических процедур `src`, `tools` и `vendor_stl_eidors`. Проверка путей исключает случайную подмену
одноимённых функций. Этот вызов строит площадки и матрицу контактов,
без решения объёмной электрической задачи.

Проверка изменения контура и построение рисунка выполняются отдельно:

```text
python -B tools/ct_fem_body_diagnostic.py --config <local.json> --input <saved_surface> --out <fresh_diagnostic>
python -B tools/ct_fem_body_diagnostic.py --plot-only --config <local.json> --input <fresh_diagnostic>/body_distance_diagnostic.local.json --out <fresh_sections.png>
```

Для следующего сгущения используют пересчитанную по КТ дочернюю ветвь;
наследуемый вариант сохраняют как контроль. Электрические расчёты выполняют
отдельно через основной тракт `run_pipeline`. Общая подготовка не выбирает
модель как текущую и не публикует исходные данные.

Программные свойства проверяются
[синтетическими тестами](../tests/test_ct_fem_preparation.py).
Отдельный [тест генератора сетки](../tests/test_ct_fem_tetgen.py) запускает
реальный TetGen на малом искусственном томе;
[проверка MATLAB-контактов](../MATLAB_TRKG4_real_subjects/tests/check_ct_fem_contacts_fixture.m)
использует [искусственную сетку](../tests/prepare_ct_fem_matlab_fixture.py).
Они не заменяют просмотра КТ, контроля CEM-площадок, электрической
сходимости и независимого сопоставления с экспериментом. Геометрическая
подготовка, численная проверка FEM и физиологическая валидация сохраняются
как разные статусы. Проверка на Георгии автоматически не переносится
на другого человека, частоту или монтаж.
