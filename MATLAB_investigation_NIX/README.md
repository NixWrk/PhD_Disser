# MATLAB_investigation_NIX

Исходное MATLAB/EIDORS-исследование прямой задачи EIT на анатомии, полученной из КТ. Отсюда выросла текущая рабочая линия [MATLAB_TRKG4_real_subjects](../MATLAB_TRKG4_real_subjects/README.md), куда перенесены лёгкие хелперы (`vendor_stl_eidors/`).

Единственный содержательный подкаталог — [`ForwardSolutionWithStlGeometryExample(by_NIX)`](ForwardSolutionWithStlGeometryExample%28by_NIX%29/README.md); его README является основным описанием проекта.

## Суть постановки

Расчётный путь построен только на STL, COMSOL не требуется:

1. внешняя STL-поверхность тела тетраэдризуется;
2. внутренние замкнутые STL-маски задают проводимости тканей поэлементно;
3. EIDORS решает прямую задачу и сохраняет измерения transfer impedance.

## Требования

MATLAB R2022b, EIDORS 3.12 на пути, Gmsh (не Netgen — на тяжёлых анатомических STL используется именно он), опционально Parallel Computing Toolbox для ускорения назначения тканей.

## Что отличает от TRKG4

| | Здесь | [TRKG4](../MATLAB_TRKG4_real_subjects/README.md) |
|---|---|---|
| Электроды | кольцевые монтажи, развёртки | только 4 электрода ТРКГ на реальных позициях |
| Геометрия | пример и развёртки по разрешению сетки | CT/STL конкретного испытуемого |
| Сердце | сфера с изменяемым радиусом | без сферической аппроксимации, радиус постоянен |
| Цель | отработка метода и сходимости по сетке | статический transfer impedance и обратная задача на реальной расстановке |

Развитие ведётся в TRKG4; эта папка сохраняется как база и источник проверенных хелперов.
