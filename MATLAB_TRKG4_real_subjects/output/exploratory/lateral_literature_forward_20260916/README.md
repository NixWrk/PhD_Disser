# Прямая проверка боковых импедансов по литературным сопротивлениям

Результат включён в [раздел 5.3 ноутбука 33.09](../../../../Colab%20Notebooks/33.09_Выбор_размеров_и_числа_боковых_сборок.ipynb). [Интерактивный график](forward_comparison.html), [PNG](forward_comparison.png), [все численные сравнения](comparison.csv).

Выполнены 36 прямых решений FEM/CEM без подгонки: девять сборок, две формы лёгкого, два табличных состояния. Приняты свойства мышцы для всего внелёгочного фона и свойства лёгкого inflated/deflated из IT’IS V5.0 при 50 кГц. Категория deflated не установлена как эквивалент выдоха добровольца. Геометрия КТ на вдохе и монтаж C01 фиксированы; конечные контакты имеют диаметр 5 мм. Совпадение этого диаметра с контактами прежнего эксперимента не установлено.

Основной результат: при этих сопротивлениях исходная КТ-модель даёт значения в среднем примерно вдвое ниже измеренных. Замена модели 4 исходной КТ-маской изменяет прогноз не более чем на 0,047 Ом. Проверка относится к двум заданным парам и не исключает другие литературно допустимые параметры.

## Источник

[IT’IS Tissue Properties Database V5.0](https://itis.swiss/virtual-population/tissue-properties/downloads/database-v5-0), DOI 10.13099/VIP21000-05-0; [частотные зависимости Gabriel](https://itis.swiss/virtual-population/tissue-properties/database/dielectric-properties). В `literature_values.csv` указаны строки исходной таблицы, проводимости и удельные сопротивления. В `plan.json` зафиксированы происхождение данных, контрольные суммы и допущения.

## Повторение расчёта

Команды выполняются из `MATLAB_TRKG4_real_subjects`. Для нового независимого прогона Python принимает `--out` с новым каталогом внутри этой папки; в MATLAB нужно указать тот же каталог запроса. Уже замороженный план команда подготовки не перезаписывает.

```powershell
python tools/lateral_literature_forward.py --prepare
```

```matlab
run_pipeline('Profile','lateral_array_design','RequestsFile','output/exploratory/lateral_literature_forward_20260916/points.csv');
```

```powershell
python tools/lateral_literature_forward.py --collect
python notebooks/build_lateral_array_design.py
```

Неизменённое MATLAB-ядро сначала пишет три файла `points_responses.csv*` в каталог библиотеки `lateral_array_design_20260916`. Параметр `--collect` проверяет завершение и соответствие запросу, затем переносит только эти три файла в каталог данного опыта. Существующие результаты назначения не перезаписываются. Подготовленные FEM-матрицы, КТ и таблица наблюдений читаются на месте; первичные данные не копируются.

Для повторного построения сравнения из уже собранных результатов достаточно `python tools/lateral_literature_forward.py`. Это не новый FEM-расчёт. Нужны локальные исходные файлы с указанными в плане контрольными суммами, Python с NumPy, pandas, Plotly и Playwright, а для повторного FEM — MATLAB и действующее окружение EIDORS. Для PNG используется Chromium из Playwright.

Численные невязки и взаимность проверяют решение дискретной задачи. Глобальная сходимость по сетке и физическая валидация этой двухтканной постановки не объявляются выполненными.
