# 20.14 Две проверки моделей с литературными сопротивлениями

**Роль этапа:** проверить, улучшает ли сокращённое описание лёгочной области
восстановление двух удельных сопротивлений при физиологически мотивированных
ограничениях. КТ принимается как достоверный источник анатомии; сопротивления
испытуемого независимо не измерены. Материалов два: нелёгочный фон с ρ₁ и
лёгкое с ρ₂. Поддиафрагмальная область относится к фону.

[Полный ноутбук](20.14_Две_проверки_моделей_с_литературными_сопротивлениями.ipynb)
и [читательская версия без кода](20.14_Две_проверки_моделей_с_литературными_сопротивлениями.html)
продолжают [20.13](20.13_Геометрия_лёгкого_и_ошибка_восстановления_сопротивлений.md).
Их результаты передаются в дальнейшие проверки применимости модели и выбора
сборок; расчёт функций сердца на этом этапе не выполняется.

## Программа и происхождение входов

Автор утвердил обе проверки и выбор литературных данных 10.09.2026.
Используются прежние индивидуальная КТ-геометрия, сетка, восемь описаний
прямой задачи и фиксированная поза сборки из 20.13. Экспериментальный вход —
девять сохранённых уровней импеданса на задержке вдоха у Ника, эксперимент 2,
реокардиомонитор МГТУ. Размер 100 мм исключён как поздняя копия 90 мм.
Последовательные измерения считаются сопоставимыми по состоянию испытуемого;
различия времени, повторного наложения и контактов остаются ограничениями.

Численные ориентиры взяты из
[IT’IS Tissue Properties Database V5.0](https://itis.swiss/virtual-population/tissue-properties/downloads/database-v5-0).
Рабочая область составляет ρ₁ = 1,3774–10,0000 Ом·м и
ρ₂ = 9,7413–24,0741 Ом·м. Она объединяет частотный ориентир наполненного
лёгкого при 50 кГц с низкочастотными литературными диапазонами. Это рабочий
перенос данных о мышце и лёгком на эффективную двухтканную модель,
а не установленный популяционный интервал нормы на данной частоте.

## Выполненные проверки

1. **Синтетическая.** Для 49 заданных пар сопротивлений заново рассчитаны
   девять импедансов исходной КТ/PEM-модели. Восемь способов восстановления
   дают 392 ограниченные инверсии. Ошибки сравниваются с заданными
   сопротивлениями; отдельно рассмотрены 25 внутренних сочетаний.
2. **Экспериментальная.** Для восьми моделей выполнены подгонка всего ряда,
   72 исключения размера и 144 одноканальных возмущения ±1%. Исключения
   условны на прежнюю позу, которая использовала весь ряд измерений.
   Поэтому они не являются независимой проверкой всей методики.
3. **Контакты.** Для исходной КТ дополнительно выполнена прямая CEM-инверсия
   с конечными электродами из трёх начальных приближений. Производные
   проверены конечными разностями. Сокращённые пространственные маски
   в основном сравнении сохраняют точечную электродную постановку PEM.

## Что установлено

Устойчивого победителя среди упрощений не найдено. Привязанный по глубине
эллипсоид уменьшает медиану ошибки ρ₂ по 49 случаям, но увеличивает максимум;
на 25 внутренних случаях преимущество по медиане перед прежней аналитикой
исчезает. Малая ошибка импеданса может сопровождаться большой ошибкой ρ₂
даже при обеих оценках внутри литературной области.

В семи из восьми основных экспериментальных подгонок ρ₂ достигает верхней
границы. Это же происходит при CEM: ρ₁ ≈ 5,7449 Ом·м,
ρ₂ ≈ 24,0741 Ом·м, остаток ≈ 8,1509 Ом. Совпадение трёх стартов
подтверждает воспроизводимость данного минимума, но не его физическую
истинность или глобальную единственность.

Следующий проверяемый кандидат — локальная поверхность с раздельным учётом
продольного профиля, поперечной кривизны и конечного края лёгкого.
Его преимущество следует устанавливать по обоим параметрам, на внутренних
и граничных случаях, при согласованных электродных условиях. Новая
поверхностная модель и расчёт без объёмного FEM здесь ещё не реализованы.

## Воспроизводимость и статус

[Расчётные команды и артефакты](../MATLAB_TRKG4_real_subjects/docs/GEOMETRY_VALIDATION_TESTS.md)
связаны с единой точкой входа MATLAB. Исходные библиотеки 20.13 сохранены;
новые результаты находятся в отдельной исследовательской папке. Ноутбук
исполняет чтение сохранённых результатов и их представление; HTML исключает
исходный код. Индивидуальные ноутбук и HTML остаются локальными.

Вычислительные проверки выполнены. Научный статус — условное сопоставление
моделей на одной анатомии и одном экспериментальном ряду. Истинная ошибка
сопротивлений у испытуемого, сходимость сетки, фактическая поза электродов,
применимость к другим людям и оптимальная пара сборок не установлены.
