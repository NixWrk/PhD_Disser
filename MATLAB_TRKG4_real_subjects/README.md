# MATLAB_TRKG4_real_subjects

Цель папки - перенести нашу COMSOL-постановку в MATLAB/EIDORS на реальные CT/STL данные испытуемых.

Что меняется относительно COMSOL-исследования:

- расчет идет в MATLAB, без COMSOL;
- геометрия берется из CT/STL испытуемого;
- используется только 4 электрода TRKG;
- сердце не аппроксимируется сферой;
- радиус сердца не меняется;
- мягкие ткани идут как фон, легкие/сердце/кости назначаются по STL-маскам;
- результатом является статический transfer impedance для заданной реальной
  расстановки 4 электродов.

## Что взято из STL-примера

Из `../MATLAB_investigation_NIX/ForwardSolutionWithStlGeometryExample(by_NIX)` перенесены только легкие MATLAB-хелперы в `vendor_stl_eidors/`:

- назначение тканей по закрытым STL-маскам;
- проверка попадания точек внутрь STL;
- выбор граничных треугольников электрода по площади;
- диагностика того, куда фактически попал каждый электрод на поверхности;
- ITIS-проводимости;
- служебные функции для centroids/cache/parallel.

Большие STL, output, Gmsh и вложенный `.git` не копировались.

## Минимальный запуск

В MATLAB открыть эту папку и выполнить:

```matlab
addpath('src')
result = run_trkg4_forward_subject('nik');
trkg4_result_summary(result)
```

Пока в `data/nik` не положены реальные STL и координаты 4 электродов, раннер остановится на проверке входных данных и покажет, чего не хватает.

## Входные данные на одного испытуемого

В `data/<subject>/stl/`:

- `body.stl` - внешняя закрытая поверхность тела/торса с руками;
- `lungs.stl` - закрытая маска легких;
- `heart.stl` - реальная маска сердца, не сфера;
- `bones.stl` - закрытая маска костей;
- `blood.stl` - опционально, если есть отдельная сегментация крови/сосудов.

В `data/<subject>/electrodes/electrodes_4_xyz_mm.csv`:

- 4 центра электродов в той же системе координат и в тех же миллиметрах, что STL;
- порядок строк: `I_plus`, `V_plus`, `V_minus`, `I_minus`.

Электроды здесь не берутся из STL-примера и не ставятся кольцом. Их нужно
разметить заново для этой постановки. После mesh-генерации код сохраняет
`output/<subject>_electrode_diagnostics.csv`, где видно расстояние от заданного
центра до ближайшей поверхности и смещение центроида фактического патча.

## Важный нюанс единиц

STL после CT почти всегда в миллиметрах, а проводимости задаются в `S/m`. Код:

1. строит mesh и выбирает tissue/electrode patches в миллиметрах;
2. перед `fwd_solve` масштабирует узлы модели в метры;
3. оставляет проводимости в `S/m` и контактный импеданс в `Ohm*m^2`.

Это нужно, чтобы абсолютный импеданс не уехал из-за несогласованных единиц.
