# Калмыков — проекты

Расчётная и текстовая часть кандидатской работы: оценка ударного объёма и фракции выброса по тетраполярной реокардиографии (ТРКГ). Сквозная методология и границы достижимого — [Colab Notebooks/13_Методология_ФВ_УО.md](Colab%20Notebooks/13_Методология_ФВ_УО.md), **читать первым**.

## Порядок чтения

1. [13_Методология_ФВ_УО.md](Colab%20Notebooks/13_Методология_ФВ_УО.md) — глобальная цель, декомпозиция сигнала ТРКГ, цепочка этапов A–F, что достижимо на текущих данных.
2. [00_Отчёт.md](Colab%20Notebooks/00_Отчёт.md) — сводный разбор лёгочной ветки: постановка, данные, пошаговые выводы, ограничения.
3. [Colab Notebooks/README.md](Colab%20Notebooks/README.md) — карта документов 00–16 и порядок прогона расчётов.
4. [ПРАВИЛА_ОПИСАНИЯ_РАСЧЁТОВ.md](Colab%20Notebooks/ПРАВИЛА_ОПИСАНИЯ_РАСЧЁТОВ.md) — регламент отчётности, стиля и идентификаторов записей.

## Геометрия грудной стенки

Папка [breath geometry](breath%20geometry) содержит отдельный исследовательский конвейер по КТ-геометрии грудной стенки. Ключевой результат для остальных проектов: расстояние от поверхности кожи до поверхности лёгкого `h` меняется при дыхании не более чем на `1–2 мм` по модулю, и только при глубоких манёврах — это количественно обосновывает допущение `h ≈ const` двуслойной модели ([03](Colab%20Notebooks/03_Модель_импеданса_лёгких.md), §1.2) и ограничивает деформацию выдоха в [TRKG4](MATLAB_TRKG4_real_subjects/docs/INVERSE_IDENTIFIABILITY_AND_BREATHING_STATES.md). Границы применимости и отрицательный результат по лагранжевой карте `Δh` — в [WALL_TRACK_SUMMARY.md](breath%20geometry/docs/WALL_TRACK_SUMMARY.md).

## Данные

Сырьё (CSV записей, DICOM КТ, исходные STL) лежит на сетевом диске `Z:` и в репозиторий не входит. В Git хранятся только код и производные артефакты: метки разметки `Colab Notebooks/timestamps/`, восстановленные параметры `Colab Notebooks/params/`, результаты расчётов и отчёты. Какие ноутбуки требуют доступа к `Z:`, а какие самодостаточны — указано в [Colab Notebooks/README.md](Colab%20Notebooks/README.md).

## Исследовательская отчётность

Правила, две истории работы, протоколы экспериментов и путь к тексту диссертации описаны в [правилах](Colab%20Notebooks/ПРАВИЛА_ОПИСАНИЯ_РАСЧЁТОВ.md). Первичные карточки и шаблоны находятся в [research](research/README.md), инструменты — в [tools](tools/README.md).

```powershell
python tools/research_report.py validate
python tools/research_report.py build
python tools/research_report.py export-html
python tools/research_report.py sync --dry-run
```

Команда `update` объединяет все четыре операции и при чистой рабочей копии обновляет проверяемое зеркало на `Z:`.
