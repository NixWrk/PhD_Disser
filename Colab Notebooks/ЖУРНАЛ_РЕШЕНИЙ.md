## Данные и разметка

- Первичные медицинские и физиологические данные остаются вне Git.
- Локальные пути задаются через `config/*.local.json`; в Git хранятся только
  примеры схем.
- Дыхательная и ЭКГ-разметка разделены на независимые артефакты и независимые
  notebook-файлы для каждого эксперимента.
- Последующие расчёты могут читать разметку только после ручного QC и статуса
  `accepted`.
- Старые `timestamps/*.json`, `params/*.json` и notebook outputs пока
  сохраняются для происхождения, но не считаются интерфейсом новой архитектуры.

## Боковые сборки

- Сборки «над лёгким» и «для мягких тканей» — один боковой монтаж.
- Сопоставимость последовательных записей разных размеров является допущением,
  а не свойством данных.
- Запись 100 мм является поздней копией записи 90 мм; в расчёте сохраняется
  90 мм, а 100 мм исключается.
- Цель многоразмерного набора — проверить модель, оценить определимость и затем
  выбрать информативную пару либо диапазон размеров. КТ/FEM-локализация позы
  матриц является другой задачей и не заменяет выбор размеров.

## Статус целевого результата

- Весь корпус остаётся разработкой методики.
- Оценки боковых тканей служат предполагаемыми поправками к ТТРКГ, а не прямой
  оценкой функций сердца.
- Переход от скорректированного сигнала к эквивалентной геометрии, УО и ФВ —
  рабочая гипотеза и программа проверок.
- Серия `60` остаётся контрактом до появления прошедшего go/no-go сердечного
  параметра и синхронного внешнего референса.

- Серия `40` разделена по приборам и ролям. Введён точный составной ключ записи,

- Серия `50` разделена на приборные go/no-go для МГТУ и РНЦХ. Один канал не
  считается достаточным для разделения нескольких произвольных источников;
  последовательные конфигурации используются как планирование до проверки
  повторяемости.
- Серия `60` оформлена как контракт УО, ФВ и будущей внешней валидации. Изменение
  эффективной сферы всего сердца не приравнивается объёму одного желудочка.
- Исторические `timestamps/*.json` и `params/*.json` удалены только из индекса
  Git и игнорируются. Локальные файлы не удалены; история Git сохраняет их
  происхождение.
- Безопасный последовательный прогон подтверждает синтетическую исполнимость,
  но не реальный научный результат. Внешние медицинские данные, ручной QC,
  калибровки, КТ/FEM и бюджеты неопределённости остаются обязательными воротами.

- В серии `50` полный ранг признан необходимым только для совместной
  идентифицируемости всех параметров. Для заранее выбранного целевого параметра
  проверяются его проекция на нулевое пространство и условная дисперсия через
  обобщённую обратную матрицу.
- В серии `60` разрешающим входом является только
  `target_design_and_experimental_operator_pass`; проектное прохождение без
  одновременности и полной ковариации не разрешает расчёт УО/ФВ.
- Серия `70` на РЕО32 не изменялась и остаётся отдельной от ТТРКГ экспериментов
  2–3.
