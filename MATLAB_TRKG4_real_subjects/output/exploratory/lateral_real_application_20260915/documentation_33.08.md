## Применение выбранной модели к эксперименту: 33.08

[Ноутбук 33.08](../../Colab%20Notebooks/33.08_Применение_КТ_модели_к_боковым_измерениям.ipynb) принимает модель 4 из 20.16 и применяет её к эксперименту 2, Ник. Он отвечает за базовые оценки на вдохе и выдохе и пульсовую инверсию для этого индивидуального применения. Геометрический выбор остаётся в 20.16. Основной расчёт использует конечные электроды; контрольная модель — полная КТ с теми же контактами. Положение C01 и КТ приняты точными входами, геометрия на вдохе используется также для выдоха.

Команды выполняются из папки `MATLAB_TRKG4_real_subjects`. Подготовка принимает локальный корень производных данных аргументом; его абсолютное значение не записывается в переносимый код.

```text
python tools/lateral_real_application.py prepare --derived-root <локальный_корень_производных_данных>
```

```matlab
run_pipeline('Profile','lateral_real_application');
```

```text
python tools/lateral_real_application.py analyze
python notebooks/build_lateral_real_application.py
```

Текущий каталог — `output/exploratory/lateral_real_application_20260915`. `input_contract.json` фиксирует записи, принятую разметку, исходную геометрию, единицы и сценарии; `cem_identity.json` связывает наблюдения, подготовленные матрицы и версию MATLAB-решателя. Каждая базовая CEM-подгонка сохраняет результаты двух начальных точек, прямые прогнозы и производные. Отдельно решается сценарий общего базового ρ₁ модели 4. Пульсовая инверсия использует собственную базовую точку каждого состояния.

Профиль возобновляет завершённые подгонки только при точном совпадении контракта. При изменении входов или MATLAB-решателя следует задать новый `OutputDir` и соответствующий `--out` на стадиях Python. Существующий контракт не переписывать для принудительного принятия старых результатов. Обычное выполнение 33.08 проверяет сохранённые CEM-решения, повторяет быстрые точечные и пульсовые инверсии, но не запускает MATLAB.

Сигналы приняты в физических единицах файлов по актуальному решению автора. Дополнительные gain, offset и смена знака не подбираются. Старые поля неизвестной шкалы сохранены как метаданные происхождения, но не используются как общий блокер. Принятая разметка дыхания и ЭКГ не повышает статус незавершённого общего QC. Все результаты сохраняют статус `exploratory_hypothesis_not_validated`.

Номинальная площадь контакта — 70,686 мм², фактические дискретные площади — 70,783–94,195 мм². Поверхностное контактное сопротивление фиксировано: 0,000159155 Ом·м². Вдох и выдох используют одинаковые площадки. Подгонка контакта, дыхательное изменение геометрии, выбор пары сборок и перенос на другую анатомию не входят в этот прогон.
