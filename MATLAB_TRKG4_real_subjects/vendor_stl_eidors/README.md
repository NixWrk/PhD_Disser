# vendor_stl_eidors

Small MATLAB helpers copied from:

```text
../archive/MATLAB_investigation_NIX/ForwardSolutionWithStlGeometryExample(by_NIX)
```

They provide STL mask classification, electrode boundary patch selection,
ITIS conductivities, mesh cache keys, centroids, and optional parallel setup.

Исторические варианты сохранены в архиве, но не добавляются на MATLAB path.
Активные версии этой папки имеют приоритет и содержат исправления выбора
непересекающихся электродных патчей, проверки входов и ключей кэша.
