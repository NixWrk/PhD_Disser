# Происхождение и применение в проекте

- Версия: 2.5.2.
- Коммит: `ff80f133161acaebac13298ad1a4aa98664ddb2e`.
- Исходный каталог: `skills/avoid-ai-writing-russian`.
- Дата установки: 29.10.2026.
- Лицензия: MIT; файл `LICENSE` скопирован из корня того же коммита.
- Исходные `SKILL.md` и `references/*.md` сохранены без изменений.
- Установлена только инструкция со справочными материалами. Пакет `aiw-ru`,
  модели детекции и соседний скилл `antiplagiat` не установлены.

В этом проекте скилл используется для языковой редактуры научного текста
с контекстом `vak`. Обязательные условия применения закреплены в
[AGENTS.md](../../../AGENTS.md), полные правила автора — в
[требованиях к научному тексту](../../../docs/RUSSIAN_SCIENTIFIC_WRITING.md).
Они имеют приоритет перед общими стилистическими рекомендациями скилла.

Название профиля не подтверждает соответствие требованиям ВАК, журнала или
конкретного стандарта. Для такой проверки нужны сами требования.
Команды `uv run --project ../..` из исходной инструкции рассчитаны на полный
репозиторий автора скилла; в установленной здесь копии Python-пакета нет.
Для обычной языковой редактуры эти команды и детекторы не используются.
