# Передача фаз дыхания в готовую модель

Дата проверки: 7 октября 2026 года. Проверены десять расчётов DIR-Lab и два расчёта одного случая TCIA с разными исходными фазами. Обучение сети и подбор фаз по ошибке прогноза не выполнялись.

## Соглашение об обозначении фаз

В [описании TCIA авторами набора](https://pmc.ncbi.nlm.nih.gov/articles/PMC5912888/) 0 % определены как конец вдоха. Использование 0 % и 50 % соответственно для конца вдоха и выдоха также явно указано в [исследовании на этом наборе](https://purehost.bath.ac.uk/ws/portalfiles/portal/287959945/EIT_Guided_by_DT_and_DL_final.pdf), раздел III.A. [Описание DIR-Lab](https://med.emory.edu/departments/radiation-oncology/research-laboratories/deformable-image-registration/downloads-and-reference-data/4dct.html) задаёт крайние фазы `T00` и `T50` и последовательность выдоха между ними.

| Состояние или назначение | DIR-Lab | TCIA | Входной параметр стадии |
|---|---|---|---:|
| Конец вдоха | `T00` | `g000` | 0,0 |
| Промежуточные фазы выдоха | `T10`–`T40` | `g010`–`g040` | 0,1–0,4 |
| Конец выдоха | `T50` | `g050` | 0,5 |
| Промежуточные фазы вдоха | `T60`–`T90` | `g060`–`g090` | 0,6–0,9 |
| Опора статистической модели формы | выбранная `T70` | опубликованная `g070` | 0,7 |

[Конвертер TCIA](https://github.com/Project-MONAI/monai-physio/blob/2026.09.1/data/TCIA-4DLung/convert.py) переносит процент из описания DICOM-серии в имя файла. [Код обучения](https://github.com/Project-MONAI/monai-physio/blob/2026.09.1/tutorials/tutorial_09_lung_train_physicsnemo_mgn.py) делит этот процент на 100 без сдвига. Выбор `g070` в качестве опоры модели формы не превращает 70 % в конец выдоха и не меняет начало шкалы.

**Исправленное утверждение.** Подпись `g070` как конца выдоха в [учебном примере MONAI](https://project-monai.github.io/monai-physio/tutorials.html#tutorial-3-reconstruct-high-resolution-4d-ct) противоречит первичным сведениям о фазах. В проверенном случае TCIA максимальный объём лёгких получен в `g000`, минимальный — в `g050`; объём `g070` находится между ними. Объёмы использованы только для контроля уже установленного соглашения. Фазы по ним не переназначались.

## Изменения расчётной процедуры

Введена единая функция преобразования подтверждённых меток фаз. Стадия исходной КТ определяется из её метки. Если вручную переданная опора противоречит метке, расчёт останавливается до обращения к сети: например, `g000` с опорой 0,7 запрещена. Неизвестная фаза также блокирует обычный запуск. Для исторических опытов оставлен явный режим условного сценария с непроверенной фазой; он не обозначается как прогноз подтверждённого дыхательного состояния.

Отчёты новых расчётов сохраняют метку исходной КТ, опорную стадию, шкалу целевых стадий и источники соглашения. Оценка по контрольным данным проверяет их согласованность. Подтверждённые стадии не выбираются по целевой КТ или величине ошибки.

## Результат повторной проверки

Во всех двенадцати сохранённых расчётах численные стадии уже соответствовали опубликованной шкале. Для DIR-Lab использовались `T70 → 0,7`, `T00 → 0,0` и `T50 → 0,5`. Для TCIA — соответствующие проценты `gPPP`. Численные входы сети не изменены; основания для искусственного сдвига на 20 % отсутствуют.

Повторная оценка десяти случаев по сохранённым полям и экспертным ориентирам не изменила ошибки: средняя ошибка неподвижного контроля составляет 8,46 мм, прогноза — 5,97 мм. Предсказанное среднее смещение составляет 3,57 мм при наблюдаемом 8,46 мм. Недооценка движения сохраняется при проверенном соглашении о фазах. Машинные результаты приведены в [проверке входов](mp10_phase_input_verification_2026-10-07.json) и [сводке DIR-Lab](mp10_dirlab_4dct_summary_2026-10-01.json).

**Границы вывода.** Проверены опубликованная шкала и её передача в наших расчётах. В скачанных весах нет отдельного описания фаз и поимённого списка обучающих пациентов. Равенство процентов цикла не устанавливает одинаковую глубину дыхания. КТ добровольцев на глубоком вдохе с задержкой не эквивалентна автоматически фазе спокойного дыхания TCIA. Подгонка исходной `g000` к модели формы, построенной по `g070`, остаётся опытом за пределами опубликованного протокола подгонки. Количественная пригодность для дыхательной геометрии добровольцев и FEM не подтверждена.
