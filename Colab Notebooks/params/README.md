# Исторические параметры

Файлы `static.json`, `ct.json` и `systolic.json` сохранены как небольшие обезличенные результаты исторического расчёта. У них нет полного контракта калибровки, SHA-256 исходных записей, статуса ручного QC и межзаписной неопределённости. Поэтому серии 33–60 не используют эти значения как канонический вход.

Новые результаты записываются только во внешний `derived_root` после прохождения входных ворот соответствующего ноутбука. При сравнении со старыми числами их следует обозначать как `legacy_unvalidated`.
