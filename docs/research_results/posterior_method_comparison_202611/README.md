# Общая ошибка прогноза заднего импеданса на 200 мм

В [aggregate.csv](aggregate.csv) приведены ошибки 11 способов расчёта, усреднённые
с одинаковым весом по четырём условиям регистрации. Проверены 44 исходные строки
основного сравнения (11 способов × 4 условия). Верхняя граница удельного
сопротивления лёгких $\rho$ составляет 17 Ом·м. Для плоских моделей выбран основной
вариант КТ-геометрии `ap_w10_volume`, для трёхмерных — исходная анатомическая КТ.

По измерению 60 мм определяли один параметр грудной стенки при фиксированном
исходном свойстве лёгких. Затем по 100 и 140 мм подбирали только удельное сопротивление
лёгких. Измерение 200 мм исключено из определения параметров и выбора геометрии.
Каждому размеру соответствует отдельная запись. Проверка характеризует перенос
между размерами сборок. Четыре условия получены при повторных измерениях двух
добровольцев и не являются четырьмя независимыми испытуемыми. Результаты относятся
к базовому импедансу и не оценивают точность ударного объёма или фракции выброса.

Сопоставлены три типа расчёта — плоские аналитические слои, трёхмерная
конечно-элементная модель (FEM) по КТ и смешанный расчёт с однородным
полупространством на 60 мм и последующим FEM. Раздельные свойства жира и мягких
тканей без отдельно выделенной жировой ткани заданы при фиксированном отношении
сопротивлений. Для плоских слоёв порядок тканей, исключение костного промежутка,
его условное заполнение мягкотканным материалом и конечная толщина лёгкого
представляют отдельные модельные допущения. Ограниченный диапазон подбора
сохраняется. Усреднение ошибок не подтверждает истинность тканевых параметров.

Для ошибки $e=Z_{\mathrm{pred}}-Z_{\mathrm{obs}}$ на 200 мм, где $Z$ — импеданс в омах,
вычислены `MAE_ohm` — среднее $|e|$, `RMSE_ohm` — корень из среднего $e^2$,
`mean_abs_percent` — среднее $100|e|/Z_{\mathrm{obs}}$.
Первые две величины выражены в омах, третья — в процентах. Удельное сопротивление
$\rho$ выражено в Ом·м. Агрегирование выполнено по полной точности исходной
таблицы. В CSV ошибки округлены до трёх знаков после запятой в омах и двух
в процентах. Округлённые проценты основной сводки сверены отдельно.

MAE на 200 мм составила **7,346 Ом** для плоской двухслойной модели с общим $\rho$,
**4,941 Ом** для FEM с общим $\rho$ мягких тканей и жира и **5,318 Ом** для
смешанного расчёта. Это общие ошибки по всем четырём условиям.

Реализация [плоских слоёв](../../../Colab%20Notebooks/exploratory/back_measurement_20261123/inspiration_rho/model_families/flat/layers.py)
и [математические тесты](../../../Colab%20Notebooks/exploratory/back_measurement_20261123/inspiration_rho/model_families/flat/test_synthetic_layers.py)
доступны отдельно. Эти тесты проверяют формулы и численное интегрирование.
Трёхмерные расчёты в данном небольшом комплекте повторно не запускаются.
Программным FEM-драйверам требуются вычислительные ядра проекта, локальный
манифест, сетка, контактные и материальные матрицы. Для части задач нужен EIDORS.
Пульсовому анализу требуются входные записи.

Для воспроизведения агрегатов достаточно стандартной библиотеки Python.

```text
python -B aggregate.py comparison.csv
python -B aggregate.py comparison.csv --check
```

Исходный `comparison.csv` и соседний `primary_results.md` передаются локально
и в этот публичный комплект не входят. Можно указать иной путь к основной сводке
через `--reference`. Скрипт проверяет состав способов и условий, вариант КТ,
совпадение контрольных измерений и пересчитывает ошибки из прогнозов.
