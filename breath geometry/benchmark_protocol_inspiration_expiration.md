# Протокол сравнения моделей перехода «КТ вдоха → анатомия выдоха»

## 1. Цель

Выборка включает шесть человек. Для трёх имеются КТ вдоха и выдоха; для трёх — только КТ вдоха. Структуры интереса: тело, лёгкие, скелет и сердце. Три парных случая используются для перекрёстной проверки моделей. После выбора метода требуется построить STL выдоха для трёх непарных случаев.

### Подтверждённое состояние данных

- Исходные данные представлены CT-снимками.
- Для P01–P03 STL максимального выдоха пока не построены.
- Скелет пока представлен одной общей структурой, без отдельных меток рёбер.
- Основная целевая фаза — **максимальный выдох**.
- Предположительно имеются также исследования спокойного выдоха; их наличие и принадлежность субъектам нужно проверить по DICOM-сериям.

Следовательно, ближайшая задача — не запуск модели, а единообразная сегментация P01–P03 на вдохе и максимальном выдохе с сохранением labelmaps и экспортом STL в исходных физических координатах.

Цель — выбрать не просто модель с минимальной средней ошибкой, а метод, который одновременно:

- точно воспроизводит независимые анатомические ориентиры и поверхности;
- сохраняет топологию и нормальную морфологическую индивидуальность: комплекцию, позу, форму грудной клетки, скелета и взаимное положение органов;
- не создаёт складок, инверсий сетки и пересечений органов;
- устойчив к неопределённости сегментации, целевого объёма и параметров;
- сохраняет качество на других пациентах и амплитудах дыхания;
- имеет понятную область применимости и измеримую неопределённость.

Под «всеми моделями» далее понимаются все основные семейства, для которых можно построить воспроизводимые реализации и сопоставить их при одинаковом наборе входных данных. Перебирать каждую опубликованную архитектуру не нужно: сначала сравниваются классы, затем лучшие представители внутри классов.

### Что означает сохранение индивидуальности

В данном исследовании это не задача моделирования патологий. Требуется сохранить нормальные различия между людьми:

- отношение ширины грудной клетки к её AP-размеру;
- общую комплекцию и толщину наружных мягких тканей;
- позу, кривизну позвоночника и небольшой исходный поворот туловища;
- геометрию каждого ребра и грудины;
- естественную лево-правую асимметрию;
- размеры и исходные положения сердца и лёгких;
- индивидуальную форму диафрагмальных и медиастинальных поверхностей.

Часть этих признаков инвариантна дыханию — например, длина и локальная форма кости. Часть закономерно меняется — положение рёбер, размеры грудной клетки и высота диафрагмы. Модель должна сохранять первую группу и изменять вторую, не притягивая человека к средней анатомии обучающей выборки.

## 2. Главное правило: разделить режимы по доступной информации

Нельзя помещать в один рейтинг модели, которые видели разный объём информации.

| Режим | Разрешённый вход | Роль КТ выдоха | На какой вопрос отвечает |
|---|---|---|---|
| **P0: чистое предсказание** | только КТ/STL вдоха и параметры, заранее полученные на других людях | полностью скрытый тест | насколько выдох предсказуем из одной анатомии |
| **P0V: predicted-volume** | P0 + объём выдоха, предсказанный по отношениям объёмов обучающих пар | полностью скрытый тест | основной применимый режим для U01–U03 |
| **P1-oracle-volume** | P0 + истинные объёмы правого и левого лёгкого из КТ выдоха тестового парного случая | раскрывается только объём, не форма | какая ошибка остаётся при точно известной амплитуде; диагностическая верхняя граница, недоступная для U01–U03 |
| **P2: sparse-calibrated** | P0V + внешняя поверхность, диафрагма, несколько рёберных/рентгеновских ориентиров | скрыта, кроме объявленных редких наблюдений | гипотетическая точность при минимальной индивидуальной калибровке; сейчас данных для режима нет |
| **R: парная регистрация** | полные КТ вдоха и выдоха | является входом | верхняя граница пространственного совмещения, но не односнимочное предсказание |
| **C: двухфазная идентификация** | обе КТ используются для подбора материала/нагрузок | обучающая цель | можно ли персонализировать механику; проверять нужно на промежуточных фазах или повторном цикле |

Для каждого режима строится отдельный leaderboard и выбирается отдельный победитель. Модель R почти наверняка будет точнее P0, но это не означает, что она решает исходную задачу.

### Недопустимая утечка эталона

Для P0 нельзя извлекать из КТ выдоха:

- форму или положение диафрагмы;
- поверхностные перемещения лёгких;
- рёберные трансформации;
- параметры FEM, минимизирующие ошибку именно этого выдоха;
- dense deformation field для инициализации;
- гиперпараметры, выбранные по итоговой ошибке на этом пациенте.

Для P0V оценка объёма строится без КТ выдоха тестового человека. В P1-oracle-volume допустимы только заранее объявленные скаляры истинного объёма; этот режим используется для анализа ошибки, но не для финальных U01–U03. Для P2 список разрешённых наблюдений фиксируется до запуска; в текущем проекте таких данных нет. Всё остальное остаётся закрытым до окончательной оценки.

### Схема исследования для шести человек

Обозначим парные случаи как `P01`, `P02`, `P03`, а случаи только со вдохом — как `U01`, `U02`, `U03`.

На трёх парных случаях проводится leave-one-subject-out validation:

| Fold | Калибровка/настройка | Полностью скрытый тест |
|---|---|---|
| 1 | P02, P03 | P01 |
| 2 | P01, P03 | P02 |
| 3 | P01, P02 | P03 |

В каждом fold КТ выдоха тестового человека открывается только после формирования предсказанных STL. Метрики считаются одним и тем же кодом. После трёх folds модели сравниваются по результатам каждого человека, медиане и диапазону.

Трёх пар недостаточно для обучения высокоразмерной статистической модели или нейросети с нуля. Для таких методов необходим внешний pretraining на DIR-Lab/COPDGene/другой 4DCT-выборке. Собственные три пары можно использовать только для:

- проверки внешней модели на нужном типе данных;
- калибровки небольшого числа заранее определённых параметров;
- проверки систематического bias;
- выбора между небольшим числом замороженных вариантов.

После выбора семейства и параметров оно повторно калибруется на P01–P03 и применяется без доступа к выдоху к U01–U03.

### Неизвестный целевой объём для U01–U03

У непарных людей неизвестен фактический объём лёгких на выдохе. Поэтому чистый P0 не должен выдавать одну геометрию с ложной уверенностью. Для каждого человека следует построить минимум три сценария:

1. `exhale_shallow` — неглубокий выдох;
2. `exhale_central` — центральная оценка;
3. `exhale_deep` — более глубокий выдох.

Спирометрии и других функциональных измерений нет. Объёмы обеих фаз P01–P03 вычисляются непосредственно по CT-маскам/STL. Для каждого парного человека определяются:

$$
V_{in}^{(i)}=V_{L,in}^{(i)}+V_{R,in}^{(i)},
\qquad
V_{out}^{(i)}=V_{L,out}^{(i)}+V_{R,out}^{(i)},
$$

$$
r_{tot}^{(i)}=\frac{V_{out}^{(i)}}{V_{in}^{(i)}},
\qquad
r_L^{(i)}=\frac{V_{L,out}^{(i)}}{V_{L,in}^{(i)}},
\qquad
r_R^{(i)}=\frac{V_{R,out}^{(i)}}{V_{R,in}^{(i)}}.
$$

В leave-one-subject-out fold для тестового человека $j$ отношение оценивается только по двум остальным:

$$
\hat r_{-j}=\operatorname{median}\left\{r^{(i)}:i\ne j\right\},
\qquad
\hat V_{out}^{(j)}=\hat r_{-j}V_{in}^{(j)}.
$$

При двух обучающих значениях median фактически является их серединой, поэтому оценка нестабильна. Её качество проверяется ошибкой объёма на каждом из P01–P03. Отдельно оцениваются total, left и right ratios.

Для финального расчёта лучше предсказывать $V_{L,out}$ и $V_{R,out}$ раздельно, а суммарный объём получать как их сумму. Нельзя одновременно навязывать три независимо оценённых ограничения $r_{tot}$, $r_L$ и $r_R$, если они противоречат друг другу; $r_{tot}$ в таком случае служит контрольной метрикой.

После перекрёстной проверки центральные объёмы U01–U03 вычисляются по медианам трёх парных отношений:

$$
\hat r=\operatorname{median}\left(r^{(1)},r^{(2)},r^{(3)}\right),
\qquad
\hat V_{out}^{(u)}=\hat rV_{in}^{(u)}.
$$

Три собственных значения не являются надёжной популяционной нормой. Поэтому это не «истинный объём выдоха», а dataset-specific prior. Он применим, только если протоколы вдоха и выдоха у всех шести людей сопоставимы.

Для определения ширины сценарного диапазона вычисляется максимальная leave-one-out ошибка отношения:

$$
\delta_r=\max_j\left|r^{(j)}-\hat r_{-j}\right|.
$$

Внутренний рабочий диапазон можно задать как $\hat r-\delta_r$, $\hat r$, $\hat r+\delta_r$ с проверкой физиологической допустимости и $0<r<1$. Это диапазон чувствительности малой выборки, а не статистический доверительный интервал.

Помимо трёх STL желательно сохранять среднюю поверхность и покомпонентную/повершинную карту разброса. Центральный STL является рабочей оценкой, а два крайних — границами чувствительности к неизвестной амплитуде дыхания.

### Контроль вычисления объёма из CT и STL

Основной объём считается по бинарной маске в физических координатах:

$$
V_{mask}=N_{vox}\,\Delta x\,\Delta y\,\Delta z.
$$

Для замкнутого ориентированного STL выполняется независимая проверка:

$$
V_{STL}=\frac{1}{6}\left|\sum_k
\mathbf a_k\cdot\left(\mathbf b_k\times\mathbf c_k\right)\right|,
$$

где $\mathbf a_k$, $\mathbf b_k$, $\mathbf c_k$ — вершины треугольника $k$. Перед расчётом STL должен быть watertight, manifold и иметь согласованную ориентацию граней. Расхождение $V_{mask}$ и $V_{STL}$ сохраняется как отдельная техническая погрешность; при большом расхождении объёмный prior не используется до исправления сетки.

### Разделение ошибки амплитуды и ошибки формы

На P01–P03 каждая модель запускается минимум в двух вариантах:

- **P0V:** использует $\hat V_{out}$, предсказанный из двух обучающих пар;
- **P1-oracle-volume:** использует истинный $V_{out}$ тестового человека, но не видит форму КТ выдоха.

P1-oracle-volume показывает, насколько хорошо модель воспроизводит **паттерн формы и перемещений при правильной амплитуде**. P0V показывает итоговую практическую ошибку, включающую ошибку оценки объёма. Разность результатов не является строго аддитивным разложением, но позволяет понять, проигрывает ли метод из-за неверного целевого объёма или из-за неправильной кинематики.

## 3. Что является ground truth

Парные КТ дают истинные поверхности и видимые ориентиры, но **не дают единственного истинного плотного DVF**. Между двумя томами нет измеренного соответствия каждого вокселя.

Поэтому эталонами следует считать:

1. независимо сегментированные поверхности органов на выдохе;
2. вручную или полуавтоматически размеченные парные ориентиры;
3. рёберные и позвонковые жёсткие трансформации;
4. объёмы органов и регионов;
5. при наличии — бронхиальные/сосудистые центролинии и междолевые щели.

Плотное эталонное поле можно создать только как **reference estimate**, например согласованным результатом нескольких DIR-алгоритмов с ручными ориентирами. Его нельзя называть истинным полем и нельзя валидировать алгоритм тем же методом, которым reference DVF был построен.

## 4. Подготовка данных

### 4.1. Проверка протокола съёмки

Для обеих КТ необходимо зафиксировать:

- положение пациента и рук;
- направление и шаг срезов, voxel spacing и reconstruction kernel;
- тип состояния: глубокий вдох, спокойный конечный выдох или максимальный выдох;
- задержка дыхания или свободное дыхание;
- контрастирование;
- наличие ЭКГ-синхронизации;
- время между исследованиями, изменение массы, комплекции и позы; возможная патология учитывается только как внешний confounder, а не как целевой индивидуальный признак.

Различия reconstruction kernel и дозы меняют текстуру и HU. Это особенно важно для intensity-based DIR и нейросетей. Геометрические метрики должны оставаться основными.

### 4.2. Начальное жёсткое совмещение

Сначала устраняется только различие укладки:

1. проверить DICOM-ориентацию и физические координаты;
2. выполнить rigid registration по позвоночнику или устойчивой части скелета;
3. визуально проверить позвонки и ориентацию таза/грудной клетки;
4. сохранить rigid transform отдельно от дыхательной деформации.

Нельзя оценивать дыхательную модель до устранения сдвига стола и поворота пациента. Одновременно нельзя affine-деформировать весь скелет: это удалит часть реальной рёберной кинематики.

### 4.3. Сегментация

Обе фазы сегментируются независимо с одинаковыми правилами:

- левое и правое лёгкие;
- доли и щели, если различимы;
- сердце/перикардиальный объём;
- позвонки, каждое ребро и грудина;
- наружная поверхность тела;
- диафрагмальные, костальные, медиастинальные и корневые зоны лёгких;
- трахея, главные бронхи и крупные сосуды, если качество позволяет.

Автоматические маски проходят слепой ручной контроль. Для оценки segmentation uncertainty полезно иметь повторную разметку части срезов или второго наблюдателя.

### 4.4. Ориентиры

Разметить ориентиры так, чтобы они покрывали весь объём, а не только центральные бронхи:

- бифуркации бронхов и сосудов;
- верхушки, корни и диафрагмальные отделы;
- передние и задние участки;
- каждую долю;
- рёберно-позвоночные и рёберно-грудинные точки;
- характерные точки сердца и средостения с учётом сердечной фазы.

Желательно 100–300 внутрилёгочных пар, распределённых по регионам. Часть ориентиров резервируется только для теста и не участвует ни в регистрации, ни в выборе параметров. Ошибка наблюдателя измеряется повторной разметкой.

## 5. Набор сравниваемых моделей

### 5.1. Обязательные отрицательные и простые baselines

| Код | Модель | Назначение |
|---|---|---|
| B0 | identity: никакого движения | показывает исходную амплитуду ошибки |
| B1 | rigid transform всего торакоабдоминального блока | отделяет дыхание от укладки |
| B2 | isotropic scale лёгких до предсказанного/оракульного целевого объёма | минимальный объёмный baseline |
| B3 | отдельные AP/ML/SI scales верхнего и нижнего отделов | физиологически более разумный геометрический baseline |
| B4 | отдельные rigid transforms рёбер + простое поле мягких тканей | baseline скелетной кинематики |

Сложная модель считается полезной, только если она стабильно превосходит эти варианты.

### 5.2. Геометрическое mesh-morphing

- thin-plate splines и RBF по контрольным точкам;
- B-spline free-form deformation;
- harmonic или linear-elastic extension поверхностных смещений;
- Laplacian mesh deformation;
- as-rigid-as-possible для рёбер/скелета;
- cage-based deformation наружной поверхности и органов;
- diffeomorphic stationary-velocity-field morphing.

Эти модели быстры и хорошо сохраняют детали исходного STL, но физичность зависит от контролов и регуляризации.

### 5.3. Классическая deformable image registration

- B-spline DIR с mutual information/NCC;
- Demons и log-domain/diffeomorphic Demons;
- SyN-подобная симметричная диффеоморфная регистрация;
- mass-preserving lung registration, учитывающая изменение аэрации;
- landmark-constrained DIR;
- sliding-aware/multi-organ registration;
- траекторная 4D-регистрация, если появятся промежуточные фазы.

DIR использует обе КТ и относится к режиму R. Она нужна как верхняя граница и для построения популяционных motion priors, но не является предсказанием по одной КТ.

### 5.4. Биомеханические модели

| Код | Вариант |
|---|---|
| M1 | однородная linear-elastic FEM |
| M2 | сжимаемая hyperelastic FEM: Ogden/Mooney–Rivlin |
| M3 | M2 + frictionless pleural contact |
| M4 | M3 + отдельные доли и междолевое скольжение |
| M5 | multi-organ: лёгкие, диафрагма, сердце/средостение, грудная стенка |
| M6 | M5 + артикулированные жёсткие рёбра и мягкотканное тело |
| M7 | poroelastic или coupled air–tissue модель, если нужна вентиляция, а не только геометрия |

Для P0 нагрузки и параметры фиксируются по внешней обучающей выборке/литературе. Для P0V разрешена оптимизация амплитуды давления и диафрагмальной тяги по объёму, предсказанному из обучающих пар. Для P1-oracle-volume используется истинный объём тестового выдоха только как диагностическая верхняя граница. Для C параметры можно идентифицировать по обеим КТ, но затем нужен новый независимый тест.

### 5.5. Статистические модели движения

- PCA/PPCA плотных DVF;
- statistical shape model вдоха и выдоха;
- CCA/PLS между поверхностью лёгких, внешним суррогатом и внутренним DVF;
- atlas transfer от ближайших по форме пациентов;
- mixture model разных дыхательных стратегий;
- Bayesian motion model с распределением допустимых полей.

Обучение проводится только на других субъектах. Предсказанное поле применяется к исходной геометрии пациента, чтобы не заменять индивидуальную форму средней анатомией.

Входные признаки statistical/deep-модели должны включать descriptors исходной комплекции: размеры тела и грудной клетки, AP/ML-отношения по уровням, объёмы лёгких, высоту диафрагмы, кривизну позвоночника и естественную асимметрию. Нормализация перед обучением допустима только с последующим точным возвратом в нативные физические координаты пациента.

### 5.6. Обучаемые модели

- VoxelMorph-подобная unsupervised registration;
- LapIRN/RRN и другие coarse-to-fine сети для больших деформаций;
- TransMorph/transformer-based registration;
- landmark-supervised и inverse-consistent сети;
- RMSim/ConvLSTM для генерации фаз из статической КТ и дыхательной кривой;
- adversarial DVF synthesis;
- implicit neural representation и neural ODE/diffeomorphic flow;
- physics-informed network или neural operator.

Сеть нельзя обучать на единственной паре и затем оценивать на ней. Допустим только внешний pretraining с полностью subject-disjoint test.

LungViT-подобное преобразование интенсивностей включается лишь как специальный контроль: оно может синтезировать экспираторную аэрацию в геометрии вдоха, но само по себе не выдаёт правильный STL выдоха.

### 5.7. Гибриды

- DIR/DL оценивает поверхностное поле, FEM распространяет его внутрь;
- statistical/DL prior предлагает параметры, FEM обеспечивает контакт;
- predicted DVF проецируется в диффеоморфное поле без складок;
- learned residual исправляет систематическую ошибку FEM;
- sparse X-ray/body-surface observations + mechanics;
- ensemble statistical prior + inverse FEM.

Гибридная модель — наиболее вероятный победитель P0V/P2, но это должно быть доказано benchmark, а не принято заранее.

## 6. Честная настройка моделей

### Для трёх парных случаев

Используется описанная выше трёхfoldовая leave-one-subject-out проверка. Поскольку в обучающей части каждого fold остаётся только два человека, полноценная внутренняя оптимизация гиперпараметров невозможна. Поэтому:

- основные параметры фиксируются по литературе или внешней выборке;
- число калибруемых на двух людях параметров должно быть малым;
- нельзя перебирать десятки конфигураций и выбирать лучшую по трём тестовым результатам без поправки на selection bias;
- все фазы одного человека всегда находятся только в одной части split;
- после каждого fold сохраняются prediction, конфигурация и ошибки до перехода к следующему.

Результат позволяет выбрать наиболее устойчивый метод для этой серии данных, но ещё не доказывает популяционную универсальность. Для такого вывода потребуется внешняя subject-level validation.

### Равные условия

- одинаковые исходные сегментации и rigid alignment;
- фиксированный список разрешённых входов для режима;
- одинаковая тестовая сетка ориентиров;
- одинаковый вычислительный/поисковый бюджет или явный отчёт о различии;
- несколько random seeds для обучаемых методов;
- сохранение всех конфигураций, версий ПО и причин отказа.

## 7. Метрики точности

### 7.1. Первичные

1. **TRE** независимых внутренних ориентиров: mean, median, SD, 95-й процентиль и maximum.
2. **ASSD** поверхностей органов и долей.
3. **HD95**, отражающий худшие локальные ошибки устойчивее обычного Hausdorff maximum.
4. Региональные TRE/ASSD отдельно для верхушки, корня, диафрагмы, передних/задних и верхних/нижних отделов.

TRE должен быть главным показателем внутреннего поля. Dice может оставаться высоким при неверной внутренней деформации большого органа.

### 7.2. Вторичные геометрические

- Dice/Jaccard органов и долей;
- абсолютная и относительная ошибка объёма;
- ошибка центра масс и principal axes;
- расстояния бронхиальных и сосудистых центролиний;
- ошибка положения купола диафрагмы;
- ошибки переноса/вращения каждого ребра;
- поверхностные карты signed distance.

Относительная объёмная ошибка считается отдельно для левого, правого и суммарного лёгкого:

$$
e_V=100\%\cdot\frac{\left|V_{pred}-V_{true}\right|}{V_{true}}.
$$

Для P0V дополнительно сообщается ошибка предсказанного отношения $\left|\hat r_{-j}-r^{(j)}\right|$. Для P1-oracle-volume объёмная ошибка solver должна быть близка к численному tolerance; оставшиеся surface/TRE ошибки относятся главным образом к форме и пространственному паттерну.

### 7.2.1. Метрики сохранения морфологической индивидуальности

- изменение длины и локальной кривизны каждого ребра: должно быть близко к нулю;
- сохранение формы тел позвонков и грудины;
- ошибка AP/ML-отношения грудной клетки по анатомическим уровням;
- сохранение исходной кривизны позвоночника после отделения дыхательного движения от укладки;
- ошибка толщины наружных мягких тканей и общего профиля тела;
- сохранение лево-правой асимметрии объёмов и форм;
- изменение индивидуальных расстояний «сердце–грудина», «сердце–позвоночник», «корень лёгкого–позвоночник»;
- spectral/curvature distance между исходным и деформированным STL в областях, которые не должны менять локальную форму;
- расстояние от результата до собственной исходной анатомии относительно расстояния до усреднённого шаблона: модель не должна становиться морфологически более похожей на другого человека, чем на себя.

Эти метрики считаются вместе с точностью относительно реального выдоха. Простое копирование вдоха хорошо сохраняет идентичность, но плохо моделирует дыхание; чрезмерно сильный population prior может хорошо воспроизводить среднюю кинематику, но терять комплекцию и позу. Победитель должен выполнять обе задачи.

### 7.3. Физическая допустимость

- доля и пространственное расположение $\det F\le0$;
- распределение Jacobian determinant;
- количество инвертированных тетраэдров;
- inverse-consistency error;
- bending/strain energy;
- объём и глубина взаимопроникновения органов;
- самопересечения поверхностей;
- нарушение жёсткости рёбер;
- нереалистичные локальные strains;
- разрывы/пережатие бронхиального дерева.

### 7.4. Изображенческие метрики

- NCC/local NCC;
- MAE в HU;
- SSIM;
- mutual information.

Они вторичны: при выдохе меняются доля воздуха и HU, поэтому хорошее совпадение интенсивности не гарантирует правильное соответствие ткани.

### 7.5. Практические метрики

- время расчёта и подготовки;
- потребление памяти;
- объём ручной работы;
- доля полностью успешных запусков;
- чувствительность к начальной сетке и гиперпараметрам;
- воспроизводимость между повторными запусками.

## 8. Особые источники ошибки

### 8.1. Сердце

Если КТ не ЭКГ-синхронизированы, разность форм сердца включает дыхание и разные фазы сердечного цикла. Нельзя всю разницу считать ошибкой дыхательной модели. Следует:

- отдельно оценивать центр/ориентацию и низкочастотную форму;
- сообщать cardiac-phase uncertainty;
- не ранжировать модели только по локальному surface distance сердца;
- при возможности использовать ECG-gated или повторные данные.

### 8.2. Сегментация

Поверхностная ошибка модели свёрнута с ошибкой сегментации. Нужны повторная разметка, perturbation masks или хотя бы оценка межнаблюдательной вариабельности.

### 8.3. Неполный вдох/выдох

Название фазы не гарантирует одинакового физиологического уровня. Реальные объёмы лёгких P01–P03 измеряются из масок и сообщаются вместе с результатом. P0V оценивает объём без тестового выдоха, тогда как P1-oracle-volume получает истинный объём; поэтому их ошибки и leaderboard разделены.

### 8.4. Поза и позвоночник

Поза является частью морфологической индивидуальности, но случайное различие укладки между двумя сканами — источник ошибки. Для каждого человека нужно разделить:

- **базовую субъект-специфическую позу**, которую сохраняют в прогнозе;
- **технический сдвиг/поворот на столе**, который устраняется rigid alignment;
- **реальное дыхательно-связанное изменение рёбер и позвоночника**, которое должна воспроизвести модель.

Нельзя выпрямлять позвоночник или приводить грудную клетку к средней позе atlas. Необходимо отдельно сообщить rigid vertebral alignment residual и различия положения рук/плеч.

### 8.5. Circular validation

Если ориентиры использованы в loss, они не могут быть тестовыми. Если одна DIR создала reference DVF, её нельзя объявить точной по совпадению с этим полем. Если КТ выдоха использована для подбора pressure/traction, итоговая ошибка на той же КТ является fitting error, а не prediction error.

## 9. Статистика и доверительные интервалы

- Основная единица независимости — пациент, не вершина сетки.
- При $n=3$ парных пациентах формальные p-values, Wilcoxon tests и Bland–Altman не дают надёжного вывода; их не следует использовать для объявления победителя.
- Для каждой модели показать метрики отдельно для P01, P02 и P03, затем median и min–max.
- Bootstrap по ориентирам или вершинам допустим только как оценка пространственной вариабельности внутри пациента, а не межпациентного confidence interval.
- Показать парные разности ошибок каждой модели относительно baselines для каждого из трёх людей.
- Статистическую значимость и Holm correction отложить до появления достаточно большой внешней выборки.
- Разницу меньше observer error или эффективного voxel resolution считать практически неразличимой.

Полезно разложить общую ошибку:

$$
\sigma_{obs}^2\approx
\sigma_{landmark}^2+
\sigma_{segmentation}^2+
\sigma_{alignment}^2+
\sigma_{model}^2.
$$

Это не строгая независимая дисперсионная модель, но хороший способ не приписывать алгоритму все наблюдаемые миллиметры.

## 10. Как выбирать победителя

### 10.1. Сначала — жёсткие критерии допуска

Модель исключается или получает отдельный статус failure, если она:

- создаёт инвертированные элементы или существенные области $\det F\le0$;
- вызывает анатомически невозможные пересечения;
- деформирует рёбра как мягкую ткань;
- систематически нарушает собственный целевой объём P0V/P1-oracle-volume;
- падает на заметной доле случаев;
- использует недекларированную информацию из КТ выдоха.

Численные tolerances фиксируются заранее с учётом voxel size, mesh resolution и numerical noise.

### 10.2. Затем — лексикографическое ранжирование

1. минимальный patient-level median/mean TRE;
2. среди статистически и практически эквивалентных — меньший HD95 и худшая региональная ошибка;
3. затем лучшая физическая допустимость и calibrated uncertainty;
4. затем устойчивость к perturbations и внешней выборке;
5. затем вычислительная стоимость и ручной труд.

Не следует сворачивать всё в один произвольный score до просмотра отдельных метрик: высокая Dice может скрыть folding, а гладкий DVF — большую ошибку у диафрагмы.

### 10.3. Pareto-победители

Итогом, вероятно, будут несколько победителей:

- **лучший P0** — прогноз только по вдоху;
- **лучший P0V** — применимый прогноз с объёмом, оценённым по обучающим парам;
- **лучший P1-oracle-volume** — диагностическая модель при истинном объёме, показывающая предел ошибки формы;
- **лучший P2** — минимально калиброванный индивидуальный метод;
- **лучший R** — точная парная регистрация;
- **лучший real-time**;
- **лучший interpretable/biomechanical**;
- **лучший uncertainty-aware**.

Если две модели различаются меньше погрешности разметки/разрешения, их следует объявить практически эквивалентными, а не выбирать победителя по третьему знаку после запятой.

|---|---:|---:|---:|---:|---:|---|

## 12. Рекомендуемый порядок реализации

1. Подготовить эталонные сегментации и тестовые ориентиры.
2. Выполнить rigid spine alignment и измерить реальные объёмы фаз.
3. Реализовать B0–B4 и единый модуль метрик.
4. Добавить три верхние границы R: B-spline, diffeomorphic и sliding-aware DIR.
5. Реализовать M1–M4: linear → hyperelastic → contact → lobar sliding.
6. Добавить M5/M6 для сердца, средостения и рёбер.
7. Обучить/подключить внешний statistical prior.
8. Подключить один сильный learned registration и один static-to-motion generator.
9. Реализовать hybrid prior + FEM.
10. Провести robustness/uncertainty analysis и только затем финальное ранжирование.

## 14. Вывод для имеющейся выборки

Три парных случая позволяют провести настоящую, хотя и малую, перекрёстную проверку. Три непарных случая являются целевыми для финальной генерации STL. Наиболее честная стратегия:

1. присвоить идентификаторы P01–P03 и U01–U03;
2. провести три leave-one-subject-out folds с закрытым выдохом тестового человека;
3. сравнить все семейства на одинаковых TRE, ASSD, HD95 и физических критериях;
4. выбрать не более 1–3 Pareto-лучших методов, учитывая большой риск нестабильности при $n=3$;
5. повторно калибровать выбранные методы на всех P01–P03;
6. для каждого U01–U03 построить shallow/central/deep STL и карту неопределённости;
7. для U01–U03 сохранить shallow/central/deep результаты, потому что истинный объём их выдоха неизвестен;
8. использовать внешние DIR-Lab/COPDGene/POPI и современные landmark datasets для проверки и расширения prior отношений объёмов.

Так можно выбрать победителя для данной серии данных, получить рабочие STL выдоха для U01–U03 и одновременно честно указать диапазон точности и главную неопределённость — неизвестную амплитуду их фактического выдоха.

## 15. Ближайший рабочий этап

### 15.1. Организовать исходные CT

Рекомендуемая структура:

```text
data_raw/
  P01/
    inhale_deep/dicom/
    exhale_max/dicom/
    exhale_quiet/dicom/       # если существует
  P02/
  P03/
  U01/
    inhale_deep/dicom/
  U02/
  U03/
```

Исходные DICOM не переименовываются и не изменяются. В отдельном `manifest.csv` фиксируются subject, phase, путь к серии, SeriesInstanceUID, voxel spacing, slice thickness, reconstruction kernel и комментарий о дыхательной команде.

### 15.2. Создать одинаковые labelmaps

Для каждой доступной фазы нужны бинарные маски:

```text
body.nii.gz
lung_left.nii.gz
lung_right.nii.gz
heart.nii.gz
skeleton_all.nii.gz
```

Если существующие STL вдоха получены без сохранённых масок, желательно повторно получить или восстановить labelmaps. Объёмы и большинство эталонных метрик надёжнее считать по маскам, а STL использовать для сеточного моделирования и surface metrics.

Для P01–P03 один и тот же segmentation workflow применяется к вдоху и максимальному выдоху. Нельзя вручную обрабатывать фазы принципиально разными методами: различие алгоритмов сегментации будет выглядеть как дыхательная деформация.

### 15.3. Экспортировать эталонные STL

Для каждой маски создаются STL без recenter, scale и произвольного поворота. Сохраняются:

```text
derivatives/P01/exhale_max/stl/body.stl
derivatives/P01/exhale_max/stl/lung_left.stl
derivatives/P01/exhale_max/stl/lung_right.stl
derivatives/P01/exhale_max/stl/heart.stl
derivatives/P01/exhale_max/stl/skeleton_all.stl
```

Аналогичная структура используется для вдоха и остальных людей.

### 15.4. Что можно делать с общим скелетом

На первом цикле общего скелета достаточно для:

- проверки координат;
- rigid registration по позвоночнику;
- оценки общей формы и позы;
- baselines B0–B3;
- проверки пересечений органов с костями.

Перед реализацией модели B4/M6 скелет следует разделить минимум на:

- отдельные позвонки;
- левое и правое ребро каждого уровня;
- грудину.

Разделение лучше выполнять на CT-labelmap, а не разрезанием уже сглаженного STL.

### 15.5. Как использовать спокойный выдох

Максимальный выдох остаётся основной конечной целью. Если спокойный выдох имеется у P01–P03, он используется как дополнительная независимая фаза:

- для проверки нелинейности зависимости «объём → форма»;
- для проверки промежуточного положения диафрагмы и рёбер;
- для валидации траектории FEM между вдохом и максимальным выдохом;
- для проверки, не переобучена ли модель только на крайнюю фазу.

Если спокойный выдох есть только у части людей, его результаты сообщаются отдельно и не смешиваются с основной трёхfoldовой метрикой максимального выдоха.

### 15.6. Критерий готовности к моделированию

Можно переходить к baselines и FEM, когда:

- все девять основных CT-серий правильно распределены: шесть вдохов и три максимальных выдоха;
- известен статус спокойных выдохов;
- для каждой основной серии есть пять согласованных масок и STL;
- подтверждены координаты и единицы;
- рассчитаны объёмы масок/STL;
- P01–P03 rigid-совмещены по позвоночнику;
- выполнен визуальный QC сегментаций.
