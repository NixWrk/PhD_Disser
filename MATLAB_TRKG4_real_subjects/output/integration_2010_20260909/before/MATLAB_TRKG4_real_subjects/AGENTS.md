# Локальные правила MATLAB/Python-моделей

- Это единственная активная папка MATLAB-моделирования проекта. Не создавать
  параллельный расчётный pipeline в другом каталоге.
- Каноническая точка входа для результатов, читаемых notebook-файлами, —
  `run_pipeline.m`. Карта стадий и артефактов находится в
  `docs/PIPELINE_FOR_NOTEBOOKS.md`.
- Активный MATLAB-код находится в `src/`, перенесённые проверенные функции — в
  `vendor_stl_eidors/`, Python-подготовка и QC геометрии — в `tools/`.
- `archive/MATLAB_investigation_NIX/` сохраняет происхождение раннего
  прототипа. Не добавлять архив на MATLAB path и не копировать его старые
  helper-файлы поверх активных версий.
- Все модели в этой папке выполняются MATLAB/EIDORS/Gmsh и Python-скриптами.
  Не приписывать существующим результатам отдельный расчёт COMSOL.
- STL, MSH, MAT, сигналы и медицинские исходные данные не коммитить. В Git
  хранить только код, обезличенные малые таблицы, документацию и безопасные
  контракты результатов. Абсолютные пути к DICOM в код не записывать; для
  локальной HU-визуализации использовать `KALMYKOV_DICOM_DIR` и
  предпочтительный корень внешних данных из корневого `AGENTS.md`.
- Перед принятием новой сетки проверять геометрию поверхности, объём,
  вырожденные/инвертированные тетраэдры, фактические положения электродов и
  теорему взаимности. Успешное завершение Gmsh само по себе не является QC.
- Для параметрического монтажа на руках принят файл
  `output/accepted_arm_parameter_mesh.msh`. Его статус подтверждается только
  отчётом `output/accepted_arm_parameter_mesh_acceptance.json`, полученным
  через `tools/verify_arm_parameter_mesh_acceptance.py`. Копии после
  `Relocate3D` отвергнуты из-за изменения границы и инвертированных элементов.
- Изменение точки входа или имени выходного файла одновременно отражать в
  `docs/PIPELINE_FOR_NOTEBOOKS.md` и в notebook-потребителе.
- Интерактивный выбор поверхностных координат предназначен для
  четырёхэлектродного монтажа ТТРКГ на любых требуемых участках внешней
  поверхности тела. Не использовать его для боковых сборок мягких тканей,
  РЕО32 или стандартной ТРКГ.
- Свободная расстановка четырёх именованных точек является основным режимом.
  Симметричный монтаж ТТРКГ является дополнительным режимом и задаётся равными
  расстояниями вдоль двух независимо размеченных поверхностных путей для сторон
  I+/V+ и I-/V-. Не отражать координаты XYZ. Первая точка каждого пути должна
  соответствовать выбранному пользователем анатомическому ориентиру. Для
  частного монтажа на руках таким ориентиром может служить граница
  «туловище–рука». HTML-координаты центров считать предварительными; точные
  центры повторно вычислять MATLAB на расчётной поверхности.
- В параметрическом тесте различать четыре варианта: четыре поверхностных
  диска 5 мм; четыре кольцевые манжеты 5 мм; четыре широкие манжеты 15 мм;
  смешанный монтаж `outer_planes_inner_rings`. По уточнению автора от
  08.09.2026 в последнем варианте только наружные токовые I+/I− являются
  поперечными плоскостями внутри цилиндров рук; внутренние измерительные
  V+/V− должны оставаться поверхностными манжетами 5 мм. Старый вариант
  четырёх плоскостей `cross_section_plane` исключён из действующей
  спецификации. Исторический `cross_section_equivalent` означает широкую
  манжету и не является плоскостью.
- В исследовании чувствительности `40.05` по решению автора вся маска сердца
  представляет эффективную смесь крови и миокарда. Это допущение не задаёт
  измеренную долю крови и не разделяет проводимости крови и миокарда.
  Паспорт, входные хэши и результаты этой серии находятся отдельно в
  `output/exploratory/arm_sigma_20260908`; её широкие тканевые диапазоны
  не интерпретировать как амплитуды сердечного цикла или обычного дыхания.
- Состав и параметры конкретного расчёта брать из
  `output/nik_trkg4_arm_electrode_model_tests_contract.json`. Для Nix
  используется маска сердца целиком; отдельная маска крови отсутствует.
