# Кажущееся ρ боковых сборок на индивидуальной однородной КТ-геометрии

Постановка от 06.11.2026: использовать уровни импеданса Scorpion на задержке
глубокого вдоха и получить отдельную зависимость ρ от размера сборки для
каждого из трёх добровольцев. Индивидуальная форма тела сохраняется; всем
пяти материалам присваивается одно неизвестное удельное сопротивление.
Размер L — номинальная токовая база A–B; потенциальная база M–N равна L/2.

## Данные и выбор записей

Подготовщик [scorpion_apparent_resistivity.py](../MATLAB_TRKG4_real_subjects/tools/scorpion_apparent_resistivity.py)
читает собственные входы каждого участника из `fem_smart_20261026`. Используются
только строки бокового канала для вдоха с прежним статусом
`eligible_conditional`. Контрольные записи переключения, перекрёстные монтажи
и записи одной подключённой сборки с другим физическим CEM-сценарием не
добавляются автоматически. Все исключения записываются в локальный план.

Медианы заново вычисляются из исходных TXT в прежних внутренних окнах
вдоха. Проверяются SHA-256, физический канал, границы отсчётов и совпадение
со снимком уровней в пределах 10⁻⁸ Ом. Границы полуоткрытые: [начало, конец).
Считываются 11 именованных полей экспорта; конечный табулятор строки не
должен сдвигать BEI к соседней фазовой колонке. Поле BEI используется как
скалярный импеданс в Ом при 100 кГц, комплексная фаза не инвертируется.

Дыхательная разметка остаётся кандидатной. Разные размеры записаны
последовательно; состояние дыхания, контакт и повторная установка не
имеют установленной межзаписной воспроизводимости. При разных соединениях
ТТРКГ точки сохраняются отдельно, даже если L одинаково.

## Физический расчёт

[Профиль MATLAB](../MATLAB_TRKG4_real_subjects/src/run_scorpion_apparent_resistivity.m)
вызывается через `run_pipeline.m` и использует неизменённое ядро
`trkg4_lateral_cem_response`. Подготовленные операторы EIDORS уже выражены
в СИ. Однородная объёмная матрица равна

\[
K(\rho)=\frac{1}{\rho}\sum_{k=1}^{5}K_k^{(\sigma_k=1)}.
\]

Сохраняются индивидуальная сетка, конечные контакты, их исходные группы
и физически присутствующие пассивные площадки. Возбуждается боковая
пара A–B; измеряется M–N. Токи +1 и −1 А дают нормированный импеданс.
Ток другого канала к нему не прибавляется. КТ-туловище индивидуально;
цилиндрические продолжения рук и положение электродов наследуются как
модельный сценарий, а не как измеренные координаты данной регистрации.

При фиксированном контактном сопротивлении полный CEM-оператор имеет вид

\[
H(\rho)=C+\operatorname{diag}(K_0/\rho,0).
\]

В используемых входах контактный параметр равен 0,01 Ом·м². Он задан
сценарно, не измерен независимо и не масштабируется вместе с ρ. Поэтому
простое отношение измеренного Z к отклику при ρ = 1 Ом·м используется
только для начального приближения. Окончательное кажущееся ρ — положительное
решение уравнения

\[
Z_{\mathrm{CEM}}(\rho_{\mathrm{каж}})=Z_{\mathrm{вдох}}.
\]

Применяется метод Ньютона по lnρ с производной канонического ядра,
максимум шесть уточнений. Допуск воспроизведения фиксирован заранее:
10⁻⁵ Ом + 10⁻⁷|Zвдох|. Он относится к численному решению; погрешность
измерений этим допуском не задаётся. Положение электродов не подбирается.

Для каждого решения проверяются невязка полной CEM-системы < 10⁻⁷ и
взаимность < 10⁻⁷ Ом. Сверяются принадлежность матриц участнику, хеши
сетки, CEM и ядра, согласие координат мм/м, симметрия и совпадение сумм
материалов q1024/q4096 с относительным допуском 10⁻¹². Последняя проверка
проверяет устранение тканевых различий; глобальная сеточная сходимость
для этих моделей не установлена.

## Воспроизведение и графики

Команды выполняются из корня проекта. `NEW_RUN` и `NEW_FIGURES` должны
обозначать новые локальные каталоги. Медицинские входы и индивидуальные
производные остаются в исключённых из Git областях.

```text
python -B MATLAB_TRKG4_real_subjects/tools/scorpion_apparent_resistivity.py prepare --model-root Experiments/scorpion_20261022/derived/exploratory/fem_smart_20261026 --out NEW_RUN/inputs
python -B MATLAB_TRKG4_real_subjects/tools/scorpion_apparent_resistivity.py run --plan NEW_RUN/inputs/input.local.json --out NEW_RUN/fem --matlab MATLAB_EXECUTABLE
python -B "Colab Notebooks/scorpion_v2/plot_apparent_resistivity.py" --plan NEW_RUN/inputs/input.local.json --results NEW_RUN/fem/results.local.json --out NEW_FIGURES
```

Для запуска 06.11.2026 план находится в
`MATLAB_TRKG4_real_subjects/output/exploratory/scorpion_apparent_20261106/inputs_v2/`,
решения — в соседнем `fem/`. Итоговые графики, таблица и описание — в
`Experiments/scorpion_20261022/derived/exploratory/apparent_resistivity_20261106/`.
Оба каталога локальные; сохранённый исходник подготовщика связан с планом
через SHA-256. MATLAB получает отдельный каталог настроек данного запуска
через `MATLAB_PREFDIR`; пользовательские настройки не переписываются.

[Читатель графиков](../Colab%20Notebooks/scorpion_v2/plot_apparent_resistivity.py)
сверяет принадлежность результата плану и полноту наблюдений, сохраняет
по одному PNG/SVG для каждого участника, CSV и описание с формулами.
В HTML таблицы первоначально свёрнуты. Линиями соединяются только точки
с одинаковыми соединениями ТТРКГ; значения между размерами не измерены.

Кажущееся ρ характеризует эквивалентный однородный объём при заданных
геометрии и контактах. Оно не разделяет свойства тканей; изменение ρ с L
само по себе не устанавливает причину расхождения с однородной моделью.
Неопределённость дыхания, координат, контактного параметра и сеточного
приближения ограничивает количественную интерпретацию.
