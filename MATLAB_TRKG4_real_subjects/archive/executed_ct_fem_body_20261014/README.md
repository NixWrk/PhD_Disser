# Исходники выполненной проверки КТ-контура

Каталог сохраняет точные байты двух версий: численной диагностики контура
и последующего построения рисунка с русскими подписями. Их контрольные суммы
связаны с сохранёнными результатами от 14.10.2026. Исходные КТ, маски,
локальные конфигурации и численные массивы сюда не включены.

Эти файлы сохраняют происхождение результата и не являются новой точкой
запуска. Архив нельзя добавлять к путям Python или MATLAB. Для повторения
исторического вычисления восстанавливают соответствующие исходники в
исходной структуре проекта и проверяют входные контрольные суммы.

В численной версии общий скрипт ещё использовал неоднозначный допуск
расстояния. Неудачная проверка при 1,25 мм сохранена; действующий интерфейс
различает коррекцию контура и точность экспорта исправленной поверхности.
