## Библиография: назначение стандартов

ГОСТ 7.32-2017 задаёт структуру отчёта, нумерацию и размещение ссылок.
Он содержит нормативную ссылку на ГОСТ 7.1-2003. Не заменять эту ссылку
молчаливо другим стандартом и не считать разные виды библиографического
оформления взаимозаменяемыми.

В [официальном перечне РГБ, подкомитет ПК 2](https://www.rsl.ru/nauka/deyatelnost-po-standartizatsii/podkomitet-pk-2-bibliotechnoe-delo-i-bibliografiya/)
приведены стандарты для следующих задач:

| Стандарт | Область применения при подготовке записи |
| --- | --- |
| ГОСТ Р 7.0.100-2018 | Библиографическое описание источника |
| ГОСТ Р 7.0.5-2008 | Библиографическая ссылка |
| ГОСТ Р 7.0.12-2011 | Сокращения русских слов и словосочетаний |
| ГОСТ Р 7.0.80-2023 | Заголовок библиографической записи |

Этот перечень устанавливает назначение документов, но не заменяет их
тексты. Для спорного оформления конкретной записи проверять соответствующий
пункт стандарта. Не выдумывать отсутствующие DOI, номера выпусков, страницы,
место издания или реквизиты диссертации. Выбранные правила описания применять
единообразно ко всему списку; наличие DOI само по себе не делает запись
полной или правильно оформленной.

Нормативные документы этого каталога предназначены для подготовки отчёта.
Автоматически добавлять их в список научной литературы отчёта не следует.
