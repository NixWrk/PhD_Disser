# Последовательное восстановление костей и сердца

Опыт входит в раздел 5.4 ноутбука [33.09](../../../../Colab%20Notebooks/33.09_Выбор_размеров_и_числа_боковых_сборок.ipynb). Проверяется замена органов мягкими тканями при фиксированных индивидуальной КТ, положении C01 и конечных контактах диаметром 5 мм. Сначала выделяется кость, затем сердце; новая локализация и жир не рассчитываются.

Параметры взяты из [IT’IS V5.0](https://itis.swiss/virtual-population/tissue-properties/downloads/database-v5-0), DOI 10.13099/VIP21000-05-0, с [дисперсионными зависимостями Gabriel](https://itis.swiss/virtual-population/tissue-properties/database/dielectric-properties). Кость представлена кортикальной костью, вся маска сердца — сердечной мышцей. Кровь, костный мозг и губчатое вещество отдельно не выделены. Эти назначения являются допущениями.

## Файлы

- plan.json, requests.csv, literature_values.csv — условия, входные точки, происхождение параметров.
- material_inventory.csv — число элементов и объёмы материалов.
- responses.csv, execution.json — 108 основных прямых решений и 27 решений при равенстве свойств органов и фона.
- derivative_qc.json — центральные разности по четырём логарифмам сопротивлений, ещё девять решений.
- comparison.csv, metrics.csv, increments.csv — сравнение с экспериментом и последовательные эффекты органов.
- local_inverse_diagnostic.csv — локальная оценка смещения параметров.
- synthetic_inverse.csv, synthetic_inverse_predictions.csv — нелинейное восстановление известных сопротивлений после замены органов фоном, при 50 кГц.
- synthetic_inverse_qc.json, synthetic_inverse_validation.json — условия и проверка синтетического восстановления.
- comparison.html, comparison.png — интерактивный график и изображение при 50 кГц.
- qc.json — контроль согласованности основного опыта.

MAT-файлы содержат индивидуальную геометрию или её производные и остаются локальными. Они необходимы для повторного FEM-расчёта.

## Воспроизведение

Рабочая папка — MATLAB_TRKG4_real_subjects. В чистом каталоге результатов последовательно выполняются:

~~~matlab
run_pipeline('Profile','lateral_tissue_ablation','Stage','export');
~~~

~~~powershell
python tools/lateral_tissue_ablation.py --prepare
~~~

~~~matlab
run_pipeline('Profile','lateral_tissue_ablation','Stage','solve');
run_pipeline('Profile','lateral_tissue_inverse_probe');
~~~

Проверка сохранённых решений и построение представлений:

~~~powershell
python tools/lateral_tissue_ablation.py
python tools/lateral_tissue_inverse_analysis.py
python notebooks/build_lateral_array_design.py
python tools/verify_lateral_tissue_report.py
~~~

Подготовка отказывается перезаписывать существующий план. Для нового каталога MATLAB-стадии принимают OutputDir; функции Python prepare(out), analyze(out) и figure(out) — соответствующий путь. Завершённые решения сохраняются с контрольными суммами.

Нелинейный тест использует два начальных приближения для каждой подгонки и прямое FEM-решение на каждой итерации. Диапазон ρ₁ — 1,377–10 Ом·м; диапазон ρ₂ — 3,817–24,074 Ом·м, включая оба табличных состояния лёгкого. Это границы сценария, не индивидуальные физиологические нормы. Синтетические результаты не являются оценками сопротивлений добровольца.

## Ограничения и продолжение

Геометрия вдоха фиксирована в обоих электрических состояниях; deflated условно сопоставлено выдоху. Диаметр 5 мм является расчётным сценарием, а не установленным размером исторического контакта. Используются действительные изотропные проводимости и постоянное контактное сопротивление. Глобальная сеточная сходимость и перенос на других людей не проверены.

Сохранён приоритет текущей замкнутой маски лёгкого над девятью исходными костными элементами общим объёмом 0,540 мл. В результате ткани образуют непересекающееся разбиение, а исходная двухтканная задача воспроизводится.

После проверки жира локализация должна совместно подбирать положение и общую пару сопротивлений по всем базовым Z одного состояния. Для каждого положения сопротивления минимизируют общую невязку, после чего сравниваются положения. Отдельная пара под каждый скалярный Z не определима. При известной КТ h вычисляется для каждого кандидата положения; независимую свободную толщину автоматически не добавляют.
