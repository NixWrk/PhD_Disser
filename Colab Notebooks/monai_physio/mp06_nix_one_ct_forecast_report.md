# MP-06/07. Готовая модель движения по одной КТ Ника

**01.10.2026. Статус: прямой вычислительный опыт завершён; прогностическая точность и анатомическая пригодность не подтверждены.** Это проверка готовых весов сердца MONAI Physio/PhysicsNeMo из выпуска `2026.07.3` через интерфейс `2026.09.1`. Обучения и дообучения на данных проекта не было.

## Вход и разделение данных

- Единственный индивидуальный вход для модели: КТ Ника, серия 307, фаза `00`, и полученная из неё автоматическая поверхность `whole_heart` TotalSegmentator v2. Готовый PCA-шаблон и веса сети взяты из официального исторического выпуска; файл PCA проверен по полному SHA-256 `903a68ab9483345247bbe27bb256c0f2621e6e80ee92e525eb1d47a1e1a3962e`.
- По фазе 00 выполнены аффинное ICP и подгонка 15 коэффициентов PCA. Остальные фазы не использовались ни в подгонке, ни в настройке весов. Сначала проверены заранее выбранные 01, 03, 07 и 08; затем **без изменения подгонки, весов и метрики** экран расширен до всех восьми доступных целевых фаз с номинальным значением <100%. Их отдельные автоматические маски открывались только при оценке замороженного прогноза.
- Номинальные доли R–R взяты из DICOM: `0,14` у исходной 00; `0,23/0,33/0,43/0,53/0,62/0,72/0,82/0,92` у целевых 01–08. Прогноз относительного движения получен как разность сетевых смещений в целевой доле и в `0,14`. Фазы с номинальным значением ≥100% не подавались в модель, рассчитанную на шкалу 0–1.
- Контроль: **та же** подогнанная поверхность фазы 00, оставленная неподвижной. Метрика: среднее из двух направлений ближайшего расстояния между поверхностями, в мм; дополнительно объединённый 95-й процентиль. Оптимизация и оперативный QC использовали каждый 16-й узел; **итоговая оценка ниже пересчитана по всем вершинам** замороженных поверхностей без повторной подгонки или сетевого вывода. Это оценка геометрической близости, а не ошибка соответствующих анатомических точек.

## Результат

Подгонка исходного шаблона к фазе 00 дала среднюю симметричную дистанцию **4,384 мм по всем вершинам** (`4,935 мм` при шаге 16 в оперативном QC). Аффинная часть имела определитель `1,041` и сингулярные числа `1,051/1,032/0,959`; грубого схлопывания она не создала. По прореженному QC PCA уменьшила среднюю дистанцию относительно аффинного ICP лишь с `5,093` до `4,935 мм`. Метрики с разной плотностью узлов не следует вычитать друг из друга.

Меньшая дистанция лучше. Сеть улучшила совпадение на фазах 02/06/07/08 и ухудшила на 01/03/04/05. Среднее по всем восьми целевым фазам: неподвижная форма `4,509 мм`, прогноз `4,483 мм`, разница `−0,026 мм` (**0,58%**). Таким образом, по выбранной метрике и всем фазам внутри диапазона модели **практического выигрыша нет**. Оперативный расчёт с прореживанием дал `5,0434 → 5,0417 мм`; знак вывода сохранился. Кроме того, исходная подгонка ошибается на несколько миллиметров, а принятой ручной анатомической разметки нет.

**Ключевое ограничение:** исторический PCA-шаблон представляет собственную тканевую геометрию Duke Heart, а наша целевая маска — наружную `whole_heart` TotalSegmentator v2. Совпадение анатомического определения и точечных соответствий между ними не доказано. Поэтому даже численно полученные сетевые смещения не считаются достоверной персональной кинематикой. Автоматические маски целевых фаз независимы от сетевого прогноза, но не являются ручной анатомической истиной. Неизвестные различия дыхания и фазовой привязки остаются отдельными источниками ошибки.

**Решение для методики:** в текущем виде готовую модель не передавать как проверенную движущуюся геометрию в FEM и не делать выводов об УО/ФВ. Новое обучение на данных проекта не требуется для этого отрицательного решения. Для пересмотра нужны анатомически совместимая готовая модель/шаблон и независимая разметка целевых фаз, затем повторное сравнение с неподвижным контролем и одинаковая FEM-постановка.

Локальный 3D-лист фазы 07 — `runs/mp06_nix_one_ct_forecast/phase_07_3d_comparison.png`: слева неподвижная подогнанная форма, справа прогноз; полупрозрачная голубая поверхность — отдельная TSv2-маска фазы 07, цвет формы показывает ближайшее расстояние до неё (0–15 мм). Это визуальный QC уже измеренной геометрии, а не дополнительная анатомическая валидация. Файл остаётся вне Git.

## Воспроизведение и происхождение

[Код опыта](mp06_nix_one_ct_forecast.py) запускается по шагам: `prepare` читает только фазу 00, `predict` загружает сохранённую подгонку и делает сетевой вывод, `evaluate-full` независимо пересчитывает финальную метрику по сохранённым поверхностям, `render` создаёт локальный 3D-лист. Аргумент `--subject-root` задаёт локальное хранилище; для `prepare`/`predict` нужен `--model-dir`. Сетевой адаптер — техническое переименование двух исторических полей метаданных без изменения весов. Официальная PCA-модель, веса, индивидуальные поверхности, коэффициенты PCA и полный JSON прогона хранятся только в исключённом из Git `runs/`. Этот отчёт содержит обезличенные агрегаты. Внутренний JSON прогона: `runs/mp06_nix_one_ct_forecast/fit.json`, `prediction.json` и `prediction_full.json`.

Ни КТ, ни маски, ни индивидуальные поверхности в Git не добавлены. Доступность исторических файлов и совместимость API установлены [проверкой загрузки весов](mp06_legacy_checkpoint_smoke.json); этот технический тест не служит проверкой качества движения.
