# Прямая проверка при 100 кГц и сравнение с 50 кГц

Результат включён в [раздел 5.3 ноутбука 33.09](../../../../Colab%20Notebooks/33.09_Выбор_размеров_и_числа_боковых_сборок.ipynb). [Интерактивный график](frequency_comparison.html), [PNG](frequency_comparison.png), [числа для каждой сборки](frequency_comparison.csv).

Дополнительно выполнены 36 прямых FEM/CEM-решений при литературных свойствах тканей для 100 кГц. Использованы те же КТ-геометрия, монтаж C01, две формы лёгкого и четыре конечных контакта диаметром 5 мм. При каждой частоте рассмотрены два табличных состояния лёгкого. Модель резистивная: меняются действительные проводимости тканей; диэлектрическая составляющая и частотная зависимость контактного сопротивления не включены. Это сравнение расчётных сценариев с одними экспериментальными наблюдениями, а не двух измерительных частот.

При 100 кГц приняты ρ₁ мышцы = 2,7636 Ом·м; ρ₂ лёгкого = 9,3153 Ом·м для inflated и 3,6817 Ом·м для deflated. Категория deflated не установлена как эквивалент выдоха добровольца. Присвоение свойств мышцы всему внелёгочному фону остаётся допущением. Источник — [IT’IS V5.0](https://itis.swiss/virtual-population/tissue-properties/downloads/database-v5-0), [частотные зависимости Gabriel](https://itis.swiss/virtual-population/tissue-properties/database/dielectric-properties). Строки исходной таблицы и рассчитанные свойства обеих частот приведены в `frequency_values.csv`.

Повышение частоты уменьшило прогнозируемые импедансы на 2,76–2,88%, поэтому расхождение с более высокими экспериментальными уровнями немного увеличилось. Для исходной КТ-маски среднее абсолютное относительное расхождение составляет 53,9% на вдохе и 53,0% при условном сопоставлении deflated с выдохом. Проверены только заданные литературные пары; вывод о невозможности восстановления любых физиологически допустимых сопротивлений не следует.

## Повторение

Команды выполняются из `MATLAB_TRKG4_real_subjects`. При наличии замороженного плана подготовка не перезаписывает его. Для независимого прогона нужно задать новый каталог через `--out` и тот же путь запроса в MATLAB. Сравнительный скрипт и канонический ноутбук читают указанные в них каталоги 50 и 100 кГц.

```powershell
python tools/lateral_literature_forward.py --prepare --frequency-hz 100000 --out output/exploratory/lateral_literature_100khz_20260916
```

```matlab
run_pipeline('Profile','lateral_array_design','RequestsFile','output/exploratory/lateral_literature_100khz_20260916/points.csv');
```

```powershell
python tools/lateral_literature_forward.py --collect --out output/exploratory/lateral_literature_100khz_20260916
python tools/lateral_literature_frequency_comparison.py
python notebooks/build_lateral_array_design.py
```

Неизменённое MATLAB-ядро сначала сохраняет три файла `points_responses.csv*` в каталоге библиотеки `lateral_array_design_20260916`. Параметр `--collect` проверяет идентичность запроса и завершение расчёта, затем переносит только эти файлы в каталог 100 кГц без перезаписи существующего результата. Исходные КТ, FEM-матрицы и наблюдения читаются на месте по контрольным суммам.

Для повторения только таблиц и сравнительного графика достаточно `python tools/lateral_literature_frequency_comparison.py`: старые FEM-решения сохраняются. Требуются NumPy, pandas, Plotly и Playwright с Chromium; для нового FEM — MATLAB и действующее окружение EIDORS. Допуски невязки и взаимности заданы исходным контрактом. Глобальная сходимость по сетке и физическая валидация двухтканной модели не объявляются выполненными.
