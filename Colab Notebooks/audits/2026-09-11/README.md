## Повторение лёгких проверок

Из корня репозитория:

```powershell
python -X utf8 "Colab Notebooks/audits/2026-09-11/repository_inventory.py"
python -X utf8 "Colab Notebooks/audits/2026-09-11/check_traceability.py"
```

Первый скрипт использует стандартную библиотеку и Git. Он читает метаданные
файлов и JSON ноутбуков, не исполняет расчёты и записывает локальный
`inventory.local.json`. Полный локальный инвентарь и каталог `private`
в Git не включаются.

Второй скрипт использует NumPy и BeautifulSoup4 из рабочего окружения.
Он проверяет обычные Python-ячейки, структуру HTML и локальные ссылки;
из 50.01 исполняется только проверяемая функция на синтетическом операторе.
Скрипт перезаписывает `checks.json` результатом текущего состояния. Поиск
Markdown-ссылок эвристический: найденные кандидаты требуют ручной проверки.
В сохранённом результате `t-tau_m` является математическим обозначением,
а не пропавшим файлом. Научные ноутбуки целиком не запускаются.

Команда основного набора тестов выполняется из папки `Colab Notebooks`:

```powershell
python -X utf8 -m pytest tests -q
```

Сохранённые 34 успешных теста относятся к состоянию исходников базовых
коммитов. Они не покрывают все выявленные ошибки передачи артефактов и
не являются физической, анатомической или экспериментальной валидацией.

## Сохранение и последующее переоформление

Три базовых коммита разделяют FEM, текущие ноутбуки с документацией и
исторические авторские отчёты. В них вошли 434 изменённых или новых пути.
Контроль SHA-256 подтвердил неизменность всех 385 включённых `.ipynb`,
`.html`, `.py` и `.m` относительно снимка до аудита. Существовавшие крупные
первичные данные и локальные конфигурации не добавлялись.

Изменения самого аудита ограничены отчётами, реестром, лёгкими проверками
и навигацией. Численные алгоритмы, ячейки научных ноутбуков и сохранённые
результаты не исправлялись. Замечания следует устранять отдельными
содержательными коммитами с проверкой конкретного дефекта.
