Владелец расчёта —
[analyze_subtraction_and_rr.py](../analyze_subtraction_and_rr.py).
Он читает внешние `phases/conversion_manifest.json`, `automatic_masks_v2`,
`products_v2`, сводку временных метаданных КТ и свидетельства GE ECG Report.

| Артефакты | Назначение |
|---|---|
| `*_heart_minus_blood_4d.html` | Синхронный просмотр 3D-геометрии, временной координаты и объёмов |
| `*_chamber_volumes_rr.html` | Отдельные графики объёмов |
| `cardiac_dicom_metadata_by_subject.csv`, `cardiac_gating_source_data.csv` | Метаданные КТ и отдельные интервалы из R-меток GE |
| `chamber_volumes_by_rr.csv` | Объёмы по реконструированным фазам |
| `chamber_volume_changes_measured_cycles.csv` | Изменения между имеющимися фазами отдельных циклов |
| `chamber_volume_changes_closed_cycle.csv`, `chamber_volume_changes_closed_cycle_summary.csv` | Модельные периодические профили и сводка; Georg не включён в композит |
| `rr_and_subtraction_summary.json` | Происхождение расчёта, определения, ограничения и статусы |
| `ecg_traces/*.png`, `ecg_traces/manifest.json` | Растровые полосы GE; готовит отдельно `extract_deidentified_ecg_trace.py` |

`ecg_traces` содержит растровое представление, а не калиброванную цифровую
ЭКГ. Эта папка относится к кардиосинхронизации КТ и не является результатом
детектора R-зубцов реокардиомониторов серии `11`.

Файлы notebook/HTML `21.03` находятся уровнем выше. Их iframe-ссылки требуют
сохранения этой папки рядом с ними. Команды воспроизведения и различия между
raw-объёмами, обработанной кровью и 3D-поверхностями приведены в `21.00`.
Автоматические маски остаются кандидатными; геометрический остаток
«сердце минус кровь» не является валидированным полным миокардом.
