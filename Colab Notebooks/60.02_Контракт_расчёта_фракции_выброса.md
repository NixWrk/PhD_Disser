# 60.02 Контракт расчёта фракции выброса

## Статус и определение

Фракция выброса сейчас не рассчитана. Для одного выбранного желудочка и одного
сердечного цикла

\[
EF = \frac{EDV-ESV}{EDV}=1-\frac{ESV}{EDV}.
\]

Внутреннее представление `EF_fraction` безразмерно; `EF_percent` равно
`100 × EF_fraction`. Амплитуда ТТРКГ и изменение эффективной сферы всего сердца
не являются ФВ.

## Допустимые входы

Входом может быть только результат `60.01` со строго одним из статусов:

- `stroke_volume_candidate_with_uncertainty` — для разработки и проверки;
- `validated_stroke_volume_estimate` — после внешней валидации.

Не используется формулировка «статус не ниже»: остальные строки отклоняются.
Вход должен содержать один `chamber_id`, один `cycle_id`, принятые времена ED/ES,
`EDV_mL`, `ESV_mL` и их ковариационную матрицу.

## Область определения и физические ограничения

Расчёт разрешён только при конечных значениях

\[
EDV>0,\qquad ESV\ge0,\qquad ESV\le EDV.
\]

Отсюда для физически согласованного кандидата \(0\le EF\le1\). Нарушение
условий — причина отказа и отдельный QC-флаг, а не повод обрезать результат к
диапазону `[0, 1]`.

## Неопределённость

Для \(f(EDV,ESV)=1-ESV/EDV\)

\[
\frac{\partial f}{\partial EDV}=\frac{ESV}{EDV^2},\qquad
\frac{\partial f}{\partial ESV}=-\frac{1}{EDV}.
\]

При градиенте \(\mathbf g\) и принятой ковариации \(\Sigma_{EDV,ESV}\)

\[
\operatorname{Var}(EF)=\mathbf g^T\Sigma_{EDV,ESV}\mathbf g.
\]

Для широкой или негауссовой неопределённости требуется Монте-Карло по совместной
модели без независимого перемешивания EDV и ESV. Метод, число выборок и критерий
сходимости фиксируются в манифесте результата.

## Выход

Результат содержит `chamber_id`, `cycle_id`, `EDV_mL`, `ESV_mL`,
`EF_fraction`, `EF_percent`, неопределённость, времена фаз, хэши входов и один
из статусов:

- `ejection_fraction_candidate_with_uncertainty`;
- `validated_ejection_fraction_estimate`.

Второй статус разрешён только после прохождения предзарегистрированной внешней
валидации `60.03` на независимой выборке.
