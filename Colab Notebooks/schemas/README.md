# Машиночитаемые контракты

Схемы фиксируют минимальную структуру внешних обезличенных манифестов для серии 40.
Они не принимают научный результат автоматически: статус `accepted` присваивается
только после содержательного QC. Уникальность составных ключей, совпадение массивов
по длине и физические ограничения дополнительно проверяются кодом ноутбуков.

- `record_manifest.schema.json` — точный набор записей и фактически активных каналов;
- `fem_operator_index.schema.json` — соответствие каждой записи и режима внешнему FEM-оператору;
- `fem_sensitivity_operator.schema.json` — прослеживаемость полного регионального FEM-оператора;
- `uncertainty_budget.schema.json` — полный бюджет для остатка 40.21.

- `source_identifiability_operator.schema.json` — точная FEM-привязка и критерии целевой оцениваемости серии 50;
- `volume_estimation_contract.schema.json` — оператор перехода от остатка к объёму одного желудочка;
- `validation_preregistration.schema.json` — замороженный до анализа протокол внешней валидации.
