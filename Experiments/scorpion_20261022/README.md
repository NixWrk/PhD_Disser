# Scorpion: Ник и Ярослав, 22.10.2026

Самостоятельная сессия двух участников. Прибор — Scorpion; аппаратная ревизия
в поставленном архиве отдельно не установлена. Дата следует из имени папки
и связанных BIN. Площадка этой сессии отдельно не подтверждена.

Получены 8 TXT Ника, 7 TXT Ярослава и два относящихся к этой дате BIN из
архива автора. Исходники сохранены в локальном `raw/` без изменения байтов.
Внутри архивной папки с именем Георгия найдены октябрьские BIN; их участки
связаны с новой сессией полным совпадением COUNT и обоих ЭКГ-полей всех
15 TXT. Имя папки не используется для определения участника.

Подтверждения автора от 23.10.2026 приведены в [протоколе](PROTOCOL.md).
[Реестр](RECORDINGS.md) сохраняет все записи. Фотографии описаны отдельно
в [указателе](PHOTOS.md). Техническая инвентаризация остаётся локальной:
`metadata/inventory.local.json`, происхождение архива —
`metadata/archive_inventory.local.json`. Эти конфигурации не публикуются.
`record_identity.json` закрепляет идентификаторы за относительными путями
и хэшами; повторное копирование файлов не назначает им новые дыхательные окна.

Единый [ноутбук 33.40](../../Colab%20Notebooks/scorpion_v2/33.40_Ник_и_Ярослав_эксперимент_и_модели_Scorpion_22_10_2026.ipynb)
и его [HTML без кода](../../Colab%20Notebooks/scorpion_v2/33.40_Ник_и_Ярослав_эксперимент_и_модели_Scorpion_22_10_2026.html)
содержат проверку сигналов, сравнение сборок и дыхательных уровней, четыре
кандидатных цикла на вдохе, двуслойную диагностику боковых сборок и
сопоставление двух независимых размеров Ника с реокардиомонитором МГТУ.

Дыхательная и ЭКГ-разметка находятся в `annotations/session_1140/`, имеют
владельца 11.40 и статус `pending_manual_review`. Все расчёты по ним имеют
статус `exploratory_hypothesis_not_validated` и находятся в
`derived/exploratory/session_3340/`. Входная проверка индивидуальных КТ
выполнена отдельно по единому стандарту. Наличие масок не означает готового
FEM-прогноза или принятого сопротивления тканей.

Для воспроизведения из корня проекта нужны локальные исходники и конфигурация
эксперимента МГТУ. Последовательность:

```powershell
python "Colab Notebooks/scorpion_v2/audit_scorpion_session.py" --experiment Experiments/scorpion_20261022
python "Colab Notebooks/scorpion_v2/inspect_scorpion_bin.py" --experiment Experiments/scorpion_20261022
python "Colab Notebooks/scorpion_v2/match_scorpion_bin.py" --experiment Experiments/scorpion_20261022

```

Последняя команда создаёт ноутбук без исполнения; затем его требуется
выполнить и экспортировать без кода по правилам основной рабочей папки.
Исходные сигналы, КТ, маски, локальные пути и конфигурации остаются вне Git.
