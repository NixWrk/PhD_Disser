# Контрольные проверки аудита 08.09.2026

Эта папка содержит проверки кода и сохранённых результатов, а не новый расчётный конвейер.
Основные исходники, экспериментальные данные и канонические FEM-результаты аудит не изменяет.
Численные проверки подтверждают только перечисленные программные и математические свойства.

Из корня `MATLAB_TRKG4_real_subjects`:

```powershell
python -X utf8 notebooks/audit_2026_09_08/check_report.py
python -X utf8 notebooks/audit_2026_09_08/check_driver.py
python -X utf8 notebooks/audit_2026_09_08/prepare_matlab_audit.py
matlab -batch "addpath('notebooks/audit_2026_09_08'); audit_matlab"
matlab -batch "addpath('notebooks/audit_2026_09_08'); audit_nonlinear"
```

Для MATLAB нужны настроенный EIDORS и прежние локальные FEM/STL-входы. `check_driver.py` запускает только имитацию MATLAB во временной папке и не выполняет оптимизацию. `check_report.py` подавляет графический вывод и DICOM, но исполняет все Python-ячейки; временная копия исходного ноутбука удаляется после сравнения.

Геометрические функции в `audit_matlab.m` извлекаются без изменения из проверяемого исходника генератором `prepare_matlab_audit.py`. `audit_nonlinear.m` сохраняет тот же снимок вспомогательных функций, использованный 08.09.2026. Это изолированные проверочные стенды; их не добавляют в основной MATLAB path постоянно. Хеши основных исходников на дату аудита находятся в `source_hashes.json`.

JSON и логи относятся к выполненным проверкам. При повторном запуске они перезаписываются в этой папке. Нелинейные дыхательные значения — сценарный контрпример логического вывода, а не новые физиологические оценки.
