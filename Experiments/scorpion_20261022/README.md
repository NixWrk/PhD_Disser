# Scorpion: Ник и Ярослав, 22.10.2026

Самостоятельная сессия двух участников. Прибор — Scorpion; аппаратная ревизия
в поставленном архиве отдельно не установлена. Дата следует из имени папки
и связанных BIN. Площадка этой сессии отдельно не подтверждена.

Получены 8 TXT Ника, 7 TXT Ярослава и два относящихся к этой дате BIN из
архива автора. Исходники сохранены в локальном `raw/` без изменения байтов.
Внутри архивной папки с именем Георгия найдены октябрьские BIN; их участки
связаны с новой сессией полным совпадением COUNT и обоих ЭКГ-полей всех
15 TXT. Имя папки не используется для определения участника.

Подтверждения автора и уточнение положения от 24.10.2026 приведены в [протоколе](PROTOCOL.md).
[Реестр](RECORDINGS.md) сохраняет все записи. Фотографии описаны отдельно
в [указателе](PHOTOS.md). Техническая инвентаризация остаётся локальной:
`metadata/inventory.local.json`, происхождение архива —
`metadata/archive_inventory.local.json`. Эти конфигурации не публикуются.
`record_identity.json` закрепляет идентификаторы за относительными путями
и хэшами; повторное копирование файлов не назначает им новые дыхательные окна.

Текущие самостоятельные отчёты:

- [Ник: 33.41](../../Colab%20Notebooks/scorpion_v2/33.41_Ник_эксперимент_модели_и_проверки_Scorpion.ipynb),
  [HTML](../../Colab%20Notebooks/scorpion_v2/33.41_Ник_эксперимент_модели_и_проверки_Scorpion.html).
- [Ярослав: 33.42](../../Colab%20Notebooks/scorpion_v2/33.42_Ярослав_эксперимент_модели_и_проверки_Scorpion.ipynb),
  [HTML](../../Colab%20Notebooks/scorpion_v2/33.42_Ярослав_эксперимент_модели_и_проверки_Scorpion.html).

Они содержат проверку сигналов, сравнение сборок и дыхательных уровней, четыре
кандидатных цикла на вдохе, двуслойную диагностику боковых сборок и
сопоставление двух независимых размеров Ника с реокардиомонитором МГТУ.
Для каждого выбрана собственная ручная поверхность Inobitec и перестроены
цилиндрические руки под обхват 370 мм. Стадии подготовки и прямого FEM
отслеживаются раздельно в `derived/exploratory/manual_stl_fem_20261026/`;
в отчёт включаются только завершённые результаты. Полные STL/MAT/сетки
и локальные конфигурации остаются вне Git.

Дыхательная и ЭКГ-разметка находятся в `annotations/session_1140/`, имеют
владельца 11.40 и статус `pending_manual_review`. Все расчёты по ним имеют
статус `exploratory_hypothesis_not_validated` и находятся в
`derived/exploratory/session_3340/`. Входная проверка индивидуальных КТ
выполнена отдельно по единому стандарту. Наличие масок не означает готового
FEM-прогноза или принятого сопротивления тканей.

В рабочем КТ-сценарии с боковым смещением −15 мм рассчитаны профили
до первого правого лёгкого и длины пересечений с тканевыми масками.
Варианты 0, −10 и −20 мм сохранены для сравнения положения.
Результат находится в `derived/exploratory/ct_calculation_20261024_y_minus15/`;
причина незапуска электрического FEM записана отдельно в
`calculation_status.local.json`. Этот расчёт не принимает эффективную h
и не снимает отказ подготовки наружной поверхности.

При наличии локальных КТ-паспортов сначала собирают сцену
`build_session_placement_3d.py`, затем выполняют `session_ct_geometry.py`.
Геометрический расчёт создаёт свежий каталог и не перезаписывает выполненный
прогон. Выборочная выгрузка диаграмм в 33.40 не публикует исходные маски.

Для воспроизведения из корня проекта нужны локальные исходники и конфигурация
эксперимента МГТУ. Последовательность:

```powershell
python "Colab Notebooks/scorpion_v2/audit_scorpion_session.py" --experiment Experiments/scorpion_20261022
python "Colab Notebooks/scorpion_v2/inspect_scorpion_bin.py" --experiment Experiments/scorpion_20261022
python "Colab Notebooks/scorpion_v2/match_scorpion_bin.py" --experiment Experiments/scorpion_20261022
python "Colab Notebooks/scorpion_v2/session_20261022.py"
python "Colab Notebooks/scorpion_v2/session_two_layer.py"
python "Colab Notebooks/scorpion_v2/session_equipment.py"
python "Colab Notebooks/scorpion_v2/build_session_subject_reports.py" --execute
```

Последняя команда выполняет два индивидуальных ноутбука и экспортирует HTML
без кода. Геометрические и электрические задачи запускаются отдельно через
описанные в `MATLAB_TRKG4_real_subjects/docs/PIPELINE_FOR_NOTEBOOKS.md` профили;
читательский генератор не считает FEM.
Исходные сигналы, КТ, маски, локальные пути и конфигурации остаются вне Git.
