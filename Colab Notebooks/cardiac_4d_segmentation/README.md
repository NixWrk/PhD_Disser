# Воспроизводимая сегментация сердца по 4D-КТ

Статус: разработка методики. Автоматические маски не являются клинически
валидированным результатом и до покадрового экспертного просмотра имеют статус
`pending_manual_review`.

## Что выделяется

- `whole_heart` — самостоятельная маска всего сердца из открытой задачи
  TotalSegmentator v2 `total/heart`; она не строится объединением других масок;
- `blood_pool` — объединение полостей левого/правого предсердий и желудочков;
  аорта и лёгочная артерия в него не включаются;
- `myocardium` — выходной класс `heart_myocardium` задачи
  `heartchambers_highres`; в текущем прогоне он представляет преимущественно
  миокард ЛЖ и перегородку и не считается маской полного миокарда всех камер;
- для каждой сердечной фазы сохраняются бинарные NIfTI, STL в координатах RAS
  и объёмы из воксельных масок.

STL используется для визуализации и FEM, но не для первичного расчёта объёма:
формат не хранит единицы и систему координат, а сглаживание поверхности меняет
объём. Источником количественных значений остаётся бинарная NIfTI-маска.

## Последовательность обработки

1. `inventory` читает только DICOM-заголовки и проверяет, какой тег действительно
   разбивает серию на полные 3D-фазы без повторяющихся срезов.
2. `convert` создаёт по одному HU-NIfTI на фазу с явным преобразованием DICOM LPS
   в NIfTI RAS+ и сохраняет хэшированные SOP UID.
3. `segment_totalseg_v2.py` запускает две модели TotalSegmentator 2.18.0:
   открытую `total/heart` для независимого `whole_heart` и лицензируемую
   академическую `heartchambers_highres` для камер и миокарда. Лицензионное
   значение читается из пользовательской конфигурации и не сохраняется в коде
   или манифестах.
4. `build_v2_cardiac_products.py` формирует три продукта, удаляет мелкие
   компоненты, исключает пересечение камер из миокарда, экспортирует STL и
   рассчитывает показатели межмодельного и временного контроля качества.
5. `summarize_v2_cohort_qc.py` объединяет результаты добровольцев в JSON и CSV.
6. После автоматического прогона обязательны визуальный просмотр всех фаз,
   исправление клапанных плоскостей/ушек/устьев сосудов и независимое сравнение
   хотя бы части фаз с ручной сегментацией Inobitec.

`segment_totalseg_v1.py` и команда `cardiac4d.py products` сохранены как
исторический исходный вариант v1 и не являются предпочтительным методом.

## Пример запуска

Абсолютные пути хранятся только в локальном скрипте запуска или
`config.local.json`, который исключён из Git.

```powershell
python cardiac4d.py inventory `
  --folder '<CT_DICOM_ROOT>' `
  --subject-id '<SUBJECT_ID>' `
  --output '<DERIVED_ROOT>\<SUBJECT_ID>\inventory.json'

python cardiac4d.py convert `
  --series-dir '<VERIFIED_4D_SERIES>' `
  --output-dir '<DERIVED_ROOT>\<SUBJECT_ID>\phases'

& '.\.venv-v2\Scripts\python.exe' '.\segment_totalseg_v2.py' `
  --input-dir '<DERIVED_ROOT>\<SUBJECT_ID>\phases' `
  --output-dir '<DERIVED_ROOT>\<SUBJECT_ID>\automatic_masks_v2' `
  --gpu 0

& '.\.venv-v2\Scripts\python.exe' '.\build_v2_cardiac_products.py' `
  --segmentation-dir '<DERIVED_ROOT>\<SUBJECT_ID>\automatic_masks_v2' `
  --output-dir '<DERIVED_ROOT>\<SUBJECT_ID>\products_v2'

& '.\.venv-v2\Scripts\python.exe' '.\summarize_v2_cohort_qc.py' `
  --derived-root '<DERIVED_ROOT>' `
  --subjects adam georg nix `
  --output-dir '<DERIVED_ROOT>\_cohort_qc_v2'
```

Для текущего окружения используются `requirements-base.txt` и
`requirements-totalsegmentator-v2.txt`; CUDA-сборка PyTorch устанавливается
отдельно под доступный GPU. Для исходного варианта сохранён файл
`requirements-totalsegmentator-v1.txt`. Каталоги `.venv*`, производные данные,
локальные конфиги и логи исключены из Git.

## Обязательный контроль качества перед анализом динамики

- правильная фаза и полный охват сердца;
- сохранённая геометрия DICOM/NIfTI и отсутствие зеркального отражения;
- раздельная проверка ЛП, ЛЖ, ПП, ПЖ и миокарда на каждом срезе;
- единые анатомические правила отсечения аорты, лёгочной артерии, полых и
  лёгочных вен;
- отсутствие скачков объёма между соседними фазами, объясняемых только ошибкой
  сегментации;
- сравнение с ручным референсом по коэффициенту Dice, 95-му процентилю
  расстояния Хаусдорфа (Hausdorff95), средней симметричной поверхностной
  дистанции (ASSD), объёму и воспроизводимости конечно-диастолической и
  конечно-систолической фаз (ED/ES);
- фиксация эксперта, даты, версии маски и причины каждой ручной правки.
